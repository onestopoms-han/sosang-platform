## 1. 데이터 스키마 및 API 계약 (Data Schema & API Contract)

대시보드가 표시할 핵심 데이터와 이를 위한 API 엔드포인트, 그리고 예상되는 JSON 응답 구조를 정의합니다.

### 1.1. API 엔드포인트 정의
| Endpoint | Method | Description | Access Level |
| :--- | :--- | :--- | :--- |
| `/api/v1/integrity_dashboard` | `GET` | 시스템 무결성 대시보드 전체 데이터 로드 | Authenticated User |
| `/api/v1/risk_status/:id` | `GET` | 특정 데이터 항목의 현재 리스크 상태 조회 (A, B, C 등급) | Authenticated User |
| `/api/v1/trust_widget/:id` | `GET` | 신뢰도 위젯 관련 상세 통계 및 시각화 데이터 로드 | Authenticated User |

## 2. UI 컴포넌트 및 상호작용 로직 (Component & Interaction Logic)

### 2.1. PainGauge 컴포넌트 (위험 지표 시각화)

**목표:** 사용자가 현재 시스템의 위험도를 직관적으로 인지하고, 클릭 시 상세 정보를 제공하는 인터랙션을 구현합니다.

*   **입력 데이터:** `metricValue` (0~100), `level` (A, B, C).
*   **시각적 표현:** 원형 게이지(Gauge)를 중심으로 색상 변화가 핵심입니다.
    *   **Color Mapping:**
        *   Level A: Growth Green (`#3CB371`) - 안전 영역
        *   Level B: Gold Amber (`#FFC72C`) - 경고 영역
        *   Level C: Critical Red/Orange (추가 정의 필요, 예: `#FF4500`) - 위험 영역
    *   **애니메이션 로직:** 마우스 오버 시 부드러운 색상 변화(Color Transition) 및 게이지의 미세한 진동 애니메이션을 적용하여 '위험성'을 강조합니다.
*   **JavaScript 상호작용 흐름:**
    1.  사용자가 특정 PainGauge (예: B등급 항목)를 클릭한다.
    2.  `onClick` 이벤트 발생 시, 해당 데이터의 상세 정보(`metricValue`, `trend`)가 하단 패널에 **모달 또는 슬라이드 인** 형태로 나타난다.
    3.  데이터 상세 표시 시, 배경 전체에 딥 블루(#004D66) 오버레이를 적용하여 **Focus** 상태를 명확히 한다.

### 2.2. Trust Widget 컴포넌트 (신뢰도 위젯)

**목표:** 시스템의 신뢰도를 요약하고, 클릭 시 상세 데이터 흐름을 보여주는 핵심 인터랙션 요소입니다.

*   **입력 데이터:** `overallTrustScore` (0~100), `status` (High/Medium/Low).
*   **시각적 표현:** 원형 프로그레스 바(Progress Bar)와 중앙의 점수 표시를 사용합니다.
    *   **Color Mapping:** `overallTrustScore`에 따라 색상을 동적으로 변화시킨다. (예: 80% 이상 $\rightarrow$ Green 계열, 50-80% $\rightarrow$ Gold 계열, 그 이하 $\rightarrow$ Red 계열).
*   **JavaScript 상호작용 흐름:**
    1.  사용자가 Trust Widget 영역을 클릭한다.
    2.  클릭 시, 데이터 로딩 상태(`Loading...`)를 표시하고 1초간 대기한다. (API 호출)
    3.  데이터 수신 후, **애니메이션**: 프로그레스 바가 부드럽게 채워지는 애니메이션(`transition: width 1s ease-in-out;`)을 실행하며, 점수 변화에 따라 위젯 전체가 미세하게 확대/축소(Scale)되는 효과를 추가하여 '확신'의 순간을 극대화한다.

# 📊 시스템적 통제권 회복을 위한 트렌드 및 경쟁사 분석 보고서

**🎯 핵심 메시지:** 불확실한 시장 환경 속에서, 개인의 건강(시스템) 관리와 데이터 기반의 위험 예측을 통해 **'손실 회피(Loss Aversion)'**를 극복하고 **'행동 가능한 실행 계획(Actionable Blueprint)'**으로 전환하는 것이 소상공인의 통제권 회복의 핵심이다.

## I. 최신 건강 및 웰니스 트렌드 (Pain Point 정의)

소상공인들이 직면한 가장 큰 고통 지점(Pain Point)은 재무적 손실뿐만 아니라, 불확실성으로 인한 심리적 불안정성에서 비롯됩니다. 이는 신체적, 정신적 건강과 직접적으로 연결되어 있습니다.

### 1. 인지 부하와 의사결정의 비효율성 (Cognitive Load & Decision Paralysis)
*   **트렌드:** 정보 과부하 시대에 복잡한 시장 데이터(재고, 마케팅 지표, 공급망 등)를 처리하는 데 드는 심리적 비용이 증가하고 있습니다.
*   **연결점:** 소상공인은 너무 많은 데이터를 분석하느라 **'다음 행동(Actionable Blueprint)'**을 취하지 못하고 의사결정 지연 상태에 놓입니다. 이는 곧 **위기 회피 비용(Risk Aversion Cost)**의 증가로 이어집니다.
*   **시스템적 통제권:** AI 시스템은 복잡한 정보를 단순화하여 즉각적인 실행 단계(Actionable Blueprint)를 제시함으로써 인지 부하를 최소화하고, 의사결정 속도를 높여 통제권을 회복시킵니다.

### 2. 예측 불가능성에 대한 심리적 불안정성 (Emotional Risk Management)
*   **트렌드:** 경제 변동성 증가로 인해 미래 수익에 대한 예측이 어려워지면서, 재무적 손실(Margin Volatility) 외에 **'손실 회피(Loss Aversion)'**로 인한 심리적 스트레스가 주요한 리스크 요인으로 부각되고 있습니다.
*   **연결점:** 잠재적 손실의 확률을 정량화하지 못하면, 소상공인은 무의식적으로 위험을 회피하는 비합리적인 결정을 내리게 됩니다.
*   **시스템적 통제권:** 데이터 기반으로 **'예상 이익 변동성(Margin Volatility)'**을 시각화하고, 이를 감성적 요소(골드 앰버/그린)와 연동하여 제공함으로써, 불안정성을 '감지'하는 것을 넘어 '관리 가능함(Control)'이라는 안정감을 제공합니다.

### 3. 개인 건강과 사업 성과의 상호 연결성 (Holistic Performance)
*   **트렌드:** 신체적 건강(수면, 스트레스 관리)이 정신적 명료성과 업무 효율성에 결정적인 영향을 미친다는 인식이 확산되고 있습니다.
*   **연결점:** 소상공인의 만성적인 스트레스와 피로 상태는 데이터 분석 능력을 저하시키고 오류를 유발하여 시스템 통제권을 훼손합니다.
*   **시스템적 통제권:** 건강 관리 데이터를 사업 성과 지표(KPI)와 통합함으로써, 신체적 안정성이 곧 비즈니스 안정성으로 직결됨을 증명하고 전방위적인 통제권을 확보합니다.

## II. 경쟁사 비교 분석: 위험 관리를 통한 차별화 포인트

경쟁사들은 주로 단순한 데이터 제공에 머물러 있지만, 참송이골드는 **'예측 및 행동 유도'**라는 시스템적 통제권 회복의 최종 단계에 집중합니다.

| 구분 | 일반적인 경쟁사 접근 방식 | 참송이골드의 차별화 전략 (시스템적 통제권) | 정량화된 위험 관리 적용 |
| :--- | :--- | :--- | :--- |
| **데이터 제공** | 과거 데이터 분석 (Diagnostic, 사후 분석) | 실시간 예측 및 경고 시스템 (Predictive, 사전 예방) | **예상 이익 변동성(Margin Volatility)** 실시간 측정 |
| **사용자 경험** | 정보 나열 및 보고서 제공 | 감성적 시각화와 즉각적인 실행 경로 제시 | **감성적 리스크 관리(Emotional Risk Management)** UX/UI 통합 |
| **결과물 중심** | 현황 보고 (What Happened) | 행동 가능한 실행 계획 (What to Do Next) | **행동 가능한 실행 계획(Actionable Blueprint)** 모듈 제공 |
| **핵심 가치** | 정보 접근성 | 시스템 무결성에 기반한 통제권 회복 | 데이터에 근거한 **손실 최소화(Loss Minimization)** |

### 💡 경쟁사 분석 시사점:
경쟁사들은 '정보'를 판매하지만, 참송이골드는 '불확실성 관리 능력'이라는 **시스템적 해답**을 판매해야 합니다. 이는 단순히 데이터를 보여주는 것을 넘어, 데이터 변화에 따라 사용자가 심리적으로 안정되고 즉각적인 행동으로 전환할 수 있도록 돕는 '감성적 시스템(Emotional System)' 구축이 핵심 경쟁력이 됩니다.

## III. 랜딩 페이지 및 제안서 활용 핵심 요약 (3가지 후크)

다음은 위 데이터를 바탕으로 마케팅 콘텐츠에 바로 적용할 수 있는 세 가지 핵심 논거입니다.

### 1. [위기 인지] 불안정성 측정: 당신의 숨겨진 손실 비용을 보십시오.
*   **논리:** 소상공인의 리스크는 재무적 변동성뿐 아니라 심리적 불안정성에서 시작됩니다. 우리는 단순한 수치가 아닌, **'예상 이익 변동성(Margin Volatility)'**과 **'위기 회피 비용(Risk Aversion Cost)'**을 측정하여 당신의 잠재적 손실 규모를 정량화합니다.
*   **활용:** 랜딩 페이지 최상단에 KPI 대시보드 시각화와 함께 "당신의 숨겨진 리스크는 얼마입니까?"라는 질문을 던져 불안정성을 즉각적으로 자극합니다.

### 2. [해답 제시] 데이터 기반의 행동 청사진: 통제권을 회복하는 시스템적 실행법.
*   **논리:** 복잡한 시장 정보에 압도당하지 마십시오. 저희는 예측 데이터를 **'행동 가능한 실행 계획(Actionable Blueprint)'**으로 전환합니다. 과거 분석에서 멈추지 않고, 지금 당장 취해야 할 구체적인 다음 단계를 시스템이 제시하여 불확실성을 통제권으로 바꿉니다.
*   **활용:** 상세페이지 및 제안서에 'Pain $\rightarrow$ Relief $\rightarrow$ Control'의 흐름을 명시하며, AI가 제공하는 구체적인 실행 모듈(Blueprint)의 존재를 강조합니다.

### 3. [신뢰 구축] 감성적 리스크 관리: 불안정함을 안정감으로 전환하는 디자인.
*   **논리:** 시스템은 데이터를 넘어 사용자의 심리까지 관리해야 합니다. 저희는 재무 데이터와 건강 지표를 **골드 앰버(#FFC72C) 및 Growth Green** 애니메이션과 연동하여, 위험 신호(Critical/Warning)가 나타날 때 즉각적인 행동을 유도하고 안정감(Control)으로 전환하는 감성적 UX를 제공합니다.
*   **활용:** UI/UX 프로토타입의 핵심 디자인 요소로 활용하여, 기술적 정확성과 심리적 안정을 동시에 전달하는 차별화된 경험을 제공합니다.
