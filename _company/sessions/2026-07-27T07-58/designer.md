## 🖼️ e-commerce MVP 와이어프레임 프로토타입 디자인 명세서 (Blueprint)

**프로젝트 목표:** '통제권 프리미엄' 경험을 극대화하는 인터랙티브 쇼핑몰 메인 페이지 및 상품 상세 페이지의 시각적 구조 확정.
**핵심 컨셉:** 권위(Authority) 상승에 따른 가치(Value)의 명확한 시각적 계층 구조 (L1 $\to$ L3).

### 1. 컬러 팔레트 및 타이포그래피 시스템

| 요소 | 색상 코드 (HEX) | 용도 | 설명 |
| :--- | :--- | :--- | :--- |
| **주조색 (Primary)** | `#1A1A1A` (Deep Charcoal Gray) | 배경, 주요 텍스트, UI 프레임 | 권위적이고 신뢰감을 주는 주된 색상. |
| **액센트색 (Accent)** | `#D4AF37` (Muted Gold) | 버튼 강조, 권위 게이지 채움, 핵심 데이터 표시 | 프리미엄과 가치를 상징하는 골드 액센트. |
| **보조색 (Secondary)** | `#E0E0E0` (Light Gray) | 배경 영역 구분, 카드 박스 | 차콜 그레이와의 대비를 통해 깊이를 제공. |
| **텍스트 색상** | `#FFFFFF` | 본문 텍스트 | 높은 가독성을 확보. |
| **폰트 시스템** | **Serif 계열 (예: Playfair Display 또는 Lora)** | 헤드라인, 브랜드명 | 전통성과 학술적 권위를 부여하여 타깃(40-50대 이상)에게 어필. |
| | **Sans-serif 계열 (예: Inter 또는 Roboto)** | 본문 설명, 데이터 수치 | 명확하고 현대적인 정보 전달을 위해 사용. |

### 2. 핵심 컴포넌트 상세 스펙

#### A. 권위 게이지 (Authority Gauge) - 메인 페이지 적용
*   **위치:** 상품 목록(Product Grid)의 좌측 또는 우측 사이드바에 고정 배치.
*   **구조:** 원형-방사형 인포그래픽 구조를 채택.
    *   **중심:** 현재 사용자의 **시스템 통제권 레벨 (L1, L2, L3)**을 가장 크게 표시.
    *   **반지름:** 게이지의 크기는 전체 컨테이너 내에서 시각적 무게감을 가지도록 설정.
    *   **채움 방식:** `Deep Charcoal` 배경 위에 `Muted Gold` 색상의 방사형 파동(Ripple) 효과를 사용하여 L1 $\to$ L2 $\to$ L3으로 진행될 때 동적인 변화를 표현.
*   **인터랙션 (Interaction):** 마우스 오버 시, 각 레벨(L1, L2, L3)에 대한 간략한 가치 설명 툴팁이 방사형으로 나타나도록 설계.

#### B. Control Value Breakdown - 상품 카드 적용
*   **위치:** 개별 상품 카드(Product Card) 내부에 배치.
*   **구조:** 원형 기반의 분할된 인포그래픽 구조.
    *   **중심 정보:** 제품 이름 및 가격 표시 (Charcoal 색상).
    *   **분할 영역 (Radial):** 원형을 3~4개의 구역으로 나누어 '통제권 프리미엄'이 어떻게 구성되는지 시각화.
        *   **구역 1 (L1 Focus):** 핵심 품질/신뢰 지표 표시.
        *   **구역 2 (L2 Focus):** 공급망 투명성 및 데이터 접근 관련 가치 표시.
        *   **구역 3 (L3 Focus):** 독점적 권한 및 미래 예측에 대한 프리미엄 가치 표시.
    *   **색상 활용:** 각 구역의 배경은 보조색(`E0E0E0`)을 사용하며, 핵심 지표(숫자)와 경계선에는 액센트색(`Muted Gold`)을 사용하여 시각적 위계를 강조.

### 3. MVP 페이지 레이아웃 (Desktop View 기준)

| 영역 | 구성 요소 | 디자인 지침 |
| :--- | :--- | :--- |
| **Header** | 로고, 내비게이션, 사용자 권위 게이지 (L1/L2/L3 표시) | 전체 배경은 Deep Charcoal. 골드 액센트로 강조된 브랜드명. |
| **Main Content Area** | 상품 목록 그리드 및 필터 | 깔끔하고 여백이 많은 레이아웃. 카드 박스는 보조색(`E0E0E0`)으로 구분. |
| **Sidebar (좌측)** | **권위 게이지 (Authority Gauge)** | A. 섹션 A에서 정의된 원형-방사형 인포그래픽을 배치하여 지속적인 상태 변화를 보여줌. |
| **Footer** | 표준 정보 및 법적 고지 | 심플하게 처리하며, 신뢰감을 유지. |

### 4. 최종 사용자 경험 (UX) 흐름 시각화 요약

1.  **접근:** 사용자가 상품 목록에 진입한다.
2.  **권위 인식:** 좌측의 Authority Gauge를 통해 현재 시스템 통제권 레벨(예: L2)을 즉각적으로 인지한다.
3.  **탐색:** 사용자가 특정 상품 카드를 클릭한다.
4.  **가치 확인:** 상품 카드 내의 **Control Value Breakdown** 컴포넌트를 통해, 해당 제품이 제공하는 '통제권 프리미엄'이 L1(품질)에서 L3(운영 권한)까지 어떤 단계로 구성되어 있는지 시각적으로 파악한다.
5.  **행동:** 사용자는 이 명확한 시각적 정보에 기반하여 구매 결정을 내린다.
