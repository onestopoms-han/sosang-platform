## 📄 디자인 브리프: HS Code 85 Chapter 위험 분류 시각 학습 모듈

이 디자인 브리프는 복잡한 관세법규(HS Code Chapter 85)의 법적 해석과 실무 적용을 내부 직원들이 직관적으로 이해하고, 오분류 리스크를 최소화하기 위해 설계되었습니다. 핵심은 **결정 흐름(Flow)**과 **핵심 비교(Comparison)**에 중점을 맞춥니다.

### 🎨 디자인 시스템 요약 (Design System Summary)

| 요소 | 색상 코드 | 의미 | 사용 목적 |
| :--- | :--- | :--- | :--- |
| **안정/권위 (Control)** | `#FFD700` (Rich Gold) | 최종 권고, 우선순위 항목, 확정된 분류 기준 | 핵심 결과 강조 및 신뢰도 부여 |
| **경고 (Warning)** | `#FFA500` (Amber) | 잠재적 오분류 위험, 추가 검토 필요 사항 | 주의를 환기하고 조치를 요구 |
| **위험 (Danger)** | `#FF6347` (Tomato Red) | 분류 오류 시 법적/재무적 리스크가 높은 항목 | 즉각적인 경고 및 긴급 조치 요청 |
| **정보 (Information)** | `#4682B4` (Steel Blue) | 정의, 배경 설명, 참고 사항 | 상세 정보를 제공하여 이해도를 높임 |

### 🖼️ 모듈 구성안: 시각 학습 흐름도 (Flowchart Module)

**목표:** Flat Panel Display Modules(FPD)와 Printed Circuits의 분류 우선순위 및 경계선을 시각적으로 명확히 제시합니다.

#### **[Flowchart 제목]**
**Chapter 85 핵심 분류 결정 흐름: FPD & PCB 오분류 방지 가이드**

#### **[Flowchart 구조 제안]**

1.  **시작 노드 (Start Node):** "품목 식별" (Item Identification)
2.  **분기점 1 (Decision Point 1):** "해당 품목이 'Flat Panel Display Module'인가?" (Is it an FPD?)
    *   **YES 경로:** $\rightarrow$ **85.24 우선 적용** (Gold 색상 강조) $\rightarrow$ [결과: 최종 분류 확인]
    *   **NO 경로:** $\rightarrow$ **분기점 2**
3.  **분기점 2 (Decision Point 2):** "품목이 'Printed Circuit'인가?" (Is it a PCB/Circuit?)
    *   **YES 경로:** $\rightarrow$ **85.41 / 85.42 경계 분석** (Amber 색상 경고) $\rightarrow$ [다음 단계: 세부 구성 요소 확인]
    *   **NO 경로:** $\rightarrow$ **일반 전기 기계 분류** (Information 색상) $\rightarrow$ [결과: 일반 분류 진행]

#### **[Flowchart 디자인 지침]**

*   **노드 디자인:** 각 결정 노드는 사각형 또는 원형으로 표현하며, 경고/위험 상태에 따라 배경색을 즉시 변경합니다.
    *   FPD 관련 경로는 **Gold**로 연결하여 '우선순위'를 시각적으로 강조합니다.
    *   PCB/반도체 관련 경로는 **Amber**로 연결하여 '경계 필요성'을 강조합니다.
*   **연결선:** 화살표는 흐름의 방향을 명확히 지시하며, 주요 분기점에는 굵은 테두리를 적용합니다.
*   **레이블링:** 각 단계마다 핵심 법적 근거(예: Note 7)를 작게 병기하여 신뢰도를 높입니다.

### 📊 모듈 구성안: 위험 품목 비교표 (Comparison Table Module)

**목표:** HS Code 85의 주요 고위험 항목 간의 정의와 적용 범위를 명확히 비교하여 실무자가 즉각적으로 판단할 수 있도록 합니다.

#### **[Comparison Table 제목]**
**Chapter 85 핵심 품목별 분류 위험 비교 및 기준표**

#### **[표 구조 제안]**

| 구분 (Category) | HS Code | 핵심 정의 (Definition Focus) | 주요 법적 쟁점 (Legal Issue) | 권고 분류 (Recommended Class) | 시각적 표시 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **디스플레이 모듈** | 85.24 | 다른 호에 통합되도록 설계된 장치 (Precedence Rule) | FPD가 일반 기계(84류)와 어떻게 결합되는지? | **85.24** | $\text{\color{#FFD700}Gold}$ |
| **인쇄 회로 (PCB)** | 85.34 | 인쇄 공정으로 얻은 요소들의 집합 (회로 구조 자체) | 패시브/액티브 소자(85.41/42)의 포함 여부? | $\text{85.34}$ 또는 $\text{85.42}$ | $\text{\color{#FFA500}Amber}$ |
| **반도체 기반 장치** | 85.41 / 85.42 | 실리콘 기반 센서, 액추에이터 등 (기능적 초점) | 'Semiconductor-based'의 물리적/기능적 기준 충족 여부? | $\text{85.41}$ 또는 $\text{85.42}$ | $\text{\color{#FF6347}Red}$ |
| **전기 부품** | 85.32, 85.35, 85.39 | 전기 장치에 사용되는 구성 요소 (Capacitors, Switches 등) | 해당 부품이 주된 기계의 일부인지 여부? | $\text{85.35}$ 또는 $\text{85.44}$ | $\text{\color{#4682B4}Blue}$ |

#### **[Comparison Table 디자인 지침]**

*   **컬러 코드 적용:** 각 행(Row)의 '권고 분류' 셀에 지정된 색상을 적용하여, 직관적으로 어떤 항목이 가장 높은 위험도를 가지는지 시각적으로 인식하게 합니다.
*   **강조:** 핵심 법적 쟁점 열에는 **볼드체**를 사용하여 독자가 반드시 검토해야 할 포인트를 강조합니다.
*   **레이아웃:** 표는 좌측에 '구분'을, 우측에 '분류/위험도'를 배치하여 정보의 계층 구조를 명확히 합니다.
