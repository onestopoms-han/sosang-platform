# 📊 SSI 인터랙티브 위젯 최종 디자인 및 기술 스펙 문서

## 1. 디자인 철학 및 목표 (Design Philosophy & Goal)

**핵심 목표:** 단순한 데이터 표시를 넘어, 사용자가 자신의 '시스템 통제 경험(SSI)'을 직관적으로 이해하고, 과학적 근거에 기반한 **'통제감 확보'의 여정**을 시각적으로 체험하게 한다.
**톤앤매너:** 권위적(Authoritative), 프리미엄(Premium), 미식적(Gourmet).
**핵심 비주얼 원칙:** 데이터의 중요성(SSI 값)은 **Rich Gold 색상**으로 강조하고, 그 근거가 되는 시스템 지표는 **Deep Forest Green** 배경 위에 명확하게 배치하여 시각적 강조가 과학적 근거에 기반함을 명시한다.

## 2. 컬러 및 타이포그래피 시스템 (Color & Typography System)

| 요소 | 색상 코드 | 용도 | 설명 |
| :--- | :--- | :--- | :--- |
| **Primary (배경)** | `#1A231C` (Deep Forest Green 계열) | 배경, 메인 카드 영역 | 깊고 차분한 신뢰감을 제공 |
| **Accent (강조)** | `#D4AF37` (Rich Gold) | SSI 값, 주요 지표 강조선 | 프리미엄성과 권위를 부여 |
| **Secondary (텍스트)** | `#E0F2F1` (Soft Off-White/Light Green) | 시스템 지표 설명 텍스트 | 가독성을 확보하며 차분함을 유지 |
| **Tertiary (보조)** | `#4A6B5C` (Darker Forest Tone) | 보조 레이블, 경계선 | 정보의 계층 구조화 |

**타이포그래피:**
*   **헤드라인/핵심 지표:** 산세리프 계열 (예: Inter, Pretendard). Bold 처리하여 강한 인상 부여.
*   **설명 텍스트:** 가독성이 높은 세리프 또는 산세리프 혼용.

## 3. SSI 위젯 컴포넌트 상세 와이어프레임 및 상태 정의 (Component Wireframes & State Definition)

SSI 위젯은 크게 **'현황 대시보드', '상태 변화 시각화', '데이터 근거'**의 세 부분으로 구성됩니다.

### 3.1. 기본 상태: 안정적(Stable State - Baseline)

**목표:** 현재 시스템의 균형 상태를 명확히 보여줌.
**레이아웃:** 중앙 집중형 카드 디자인.

| 영역 | 내용 | 시각적 처리 | 데이터 흐름/상태 |
| :--- | :--- | :--- | :--- |
| **Title** | **시스템 안정성 지수 (SSI)** | 가장 크고 굵게 표시 (Rich Gold) | 고정 값 표시 |
| **Core Value** | `Control Score: XX%` | **가장 크게**, Rich Gold 색상으로 강조 | 현재 계산된 SSI 값 |
| **Status Bar** | 안정성 상태 표시 (예: '안정', '주의', '위험') | 배경색 기반의 바(Bar) 형태로 시각화 | `control_score` 값에 따라 동적 변화 |
| **System Insight** | 시스템 지표 설명 (`시스템 통제권 확보율: XX%`) | 작은 폰트 (Secondary 색상), Gold 테두리 처리 | 데이터 근거 명시 |

### 3.2. 상태 변화 시각화: 역동성(Dynamic State - Transition)

사용자의 입력이나 시스템 변동에 따라 SSI가 변화할 때, 그 **과정**을 보여주는 것이 핵심입니다.

**레이아웃:** 애니메이션 기반의 게이지 및 트랜지션 표시.

1.  **게이지 움직임:** Core Value (`Control Score`)는 현재 위치를 Gold 색상으로 표시하고, 이전 상태와의 변화를 부드럽게(Smooth Transition) 보여준다.
2.  **시스템 지표 강조:** `System Insight` 영역의 텍스트(`시스템 통제권 확보율: XX%`)가 실시간으로 업데이트되며, 데이터 값은 **Rich Gold**로 플래시 효과 또는 서서히 채워지는 애니메이션을 적용한다.
3.  **경고 표시 (Alert State):** SSI가 임계값 이하로 떨어지면, 전체 카드 배경색이 Deep Forest Green에서 경고 색상(예: Amber/Orange)으로 미묘하게 변화하며 즉각적인 주의를 유도한다.

### 3.3. 데이터 근거 시각화: 권위 확보 (Authority Visualization)

데이터의 신뢰도를 극대화하는 영역입니다.

**레이아웃:** 하단에 세부 근거를 배치하여 '왜 이 숫자가 중요한지'를 설명합니다.

*   `[Control Score: XX%]` 값 아래에 작은 폰트로 시스템 지표 설명(`시스템 통제권 확보율: YY%`)을 배치한다.
*   **데이터 레이블링 규칙:** 모든 수치(예: `control_score: 98.5%`)는 가장 크게 배치하고, 그 아래의 시스템 지표 설명은 **Rich Gold**로 표시하여 시각적 강조가 과학적 근거에 기반함을 명시한다.

## 4. 기술적 제약 조건 및 데이터 흐름 (Technical Constraints & Data Flow)

**A. 데이터 모델 (Data Model):**
위젯은 최소한 다음의 세 가지 핵심 데이터를 실시간으로 받아야 합니다.

1.  `control_score`: (0 ~ 100%) 현재 시스템 안정성 지수. (Primary Visualization)
2.  `system_metric_name`: (String) 표시할 시스템 지표 이름 (예: '시스템 통제권 확보율').
3.  `system_value`: (Number) 해당 지표의 구체적인 수치 값.

**B. 상태 변화 로직 (State Transition Logic):**
*   **Input:** `control_score`가 변경될 때마다, 시스템은 내부적으로 정의된 **임계값(Thresholds)**을 검사해야 한다.
    *   `90% ~ 100%`: Stable (녹색 계열 강조)
    *   `70% ~ 89%`: Caution (황색 계열 변화 시작)
    *   `<70%`: Warning (주요 경고 표시 및 색상 변경)
*   **UI Action:** 이 임계값에 따라 위젯의 배경색, Core Value의 강조 색상(Gold Intensity), 그리고 시스템 지표 텍스트 색상이 동적으로 변화해야 한다.

**C. 인터랙션 요구사항 (Interaction Requirement):**
*   사용자가 특정 데이터 포인트(예: `control_score`)를 마우스 오버하거나 탭할 경우, 해당 수치 옆의 시스템 지표 설명(`시스템 통제권 확보율: XX%`)이 **툴팁(Tooltip)** 형태로 확장되어 상세 설명을 제공해야 한다. (이는 '과학적 근거'에 대한 즉각적인 접근성을 제공함.)
