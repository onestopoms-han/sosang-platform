모든 디자인은 모바일 환경의 스크롤 흐름과 터치 인터랙션을 최적화하여, 사용자가 구매 버튼을 누르기 직전에 '신뢰도'를 극대화하는 데 중점을 둡니다.

### 🖼️ 캠페인 전용 시각 변주 목업 세트 (3종)

다음은 Authority Gauge의 위치와 인터랙션 방식을 달리하여 신뢰도를 구축하는 3가지 핵심 디자인 컨셉입니다. 각 목업은 모바일 상세페이지 환경을 가정하고 디자인 스펙으로 제공됩니다.

#### **1. 목업 A: The Direct Proof (직접 증명형)**
*   **목표:** 시스템의 투명성과 현재 상태를 즉시 제시하여 불안정성을 해소합니다.
*   **배치 위치:** 상품 설명 섹션 중간, 구매 옵션 직전.
*   **핵심 요소:** Authority Gauge를 수평으로 배치하고, 진행 단계별로 명확한 텍스트와 색상 변화를 강조합니다.

| 디자인 요소 | 상세 스펙 | 의도 및 효과 |
| :--- | :--- | :--- |
| **레이아웃** | 세로형 (모바일 최적화). Authority Gauge는 전체 너비의 70%를 차지하며, 하단에 구체적인 데이터가 배치됨. | 시선이 자연스럽게 진행도(Gauge)로 이동하여 현재 위치를 즉시 인지하게 함. |
| **Authority Gauge** | Deep Blue(#004D66) 배경 위에 Growth Green(#3CB371)으로 채워지는 진행 바 형태. (예: 0% → Gold Stage 진입 시 95%) | 시스템적 통제권 확보 과정을 시각적으로 동적인 '진행'으로 표현. |
| **인터랙션** | 사용자가 스크롤할 때 Gauge가 부드럽게 업데이트되며, 마우스 오버/탭 시 각 단계별 데이터(예: "Stage 1: 초기 분석 완료")가 팝업되어 표시됨. | 스크롤링 자체가 권위 상승의 경험이 되도록 유도. |
| **CTA 연계** | Gauge 하단에 "다음 단계로 가기 (Continue to Next Stage)" 버튼을 배치하여 다음 섹션으로의 자연스러운 흐름을 제안. | 구매 행위를 '시스템 관리'의 다음 단계로 포지셔닝. |

#### **2. 목업 B: The Immersive Lock (몰입형 잠금형)**
*   **목표:** 최종 권위 확보 단계('Gold Layer Solidification')를 극적으로 시각화하여 심리적 안정감과 구매 결정력을 높입니다.
*   **배치 위치:** 상품의 핵심 가치를 설명하는 가장 중요한 섹션, CTA 직전.
*   **핵심 요소:** '골드 레이어 고정' 애니메이션을 중심으로 디자인을 구성합니다.

| 디자인 요소 | 상세 스펙 | 의도 및 효과 |
| :--- | :--- | :--- |
| **레이아웃** | 중앙 집중형. Gauge를 화면 전체에 걸쳐 배치하고, 배경은 Deep Blue로 깊이감을 부여함. | 사용자가 모든 시선과 인지 자원을 이 '잠금' 과정에 집중하도록 유도. |
| **Authority Gauge** | Gauge가 완전히 채워지는 순간, 배경 전체가 Gold Color(고급스러운 골드 톤)로 부드럽게 '고정(Solidification)'되는 애니메이션을 적용. (지속 시간: 1500ms 확정) | 최고 권위 단계 진입 시, 단순한 색 변화가 아닌 '물리적/시스템적 고정'의 느낌을 부여하여 신뢰도를 극대화. |
| **텍스트 강조** | "System Control Secured" 또는 "Authority Lock Achieved"와 같은 강력하고 간결한 문구를 Gold 톤으로 중앙에 배치. | 감성적 만족감과 시스템적 성공을 동시에 전달. |
| **CTA 연계** | 고정 애니메이션이 끝난 후, CTA 버튼은 '구매하기 (Acquire System)'로 변경되며 명확하게 강조됨. | 권위 확보가 곧 구매 행위의 정당한 이유임을 각인. |

#### **3. 목업 C: The Data Flow Map (데이터 흐름 지도형)**
*   **목표:** 효능 주장 대신 데이터 기반의 '시스템적 과정'을 시각화하여 과학적인 신뢰를 구축합니다.
*   **배치 위치:** 상세페이지 상단 또는 사이드바 영역에 배치하여 전체 콘텐츠의 맥락을 제공합니다.
*   **핵심 요소:** Authority Gauge를 데이터 흐름(Flow)의 일부로 표현합니다.

| 디자인 요소 | 상세 스펙 | 의도 및 효과 |
| :--- | :--- | :--- |
| **레이아웃** | 수직형 정보 카드 형태. Gauge는 상단에 위치하고, 그 아래에 Authority를 구성하는 핵심 데이터 포인트(예: 장-뇌 축 연관성, 특정 영양소 지표 등)가 목록화됨. | 단순한 진행률이 아닌, '왜 이 단계에 도달했는지'에 대한 과학적 근거를 제공. |
| **Authority Gauge** | 보조적인 역할. 데이터 흐름의 시작점 또는 현재 위치를 표시하는 작은 인디케이터로 활용. (색상은 Growth Green을 기본으로 사용) | Gauges가 주된 시각적 목표가 아닌, 전체 시스템의 맥락을 이해하는 보조 도구임을 강조. |
| **텍스트 강조** | 각 데이터 포인트 옆에 Authority 점수와 함께 짧은 과학적 근거 문구를 병기 (예: "Authority 60%: 장-뇌 축 최적화"). | 마케팅 메시지를 '효능'이 아닌 '관리 체계'로 전환. |
| **CTA 연계** | 하단에 "전체 데이터 흐름 확인하기" 버튼을 배치하여 상세 정보 접근성을 높임. | 잠재 고객에게 깊이 있는 정보를 제공하며 신뢰를 심화. |
