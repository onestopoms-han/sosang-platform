# 📋 작업 브리프

**원 명령:** "기존 실행 중인 서버 있으면 다 종료하고, 현재 폴더의 개발 서버(npm run dev 등)만 다시 실행해줘"

## 요약
현재 로컬 환경에서 실행 중인 모든 개발 서버를 안전하게 종료하고, 지정된 폴더의 개발 모드 서버만 재시작하는 기술 요청입니다.

## 분배
- **💻 코다리**: 터미널 기반의 작업 지침을 제공하십시오. 먼저, 현재 실행 중인 모든 백그라운드 프로세스(개발 서버 포함)를 종료할 수 있는 일반적인 명령어 시퀀스 (예: Ctrl+C 안내 또는 kill command 사용)를 안내하고, 그 후 해당 폴더에서 개발 서버를 재시작하는 정확한 명령(`npm run dev` 등)을 실행하거나 가상의 코드 블록으로 제시하십시오.
