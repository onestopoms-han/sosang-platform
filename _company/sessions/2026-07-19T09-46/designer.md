# 🚀 인터랙티브 와이어프레임 가이드라인: 시스템 주권 확보 플로우
**목표:** KPI 게이지 상태 변화를 통해 사용자에게 '경고 $\rightarrow$ 원리 제시 $\rightarrow$ 안정화'의 심리적 압박(Urgency)을 극대화하고, 최종 CTA('무료 진단 테스트 신청')로 유도한다.

## 1. 핵심 디자인 시스템 적용 (Visual Foundation)
*   **Primary Color:** Deep Blue ($\#004D66$) - 과학적 권위, 안정성 표현.
*   **Secondary/Action Color:** Growth Green ($\#3CB371$) - 성장, 긍정적 변화, 성공의 희망 표현.
*   **Urgency Indicator:** Amber Zone (경고 영역)를 명확히 구분하여 시각적 위협감을 조성한다.

## 2. KPI 게이지 상태별 상세 UX 플로우 및 애니메이션 지시

KPI 게이지(SSI Gauge)는 단순한 수치 표시가 아닌, 사용자의 **생체 시스템의 불안정성**을 반영하는 동적 에너지 흐름으로 시각화되어야 합니다.

### State A: 초기/안정 상태 (Baseline / Stable)
*   **시각:** 게이지 바는 Deep Blue 톤으로 채워지며, 부드럽게 상승하는 생체 시스템의 안정적인 흐름을 표현한다.
*   **텍스트:** "시스템 안정화 단계" 또는 "기반 데이터 확보 중"
*   **Hover Effect (마우스 오버):** 게이지 바가 미세하게 진동하며, 주변에 Growth Green 색상의 은은한 광선(Flow Line)이 흐르는 애니메이션을 적용한다. 이는 잠재적인 성장의 가능성을 암시한다.

### State B: 경고 상태 (Warning / Amber Zone)
*   **심리적 효과:** 불안감과 즉각적인 주의 집중. 시스템에 문제가 발생했음을 인지시킨다.
*   **시각:** 게이지 바가 **Amber Zone**으로 전환되며, 색상이 Deep Blue에서 붉은 기가 도는 주황색(Amber)으로 변화한다. 배경 전체에 미세한 경고 효과(Subtle Pulse/Flicker)를 적용하여 시각적 압박을 높인다.
*   **Micro-Animation:** 게이지의 움직임이 약간 빨라지거나, 바 자체가 미세하게 떨리는 듯한 애니메이션을 추가하여 **'시스템 불안정성'**을 직접적으로 전달한다.
*   **Call to Action (CTA):** CTA 버튼은 잠시 비활성화(Disabled) 상태로 전환되거나, 경고 문구와 함께 "위험 감지! 원리 제시 필요"라는 팝업 메시지를 동반하여 클릭을 강제한다.

### State C: 임계점/위기 상태 (Critical / Red Zone)
*   **심리적 효과:** 즉각적인 위협, 시스템 붕괴에 대한 공포 유발. 행동 없이는 손실이 따른다는 느낌을 극대화한다.
*   **시각:** 게이지 바가 **Red Zone**으로 완전히 전환되며, 강력하고 빠른 색상 변화(Deep Blue $\rightarrow$ Red)를 적용한다. 배경은 붉은 기운이 감도는 어두운 톤으로 전환된다.
*   **Micro-Animation:** 게이지 자체가 빠르게 깜빡이거나(Rapid Flicker), 바가 아래로 급격히 하강하는 듯한 애니메이션을 사용하여 **'시스템 붕괴 임박'**의 긴급성을 시각적으로 표현한다.
*   **Urgency Text:** "경고: 시스템 안정화 실패! 즉시 조치 필요"와 같은 강력하고 직접적인 문구를 게이지 주변에 오버레이한다.
*   **Final CTA Lock:** 이 상태에서는 '무료 진단 테스트 신청' 버튼이 **최대 강조**되며, 다른 선택지는 비활성화되고 오직 단 하나의 행동만이 남도록 설계한다.

## 3. 최종 인터랙티브 흐름 요약 (Interaction Flow Summary)

| 단계 | KPI 상태 | 시각적 변화 (Color/Motion) | 사용자 경험 (Psychological Impact) | 목표 액션 유도 |
| :--- | :--- | :--- | :--- | :--- |
| **1단계** | Stable (Blue) | 부드러운 흐름, 은은한 Green Flow | 안정감 및 잠재적 성장 기대 | 데이터 확인 (Passive) |
| **2단계** | Warning (Amber) | 색상 변화(Orange), 미세 진동/펄스 | 주의 집중, 불안감 시작 | 원리 제시 정보 탐색 (Active Inquiry) |
| **3단계** | Critical (Red) | 급격한 색상 전환, 빠른 깜빡임 | 긴급성 극대화, 시스템 붕괴 공포 | 즉각적인 해결책 요구 (Urgent Action) |
| **4단계** | Action Trigger | CTA 버튼 최대 강조 및 고정 | 통제력 상실에 대한 위협 | **무료 진단 테스트 신청** |

## 4. 디자인 가이드라인 요약 (Design Guideline Summary)

1.  **색상 대비:** Deep Blue(신뢰/기반)와 Growth Green(성장/해결책)의 대비를 극대화하여, 불안정 상태에서 해결책으로 넘어갈 때 시각적 이질감을 통해 전환을 강조한다.
2.  **동작의 속도:** Stable $\rightarrow$ Critical로 갈수록 애니메이션과 색상 변화의 **속도(Velocity)**를 점진적으로 증가시켜 사용자의 심박수를 높이는 효과를 유도한다.
3.  **CTA 위치:** Critical 상태에서는 CTA 버튼이 화면 중앙에 고정되며, 배경의 긴급한 시각적 자극을 무시할 수 없도록 배치한다.
