## 📄 웹페이지 카피라이팅 초안 (Webpage Copy)

### 1. 메인 히어로 섹션 (Hero Section: 불안정성 인식 극대화)
**목표:** 대표의 가장 큰 불안(불확실성)을 직접적으로 언급하며 시선을 사로잡고, 서비스가 유일한 해답임을 제시합니다.

| 요소 | 카피라이팅 (Copywriting) | 강조 포인트 |
| :--- | :--- | :--- |
| **헤드라인 (H1)** | **당신의 사업, 법적 불확실성으로 잠식되고 있습니까?** | 직접적인 질문으로 즉각적인 공감 유도. |
| **서브카피 (Subcopy)** | 복잡한 법률과 규제 속에서, 당신은 통제권을 잃고 위험에 노출되어 있습니다. 이제 AI 기반 시스템으로 모든 리스크를 명확히 인지하고 통제하세요. | 불안정성 인식(Red)을 명시하고, 서비스가 제공하는 핵심 가치(통제권 확보)를 제시. |
| **CTA 버튼 (Call to Action)** | **나의 리스크 점수 확인하기** | '점수 확인'이라는 구체적 행동 유도. RRS 시스템과의 연동 강조. |

### 2. 문제 정의 섹션 (Pain Point Deep Dive: 불안정성 심화)
**목표:** 소기업 대표가 실제로 겪는 법률/행정적 고통을 구체적인 페인 포인트로 짚어내어 공감대를 극대화합니다.

| 요소 | 카피라이팅 (Copywriting) | 강조 포인트 |
| :--- | :--- | :--- |
| **헤드라인** | **숨겨진 리스크가 당신의 성장을 멈추게 합니다.** | 불안정성이 곧 성장 저해임을 연결. |
| **본문/불안 포인트 (Bullet Points)** | - **규제 변화의 공포:** 예측 불가능한 법규 변경이 사업 운영에 미치는 치명적인 영향. <br> - **복잡한 계약 리스크:** 사소한 조항 하나가 큰 손실로 이어지는 잠재적 위험. <br> - **미지의 행정 절차:** 어디서부터 시작해야 할지 모르는 행정 업무의 혼란과 시간 낭비. | 구체적인 상황을 제시하여 '나의 이야기'로 인식하게 함. |
| **중간 CTA** | **당신의 리스크, AI가 측정합니다.** | RRS 시스템으로의 전환을 유도. |

---

### 3. 솔루션 제시 섹션 (Solution: 명확한 통제권 확보 강조)
**목표:** 우리 서비스(AI 법률 에이전트)만이 제공할 수 있는 '명확성'과 '통제감'이라는 독점적인 해법을 강조합니다.

| 요소 | 카피라이팅 (Copywriting) | 강조 포인트 |
| :--- | :--- | :--- |
| **헤드라인** | **불확실성을 통제 가능한 데이터로 바꾸는 시스템.** | '통제권 확보'의 핵심 메시지 전달. |
| **본문/솔루션 설명** | 우리는 단순한 정보 제공을 넘어, 복잡한 법률 환경을 **'Risk Reduction Score (RRS)'**라는 명확한 지표로 전환합니다. AI 에이전트가 실시간 데이터를 분석하여 당신의 사업 상황에 따른 최적의 대응 경로를 제시함으로써, 모호함을 확신으로 바꿉니다. | 시스템 기반 접근법(AI, RRS)을 통해 불안정성 해소라는 구체적인 결과를 약속. |
| **핵심 가치 강조** | **모호함 $\rightarrow$ 데이터 기반 통제권 확보 (Red $\rightarrow$ Gold)** | 디자인의 색상 흐름과 연결하여 시각적/심리적 전환을 명시적으로 강조. |

### 4. 서비스 작동 방식 섹션 (How It Works: 신뢰 구축)
**목표:** AI 에이전트가 어떻게 불안정성을 통제하는지 과정을 단순화하여 보여줍니다.

| 요소 | 카피라이팅 (Copywriting) | 강조 포인트 |
| :--- | :--- | :--- |
| **단계 1** | **[Input] 상황 진단:** 사업 데이터를 입력하면 AI가 현재의 법적/행정적 불안정성(RRS)을 정량화합니다. | 데이터 입력의 용이성 강조. |
| **단계 2** | **[Chatting] 리스크 분석:** AI 에이전트가 수많은 판례와 규제를 기반으로 잠재적 위험 요소를 심층 분석하고 근거를 제시합니다. | '추측'이 아닌 '근거 기반' 분석임을 강조. |
| **단계 3** | **[Finalizing] 통제 전략 도출:** RRS 변화에 따라, 가장 효과적인 리스크 감소 전략과 실행 계획을 설계합니다. | 단순 정보가 아닌, 실행 가능한 '전략' 제공 강조. |
| **단계 4** | **[Approved] 명확한 다음 단계:** 사용자가 확신을 가지고 행동할 수 있도록 최종 승인된 통제 경로를 제시합니다. | 최종적으로 사용자에게 '명확성'과 '행동력'을 부여함. |

| 요소 | 카피라이팅 (Copywriting) | 강조 포인트 |
| :--- | :--- | :--- |

| **본문** | 복잡한 법률 환경에 휘둘리지 않고, 데이터 기반의 명확한 통제권으로 사업을 안정적으로 성장시키십시오. 지금 바로 AI 법률 시스템을 경험하고 리스크를 관리하세요. | 서비스 사용의 최종 목표(안정적 성장)를 제시. |
| **CTA 버튼** | **지금, 나의 RRS 확인 및 솔루션 받기 (클릭)** | 행동과 보상의 연결. 긴급성과 명확성 부여. |

## 📱 앱 내 주요 화면 카피라이팅 초안 (App Screen Copy)

### A. 대시보드 화면 (RRS 게이지 강조)
**목표:** 사용자가 현재 상태(불안정성)와 목표 달성 상황을 한눈에 파악하고, 다음 행동의 방향성을 제시합니다.

*   **상단 헤드라인:** **[사업 리스크 현황] 현재 통제 레벨: 65% (경고)**
*   **핵심 지표:** **Risk Reduction Score (RRS): 65/100**
    *   *(게이지는 Soft Coral/Red 영역에 위치)*
*   **상태 설명:** "현재 귀사의 사업 운영은 잠재적 리스크가 높은 상태입니다. 시스템 기반 분석을 통해 명확한 통제권 확보가 필요합니다." (불안정성 인식 강조)
*   **추천 액션 바:**
    1.  **[분석 시작]** $\rightarrow$ RRS 세부 진단으로 이동
    2.  **[솔루션 제안]** $\rightarrow$ 리스크 감소 전략 보기
    3.  **[시스템 업데이트]** $\rightarrow$ 최신 법규 반영 및 재분석

### B. 솔루션 상세 화면 (통제권 확보 강조)
**목표:** RRS에 따라 구체적인 '관리 전략'을 제시하여, 사용자가 무엇을 해야 할지 명확한 지침을 제공합니다.

*   **화면 헤드라인:** **당신의 리스크를 3단계로 통제하세요.**
*   **단계별 설명 (RRS 변화에 따른 색상 변화 시각화):**
    1.  **[Red Zone] 불안정성 인지:** 현재 상황을 명확히 인식하고, 가장 시급한 위험 요소를 식별합니다. *(Action: 즉시 리스크 진단)*
    2.  **[Gold Zone] 통제권 확보:** AI가 제안하는 최적의 법률/행정 전략을 확인하고 실행 계획을 수립합니다. *(Action: 맞춤형 솔루션 적용)*
    3.  **[Green Zone] 안정적 성장:** 실행 결과를 추적하며, 리스크를 효과적으로 관리하여 사업을 안정적으로 확장합니다. *(Action: 지속적인 모니터링 및 최적화)*
