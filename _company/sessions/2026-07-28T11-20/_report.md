### 📤 Task 4: 상세페이지 인쇄용 PDF 출력/내보내기 최적화 스크립트 작성
* D2C 브랜드 상세 기획 페이지를 외부 오픈마켓(쿠팡, 네이버 스마트스토어 등) 가로 860px 양식에 맞추어 이미지 깨짐 없이 하나의 PDF 파일로 내려받을 수 있도록 가이드하는 버튼 및 프린트 최적화 CSS 스타일 매칭을 추가하십시오.
