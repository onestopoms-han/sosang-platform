### 🖼️ 컴포넌트 상세 디자인 및 인터랙션 정의

#### 1. Dynamic Pricing Widget (동적 가격 계산 위젯)

이 위젯은 최종 가격(`calculatedPrice`)과 권위 레벨(`authorityLevel`)이 실시간으로 변하는 과정을 시각화하여, 고객에게 '선택에 따른 가치 변화'를 즉시 인지하게 만듭니다.

**레이아웃 및 구조:**

*   **컨테이너:** Midnight Navy 배경의 세련된 카드 형태로 디자인합니다. 모서리는 미세하게 둥글게 처리하여 고급스러움을 유지합니다.
*   **가격 표시 영역 (Core Price):** 가장 크고 명확하게 표시하며, 최종 가격(`calculatedPrice`)은 **Sovereign Gold** 색상으로 강조합니다.
    *   **표현 방식:** 기본 가격(Base Price)과 적용된 할인 로직(Discount Logic)을 함께 보여주되, 최종 가격이 중심이 되도록 설계합니다.
*   **권위 레벨 표시 (Authority Level):** `authorityLevel`('L1', 'L2', 'L3')을 시각적으로 표현하는 핵심 요소입니다.
    *   **표현 방식:** **Sovereign Gold** 색상의 게이지(Gauge) 또는 바(Bar) 형태로 구성합니다. L1이 가장 높은 권위 레벨임을 명확히 보여줍니다.
*   **동적 반응 (Interaction Logic):**
    *   사용자가 드롭다운 메뉴나 옵션을 변경할 때마다, `calculatedPrice`와 `authorityLevel` 게이지가 **부드럽게 애니메이션(Smooth Transition)** 되면서 재계산된 값으로 업데이트되어야 합니다.
    *   특히, 가격 변화 시 Gold 색상의 강조선이 움직이는 것을 통해 '시스템 통제권'의 변화를 역동적으로 표현합니다.

**예시 레이아웃 스케치 (Conceptual Layout):**

```
+------------------------------------------+
| [ Dynamic Pricing Widget ]              |
|                                          |
|   [ Base Price: ₩XXXXXX ] (회색)          |
|                                          |
|  [ Calculated Price: ₩YYYYY ] (골드 강조) | <-- 가장 눈에 띄는 최종 결과
|                                          |
|  --- Authority Level Gauge ---            |
|  [ L3 : 95% 통제권 ] (Gold 채움 바)        | <-- Gold 색상으로 진행률 표시
|                                          |
|  [ Risk Cost Impact: ₩XXX,XXX ] (청록색)   | <-- 잠재적 위험 비용을 보조적으로 표시
+------------------------------------------+
```

#### 2. Authority Level Gauge (권위 레벨 게이지)

이 컴포넌트는 사용자가 선택한 패키지가 부여하는 '시스템 통제권'의 정량화된 수준을 시각적으로 강조합니다. 이는 마케팅 메시지(권위 확보)를 디자인 언어로 번역하는 역할을 합니다.

**레이아웃 및 구조:**

*   **형태:** 원형 게이지(Circular Gauge) 또는 계층적 파이프라인 차트(Pipeline Chart) 형태를 채택하여, 데이터 중심의 전문성을 강화합니다.
*   **색상 사용:**
    *   배경: Midnight Navy.
    *   완료된 권위 레벨 구간: **Sovereign Gold**로 채워집니다.
    *   미달된 부분: 어두운 회색(Navy의 톤)으로 처리합니다.
*   **상호작용:**
    *   `authorityLevel`('L1', 'L2', 'L3')에 따라 게이지가 점진적으로 채워지거나, 특정 레벨이 활성화될 때 해당 영역 전체가 Gold로 변하며 **'권위의 획득'**을 명확하게 시각화합니다.
    *   마우스를 올리면(Hover) 각 레벨(`L1`~`L3`)에 대한 정량적인 설명(예: L1 = 최고 시스템 통제권 확보)이 툴팁으로 나타나도록 구성하여 교육적 요소를 추가합니다.

**핵심 비주얼 메시지:**
> "당신의 선택은 단순한 구매가 아닌, **시스템 통제권**을 획득하는 과학적 결정입니다."
