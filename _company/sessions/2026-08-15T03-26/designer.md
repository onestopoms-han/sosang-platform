# 📊 리스크 대시보드 & 핵심 컴포넌트: 데이터 비활성화 UI/UX 가이드라인 및 와이어프레임

## 1. 디자인 원칙 (Principle Guidelines) - 실패 상태 정의

데이터가 비활성화되거나 API 호출에 실패했을 때, 시스템은 **'실패'**가 아닌 **'현재 통제 불가(Uncertainty)'** 상태로 사용자에게 인식되어야 합니다.

### 1.1. 핵심 색상 및 상태 매핑 재확인 (Color Mapping Reconfirmation)

기존의 '데이터 기반 권위' 원칙을 실패 상태에 적용하여 시각적 언어를 확립합니다.

| 상태 | 디자인 용어 | 색상 시스템 | 사용자 메시지 톤앤매너 | 근거 |
| :--- | :--- | :--- | :--- | :--- |
| **안정 (Stable)** | 통제권 확보 (Control Achieved) | Deep Forest Green (`#1E8449`) | "현재 상태는 안정적입니다." | `designer_system_guide.md` 참조 |
| **경고 (Warning)** | 선제적 조치 필요 (Proactive Action Needed) | Amber (`#FFC300`) | "데이터 접근에 잠재적 제약이 있습니다. 즉각적인 검토가 필요합니다." | `designer_wireframe_update_risk.md` 참조 |
| **위험 (Critical)** | 통제권 상실 임박 (Imminent Loss of Control) | Red (`#D9534F`) | "데이터 접근이 차단되었습니다. 시스템 상태 점검이 필요합니다." | `designer_wireframe_update_risk.md` 참조 |
| **비활성화 (Unavailable)** | 정보 부재/시스템 경계 (Data Absence/Boundary) | Light Gray / Muted Blue (`#AAAAAA`) | "데이터를 불러오는 데 실패했습니다. 안전 기본값이 적용 중입니다." | 시스템 강건성 원칙 |

### 1.2. 타이포그래피 및 레이블 가이드라인

*   **핵심 지표 (Primary Metric):** 가장 큰 폰트 사이즈와 **Rich Gold** 색상으로 강조하여, 현재 통제 가능한 핵심 수치(예: Authority Flow Rate)를 명확히 표시합니다.
*   **상태 메시지 (Status Message):** 실패 시, 일반적인 에러 코드 대신 **Amber/Red** 색상을 사용하여 잠재적 위험을 즉각적으로 알립니다. 텍스트는 감정적이고 행동 지향적이어야 합니다.
    *   (예시) "데이터 연결 오류" $\rightarrow$ "**통제권 확보 경로 데이터 접근 불가**"
*   **근거 표시 (Evidence/Source):** 모든 상태 메시지 하단에는 시스템의 신뢰도를 보장하기 위해, 가장 작은 폰트(`font-size: 8px;`, `color: #AAAAAA`)로 해당 정보가 **'시스템 강건성'**에 기반함을 명시합니다.

## 2. 와이어프레임 제안 (Wireframe Proposal)

### 2.1. 리스크 대시보드 통합 상태 (Risk Dashboard Unified State)

**목표:** 사용자가 한눈에 현재 시스템의 '통제 상태'를 파악하고, 실패 시 다음 행동을 유도합니다.

| 영역 | 안정 상태 (Green) | 경고 상태 (Amber) | 위험 상태 (Red) |
| :--- | :--- | :--- | :--- |
| **상태 표시줄** | Deep Forest Green 배경, "시스템 통제권 확보됨" 텍스트 강조. | Amber 배경, "데이터 접근에 잠재적 제약" 텍스트 경고. | Red 배경, "중요 리스크: 데이터 연결 실패" 텍스트 긴급 알림. |
| **핵심 지표 (Authority Flow Rate)** | Rich Gold로 표시되며, 아래 시스템 지표(`시스템 통제권 확보율: XX%`)가 명확하게 표시됨. | 지표 자체가 Amber 색상으로 바뀌며, 하단에 '데이터 로딩 실패' 메시지 노출. | 지표는 Red로 변하며, **"데이터 비활성화 상태"** 경고 박스가 전체 영역을 덮음. |
| **액션 플랜 (Action Plan)** | "모니터링 유지" 버튼 활성화. | "**권한 확보 경로 재설정**" 또는 "**API 연결 확인**" 등의 구체적인 다음 행동 버튼 제시. | "**시스템 진단 모듈 실행**"을 최우선 CTA로 제시하여 내부 점검 유도. |
| **근거 표시** | 하단 우측에 회색으로 `(근거: ...)` 명시. | 하단 우측에 Amber로 `(근거: ...)` 명시. | 하단 우측에 Red로 `(근거: ...)` 명시. |

### 2.2. 핵심 컴포넌트: Authority Flow Rate 게이지 (Gauge Component) 실패 시

**목표:** 게이지 자체의 디자인은 유지하되, 데이터 부재 시 동적인 피드백을 제공합니다.

1.  **데이터 존재 시 (Normal State):**
    *   게이지는 Rich Gold 색상으로 채워지고, 시스템 지표(`Control Score: 98.5%`)가 명확히 표시됩니다.
2.  **API 실패/데이터 부재 시 (Failure State - Amber):**
    *   게이지의 배경은 **Amber**로 변경되며, 게이지 내부에는 중앙에 **'정보 부족' 아이콘** 또는 **물음표(?)**가 표시됩니다.
    *   텍스트는 "데이터 로딩 실패" 대신 "**잠재적 리스크: 데이터 미확보**"로 명시하고, 아래에 시스템 지표(`시스템 통제권 확보율: XX%`)를 비활성화된 회색 톤으로 표시합니다.
3.  **최악의 경우 (Critical State - Red):**
    *   게이지 전체가 **Red** 배경으로 채워지며, 게이지 중앙에는 시스템 메시지가 크게 표시됩니다.
    *   메시지: "**통제권 확보 경로 데이터 접근 불가.** 즉각적인 시스템 진단이 필요합니다."
    *   이 상태에서는 모든 상호작용 버튼은 비활성화되고, 오직 **'시스템 진단 모듈 실행'** 버튼만 활성화되어야 합니다.
