CEO의 지시사항을 바탕으로 'C등급 (Critical Risk)' 시나리오의 인터랙션 및 시각 디자인을 완성하겠습니다. 이는 단순한 경고를 넘어, 사용자에게 즉각적인 불안감과 긴급성을 전달하며, 개발된 API 스키마에 기반하여 구현 가능한 HUD(Head-Up Display) 시스템을 구축하는 데 중점을 둡니다.

이 작업은 기존의 '시스템 무결성' 컨셉(골드/블루/그린)을 유지하면서, 위기 상황에서 시각적 계층 구조를 극대화하는 방향으로 진행됩니다.

### 🌟 C등급 시나리오: HUD 디자인 및 감성 가이드

#### 1. 시각 시스템 정의 (Visual System Definition)
C등급 상태에서는 기존의 안정적인 'Growth Green'과 'Deep Blue' 색상을 보조적으로 사용하여, **골드(Gold)** 계열을 주된 경고 신호로 사용하여 긴급성을 강조합니다.

*   **주요 색상:** `#FFC72C` (골드 앰버)를 경고 및 임계점에 할당하여 시각적 위계를 최상단에 위치시킵니다.
*   **배경 상태:** 전체 UI는 미묘하게 어두운 블루 계열(Deep Blue의 변형)로 전환되어, 골드 알림이 더욱 돋보이도록 대비를 높입니다.

#### 2. HUD 인터랙션 및 시각 요소 설계 (Interaction & Visual Elements Design)
개발된 API 스키마(`Result_Section`, `Journey_Map` 등)와 연동될 수 있도록, 데이터 누락/오류 알림에 특화된 세 가지 핵심 HUD 모듈을 정의합니다.

**A. 실시간 데이터 누락/오류 알림 (Data Integrity Alert)**
*   **디자인:** 중앙 또는 주요 지표 옆에 떠오르는 얇고 날카로운 골드 라인 형태의 경고 박스.
*   **애니메이션:** 정지된 상태가 아닌, **미세한 진동(Subtle Pulse/Tremor)** 애니메이션을 적용하여 데이터의 불안정성을 시각적으로 표현합니다. (급박함 유발)
*   **텍스트 예시:** "데이터 불일치", "API 응답 지연"

**B. 임계점 초과 애니메이션 (Threshold Overload Animation)**
*   **디자인:** 특정 KPI가 위험 임계값(C등급)을 초과했을 때, 해당 지표의 시각적 바(Bar) 또는 그래프 라인이 **급격하게 붉은 골드 색상으로 채워지며** 경고 상태를 명확히 표시합니다.
*   **애니메이션:** 초기에는 느리게 진행되다가 임계점을 넘으면 짧은 시간 동안 **빠른 깜빡임(Rapid Flicker)** 효과를 주어 즉각적인 행동을 요구합니다.

**C. 시스템 오류 메시지 모달 (Critical Error Modal)**
*   **디자인:** 화면 중앙에 오버레이되는 모달 창. 배경은 어두운 블루 톤이며, 경고 내용은 골드 텍스트로 강조됩니다.
*   **구성 요소:**
    1.  **상태 표시:** 크고 선명한 'C등급 위험' 아이콘 (골드 색상).
    2.  **문제 진단:** 발생한 오류의 핵심 원인(예: "데이터 유입 실패")을 간결하게 제시.
    3.  **긴급 조치 버튼:** 가장 눈에 띄는 곳에 **"시스템 복구 시도" (Call to Action)** 버튼을 골드 배경으로 강조하여 배치합니다.

#### 3. 감성적 카피 가이드라인 (Emotional Copy Guidance)
카피는 '공포'가 아닌, '통제권을 되찾아야 한다'는 당위성을 부여해야 합니다.

| 단계 | 목표 감정 | 추천 카피 방향 (Pain $\rightarrow$ Control) | 예시 문구 (HUD 적용) |
| :--- | :--- | :--- | :--- |
| **Pain (불안 유발)** | 긴급성, 통제력 상실 | 현재 상태가 위험하며 즉각적인 조치가 필요함을 강조. | "경고: 시스템 무결성 위협" |
| **Control (해답 제시)** | 권위감, 행동 촉구 | 데이터 기반의 해결책이 이미 존재함을 암시하고 사용자에게 통제권을 부여. | "데이터 분석 대시보드 확인" |
| **Urgency (긴급 조치)** | 즉각성, 확신 | 시스템 복구를 위한 최소한의 행동을 명확히 지시. | "복구 시도 시작", "안정화 프로토콜 활성화" |

#### 4. API 스키마 기반 구현 가능성 검토
이 디자인은 다음과 같은 데이터 입력 및 출력에 직접적으로 매핑됩니다.
*   `status_code`: C등급 상태를 트리거하는 핵심 변수.
*   `error_details`: 알림 모달에 표시될 구체적인 원인 정보.
*   `system_integrity_score`: 위험도를 시각화하는 지표 (골드 게이지/바).
*   `action_required`: 사용자가 취해야 할 다음 단계 버튼의 동적 변화.
