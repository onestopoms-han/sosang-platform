## HS Code 82.01 (Hand tools) 법규 기반 Q&A 및 지식베이스 업데이트

### 1. 품목 분류의 최우선 기준 (Classification Priority)

**Q: HS 코드 82.01(수공구)에서 품목을 분류할 때 가장 우선해야 할 판단 기준은 무엇인가?**
**A:** **재료 구성이 아닌, 도구의 '용도 및 물리적 형태'를 최우선 판단 기준으로 삼아야 합니다.**

*   **핵심 원칙:** 도구가 어떤 재료로 만들어졌는지보다 해당 도구가 실제로 수행하는 기능(Function)과 그 물리적인 구조(Form)가 분류의 핵심 기준이 됩니다.
*   **목표:** 실제 현장 적용성을 극대화하고, 시스템이 '물리적 상태'를 기반으로 예측적 통제력을 확보하도록 합니다.

### 3. 명확한 예외 처리 로직 (Exclusions) - 경고/필터링 모듈

**Q: HS Code 82.01 분류에서 제외되어야 하는 품목 및 관련 코드(Exclusions a~e)는 무엇인가?**
**A:** 다음 항목들은 수공구 분류에 포함되지 않으며, 별도의 경고 또는 필터링 모듈로 분리하여 관리해야 합니다.

| 구분 | 제외 품목 (HS Code) | 설명 및 참고 사항 |
| :--- | :--- | :--- |
| **(a)** | 82.03 (Sheep ear and other animal marking pliers) | 양털 또는 기타 동물 표식용 플라이어류는 본 분류에서 제외됩니다. |
| **(b)** | 82.05 (Road or stone splitting wedges; scythe blade trueing anvils) | 도로 또는 돌 분리용 쐐기, 낫날 정렬 받침대 등은 제외됩니다. |
| **(c)** | 82.11 (Pruning knives) | 전정용 칼류는 본 분류에서 제외됩니다. |
| **(d)** | Chapter 84 (Garden rollers, harrows, hay or grass mowers and similar implements) | 손으로 밀거나 당기는 형태의 잔디 롤러, 쟁기, 건초나 풀 깎는 기계 등은 별도 장(Chapter 84)으로 분류됩니다. |
| **(e)** | 95.06 (Ice axes) | 얼음 도끼류는 본 분류에서 제외되며, 별도의 HS 코드를 따릅니다. |
