# 📊 SSI 인터랙티브 컴포넌트 디자인 시스템 명세서 (Design Spec v1.0)

## 1. 컴포넌트 개요
**컴포넌트 명:** System Stability Index (SSI) Visualization
**목표:** 사용자가 '불안정성 $\rightarrow$ 통제권 확보 경험(Convergence) $\rightarrow$ 안정(안착)'의 여정을 시각적으로 체험하도록 하여, 데이터 기반 성장 컨설팅의 가치를 전달한다.
**핵심 원칙:** 시각적 강조(Rich Gold)는 단순한 미학이 아닌 **과학적 근거(데이터)**에 기반함을 명확히 한다.

## 2. 디자인 시스템 참조
| 요소 | 정의 | 사용 색상/스타일 | 근거 |
| :--- | :--- | :--- | :--- |
| **Primary Color** | 배경 및 기본 구조 | Deep Blue (`#004D66`) | 브랜드 정체성 |
| **Accent Color** | 통제권 확보 경험 강조 | Rich Gold (`#FFD700` 계열) | 데이터 기반 권위, 시스템 지표 |
| **Secondary Color** | 성장 및 안정 상태 표현 | Growth Green (`#3CB371`) | 긍정적 변화, 안정 상태 |
| **Text/Label** | 시스템 지표 설명 | Light Gray / Small Font | 과학적 근거 명시 |

## 3. 인터랙션 및 시각적 상태 흐름 (Interaction & Visual States)

SSI 컴포넌트는 사용자가 데이터의 여정을 따라가며 '통제권'을 확보하는 과정을 경험하도록 설계됩니다. 전체 과정은 **5단계**로 구성되며, 각 단계는 특정 색상 변화와 애니메이션으로 표현됩니다.

### 3.1. 초기 상태 (Initial State: 불안정성)
*   **레이블:** `불안정 상태 (Instability)`
*   **시각적 표현:** 전체 바(Bar) 또는 게이지는 **Deep Blue**를 기본 배경으로 하며, SSI 값은 낮은 수치(예: 0% ~ 20%)로 표시됩니다.
*   **색상 강조:** 변화 없음. 시스템의 불안정성을 나타냄.
*   **텍스트 강조:** `Control Score: XX%` (골드 색상 강조) 아래에 작은 폰트로 **시스템 지표 설명: 불안정성 구간**을 명시합니다.

### 3.2. 데이터 탐색 상태 (Hover State: 수렴 과정 시작)
*   **Interaction:** 사용자가 게이지 위로 마우스를 올리거나(Hover), 해당 섹션을 클릭할 때(Click).
*   **애니메이션 흐름:** 전체 시각화 영역이 부드럽게 확장되며, 내부 데이터 라인(Data Line)이 **Deep Blue에서 Growth Green으로 서서히 전환**됩니다.
*   **색상 강조:** Transition 중인 구간은 **Growth Green**을 점진적으로 채워나가며 변화를 시각화합니다.
*   **텍스트 강조:** `Control Score: XX%` (골드 색상)가 더 밝게 빛나며, 시스템 지표 설명이 '수렴 과정'임을 암시합니다.

### 3.3. 중간 상태 (Mid-State: 통제권 확보 시점)
*   **레이블:** `통제권 확보 구간 (Convergence)`
*   **시각적 표현:** 게이지의 중앙부 또는 특정 지점에서 **Rich Gold 색상**이 가장 강하게 발현됩니다. 이 부분은 사용자가 현재 시스템을 '인지'하고 '통제할 수 있는 잠재력'이 있음을 상징합니다.
*   **애니메이션 흐름:** 데이터 라인은 Green에서 Gold로 명확하게 전환되며, 이 구간에 멈춤(Pause) 또는 강조 효과가 적용됩니다.
*   **텍스트 강조:** `Control Score: XX%` (골드 색상 최대치)를 가장 크게 표시하고, 시스템 지표 설명은 **'통제권 확보'**로 명시합니다.

### 3.4. 최종 상태 (Final State: 안정/안착)
*   **레이블:** `시스템 안착 (Stabilization)`
*   **시각적 표현:** 전체 시각화 영역이 **Growth Green**으로 완전히 채워지며, 게이지가 최대치(100%)에 도달합니다.
*   **색상 강조:** 전체 배경과 진행 상태는 안정적인 **Growth Green**을 사용합니다.
*   **텍스트 강조:** `Control Score: 100%` (골드 색상)를 명확히 표시하고, 시스템 지표 설명은 **'완벽한 안착 및 통제권 확보'**로 마무리합니다.

## 4. 최종 컴포넌트 구조 (Component Structure Blueprint)

| 영역 | 디자인 요소 | 적용 스타일/색상 | 기능/목적 |
| :--- | :--- | :--- | :--- |
| **Header** | `Control Score: XX%` | Rich Gold (가장 크게), 아래에 작은 폰트로 시스템 지표 설명 | 핵심 결과값 및 권위 강조 |
| **Visualization Bar** | 전체 진행 바 | Deep Blue $\rightarrow$ Growth Green $\rightarrow$ Rich Gold | 데이터의 변화 여정 시각화 |
| **Data Line** | 실제 데이터 라인 | 동적 색상 전환 (Blue $\rightarrow$ Green $\rightarrow$ Gold) | 상호작용에 따른 흐름 명시 |
| **Status Label** | 상태 레이블 | 5단계별 명확한 텍스트 (`불안정` / `수렴` / `안착`) | 사용자 여정 단계 안내 |
