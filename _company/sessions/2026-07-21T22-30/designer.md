# 💎 참송이 골드 상세페이지 디자인 가이드 (Visual & Wireframe Specification)

## 1. 디자인 시스템 정의 (Visual System Definition)

| 요소 | 설정 값 | 설명 |
| :--- | :--- | :--- |
| **주요 색상 (Primary)** | Midnight Navy (`#0A1931`) | 신뢰감, 깊이, 권위의 기반 색상. 배경 및 주요 텍스트에 사용. |
| **보조 색상 (Accent)** | Sovereign Gold (`#C9B03D`) | 프리미엄, 가치, 통제권을 상징하는 강조색. CTA 버튼, 핵심 수치, 경계선에 사용. |
| **배경 색상** | Deep Charcoal/Navy Gradient | 섹션 전환 시 미묘한 깊이감을 주기 위해 짙은 네이비에서 어두운 차콜로의 부드러운 그라데이션 적용. |
| **타이포그래피 (Heading)** | Serif 계열 (예: Playfair Display, Baskerville) | 권위와 클래식함을 부여하여 전문성을 강조. |
| **타이포그래피 (Body)** | Sans-Serif 계열 (예: Montserrat, Inter) | 가독성과 현대적인 과학적 느낌을 제공. |
| **레이아웃 원칙** | 7.0:1 명암비 준수 | 미니멀하고 깊이감 있는 이미지를 통해 '고급 시스템' 경험 극대화. |

## 2. 섹션별 와이어프레임 및 비주얼 상세 (Section-by-Section Wireframe)

### SECTION 1: 문제 제기 (Pain Point) - '불안정성'과 '통제력 상실'에 대한 공감 유도

**목표:** 고객의 현재 상태(시스템 불균형)를 직관적으로 인식시켜 불안감을 증폭시킨 후, 해결책에 대한 갈망을 심어줍니다.

| 레이아웃 요소 | 시각 자료 요구 사항 (Visual Asset Requirement) | 디자인 지시사항 (Design Instruction) |
| :--- | :--- | :--- |
| **1.1 도입부 헤드라인** | 배경: Midnight Navy의 깊은 단색. Gold 텍스트 강조. | 중앙 정렬. 폰트 크기 최대화하여 시선을 즉시 사로잡음. |
| **1.2 핵심 Pain Point 서술 (Body Copy)** | **이미지:** 추상적인 데이터/흐름을 표현하는 미세한 노이즈 또는 불규칙한 패턴의 배경 오버레이. | 텍스트는 중앙에 배치하되, 주변 여백(Padding)을 극대화하여 '고립감'과 '혼란'을 시각적으로 연출. |
| **1.3 통제력 상실 강조** | **인포그래픽:** '균형이 깨진 시스템'을 상징하는 미니멀한 그래프 또는 파동 패턴(불규칙한 선). | 이 섹션에서 Gold 색상을 사용하여 불안정성의 정도를 시각화 (예: 불균형 지점 표시). |

### SECTION 2: 솔루션 제시 (Solution) - '시스템 관리자 경험'의 도입

**목표:** 참송이 골드가 단순한 영양이 아닌, 시스템을 통제하는 핵심 인프라임을 권위적으로 제시합니다.

| 레이아웃 요소 | 시각 자료 요구 사항 (Visual Asset Requirement) | 디자인 지시사항 (Design Instruction) |
| :--- | :--- | :--- |
| **2.1 솔루션 소개 (The Reveal)** | **이미지:** Midnight Navy 배경 위에 Sovereign Gold로 빛나는 참송이 골드 이미지의 고화질 클로즈업 샷 (빛과 그림자 강조). | 대비를 극대화하여 제품 자체에 '권위'와 '고급스러움'을 부여. |
| **2.2 참송이 골드의 역할 (The Role)** | **인포그래픽:** '장-뇌 축(Gut-Brain Axis)'의 개념을 시각적으로 표현하는 깔끔한 연결 다이어그램. | 각 연결 고리(Node)는 Navy 색상으로, 핵심 통제 영역은 Gold로 강조하여 시스템적 이해도를 높임. |
| **2.3 시스템적 통제권 강조** | **와이어프레임:** L2 $\rightarrow$ L3 전환 경험을 시각화하는 단계별 플로우차트 또는 슬라이더 디자인. | 사용자 상호작용(Interaction)에 초점을 맞추어, 고객이 '관리자'가 되는 과정을 단계적으로 보여줌. |

## 3. 최종 비주얼 가이드 (Final Visual Guide Summary)

1.  **컬러 적용:** 모든 주요 섹션은 Midnight Navy 배경을 사용하고, 핵심 정보 및 CTA는 Sovereign Gold로만 강조하여 시각적 위계를 설정합니다.
2.  **이미지 품질:** 모든 제품 사진(참송이 골드)은 극도로 클로즈업되고 질감이 살아있는 **고해상도 마크로 샷**을 사용하며, 인공적인 조명과 깊은 그림자를 활용하여 '프리미엄' 느낌을 강화합니다.
3.  **아이콘 시스템:** 모든 기능 설명에는 단순하고 기하학적인(Geometric) 라인 아이콘 세트를 사용하여 과학적이고 정돈된 느낌을 유지합니다.
