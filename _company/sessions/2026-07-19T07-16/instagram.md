### 🎬 Script 1: 에너지/피로 집중 (미토콘드리아 최적화)

**핵심 메시지:** 만성 피로의 근본 원인은 세포 내 에너지 공장의 비효율이다.
**타겟 감정:** 지침, 에너지 부족에 대한 갈망, 과학적 해결책에 대한 기대.

| 항목 | 상세 내용 |
| :--- | :--- |
| **최적 게시 시간대 제안** | 평일 오전 8시 ~ 10시 (출근 준비 및 활력 필요 시점) 또는 저녁 7시 ~ 9시 (하루를 정리하고 회복할 때) |
| **필수 해시태그 세트 3개** | 1. `#미토콘드리아최적화` (전문성 강조) / 2. `#만성피로해결` (문제 해결 집중) / 3. `#에너지생체시스템` (솔루션 포지셔닝) |
| **구체적인 장면 전환 지시 (Shot List)** | **[0-2초]** 어둡고 흐릿한 톤의 클로즈업 (피곤함 표현). 화면 중앙에 붉은색 '경고' 오버레이. **[2-5초]** 빠르게 화면이 전환되며, 미토콘드리아 애니메이션 또는 세포 내 에너지 흐름을 시각화하는 고해상도 다이어그램 등장. **[5-9초]** 송이버섯의 질감이 Deep Blue/Growth Green 색감으로 강조되며, 활력이 느껴지는 역동적인 움직임으로 전환. **[9-13초]** 사용자가 활기차게 활동하는 모습(운동, 업무 집중)과 함께 제품이 배치되어 '시스템 주권 확보'를 시각적으로 제시. |
| **캡션 방향성 (예시)** | "혹시 매일 아침, 잠을 자도 지치나요? 당신의 에너지는 고장났습니다! 🚨 만성 피로는 단순한 피로가 아닙니다. 그것은 세포 내 에너지 공장인 미토콘드리아의 비효율에서 시작됩니다. 균주바이오컴버젼 송이버섯은 이 시스템을 최적화하여 진정한 활력을 되찾아 드립니다. #에너지생체시스템" |

### 🎬 Script 2: 정신/인지 집중 (장-뇌 축)

**핵심 메시지:** 장 건강이 인지 기능과 기분에 직접적인 영향을 미친다.
**타겟 감정:** 혼란, 집중력 저하에 대한 답답함, 명확한 연결고리에 대한 이해.

| 항목 | 상세 내용 |
| :--- | :--- |
| **최적 게시 시간대 제안** | 평일 점심시간 직후 (오후 1시 ~ 2시) 또는 저녁 식사 후 (소화 및 휴식과 연관 지어 설명 시) |
| **필수 해시태그 세트 3개** | 1. `#장뇌축` (핵심 과학 용어) / 2. `#인지기능향상` (결과 중심) / 3. `#마인드풀니스식사` (행동 유도) |
| **구체적인 장면 전환 지시 (Shot List)** | **[0-2초]** 복잡한 생각이나 스트레스로 인해 머릿속이 흐릿해지는 모션 그래픽 또는 인물의 혼란스러운 표정 클로즈업. 화면에 '집중력 저하' 경고 표시. **[2-5초]** 장(Gut)과 뇌(Brain)가 연결되는 신경 경로를 시각적으로 표현하는 깔끔한 인포그래픽. **[5-9초]** 건강한 장내 미생물 환경을 상징하는 밝고 안정적인 녹색/파란색의 움직임 강조. **[9-13초]** 명료하고 맑은 정신으로 집중하며 업무를 처리하거나 편안하게 웃는 인물의 모습. 제품이 이 '균형'을 제공한다는 점을 부드럽게 암시. |
| **캡션 방향성 (예시)** | "집중력이 흐려지고 감정 기복이 심하다면, 당신의 문제는 장에 있습니다. 🧠✨ 장-뇌 축은 우리가 생각하는 것보다 훨씬 깊게 연결되어 있습니다. 건강한 장내 환경이야말로 맑은 정신과 최고의 인지 기능을 위한 첫걸음입니다. 송이버섯이 이 균형을 잡아드립니다. #장뇌축" |

### 🎬 Script 3: [추가 제안] 시스템 안정화 (권위 및 솔루션 강조)

**핵심 메시지:** 단순한 영양이 아닌, 과학적 시스템 관리 솔루션이다.
**타겟 감정:** 권위에 대한 갈망, 시스템에 대한 통제력 확보 욕구.

| 항목 | 상세 내용 |
| :--- | :--- |
| **최적 게시 시간대 제안** | 주말 오전 (심층적인 정보 습득 시간) |
| **필수 해시태그 세트 3개** | 1. `#생체시스템관리` (고급 포지셔닝) / 2. `#과학적근거` (권위 강조) / 3. `#프리미엄건강식품` (가치 포지셔닝) |
| **구체적인 장면 전환 지시 (Shot List)** | **[0-2초]** 매우 세련되고 차분한 분위기. Deep Blue/Growth Green의 미니멀한 디자인 배경 위로 '시스템 주권 확보'라는 문구가 묵직하게 등장. **[2-5초]** 데이터 시각화 프레임워크(골드 앰버 $\rightarrow$ 과학적 원리 제시 $\rightarrow$ 성장 그린 안정화)를 빠르게 보여주며, 복잡한 데이터를 단순하고 명확하게 정리하는 과정을 애니메이션으로 표현. **[5-9초]** 송이버섯이 이 '시스템 관리'의 핵심 요소임을 강조하며, 자연과 과학이 결합된 고급스러운 비주얼 연출. **[9-13초]** 최종적으로 제품을 보며 확신에 찬 표정으로 카메라를 응시하는 모습 (권위 확보). |
| **캡션 방향성 (예시)** | "단순한 영양제를 넘어, 당신의 생체 시스템을 관리하는 솔루션. 미토콘드리아 최적화부터 장-뇌 축 균형까지, 과학적 논리를 증명하는 바이오컴버젼 송이버섯이 제공하는 '시스템 주권 확보 경험'을 만나보세요. 🔬👑" |
