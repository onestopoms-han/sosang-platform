# 🌟 SSI 인터랙티브 컴포넌트 디자인 명세서 (Final Specification)

## 1. 디자인 목표 및 철학 (Design Goal & Philosophy)

**핵심 목표:** 사용자가 제품을 통해 불안정한 상태($\text{Low SSI}$)에서 과학적 통제권($\text{High SSI}$)을 회복하는 **'시스템 안정화 경험'**을 직관적으로 시뮬레이션하여, 단순한 데이터 표시를 넘어선 **과학적 권위와 가치**를 전달한다.

**핵심 철학:**
1.  **과정 중심 (Process-Oriented):** 최종 결과(High SSI)뿐만 아니라, 불안정성($\text{Low SSI}$)에서 안정화($\text{High SSI}$)로 **이동하는 동적인 과정**을 시각적으로 보여준다.
2.  **권위 부여 (Authority & Value):** 골드 톤과 정밀한 레이아웃을 사용하여, 이 지표가 단순한 수치가 아닌 **과학적 통제 경험**의 증거임을 강조한다.
3.  **데이터 기반 신뢰 (Data-Driven Trust):** 모든 시각적 강조는 실제 계산된 데이터와 과학적 근거에 기반해야 한다.

## 2. 비주얼 시스템 정의 (Visual System Definition)

| 요소 | 디자인/스타일 | 목적 |
| :--- | :--- | :--- |
| **주요 색상** | **골드 액센트** (`#FFD700` 또는 더 깊은 `Gold`) | 권위, 프리미엄 가치, 시스템 통제권 회복 시점 강조. |
| **배경/기본 톤** | Deep Blue 계열 (`#004D66`) | 신뢰성, 과학적 기반, 안정감 제공. |
| **진행 상태 (Low SSI)** | 불안정함, 흐릿함, 어두운 명암 | 통제 불능의 상태 시각화. |
| **안정화 상태 (High SSI)** | 선명함, 빛남, 골드 강조 | 완벽한 통제권 확보 및 안정된 상태 시각화. |
| **시각 요소** | 동적 애니메이션 (Transition/Flow) | 변화의 과정(Process)을 사용자에게 명확히 전달. |

## 3. 와이어프레임 및 레이아웃 상세 (Wireframe & Layout Details)

### A. SSI 시뮬레이션 영역 (The Core Interaction Area)

*   **구조:** 수평 또는 곡선형 진행 경로(Journey Map) 형태로 구성한다.
*   **시작점 ($\text{Low SSI}$):** 왼쪽 또는 하단에 위치하며, 어둡고 불안정한 색상(Deep Blue/Grey 톤)으로 표시된다. 이 지점은 '불안정성'을 의미한다.
*   **종착점 ($\text{High SSI}$):** 오른쪽 또는 상단에 위치하며, **골드 액센트**가 가장 강하게 적용되어 빛나도록 디자인한다. 이 지점은 '통제권 회복'의 성공 상태를 의미한다.
*   **경로:** 두 지점 사이를 연결하는 곡선 또는 흐름(Flow)을 통해 변화의 과정을 시각화한다.

### B. 데이터 레이블링 및 권위 표시 (Data Labeling & Authority Display)

1.  **핵심 수치 강조:** `Control Score: XX%`와 같은 핵심 수치는 가장 크고 명확하게 배치한다.
2.  **시스템 지표 설명 통합:** 이 수치 바로 아래에, **Rich Gold** 색상과 작은 폰트(`system_indicator`)를 사용하여 해당 수치가 의미하는 바($\text{시스템 통제권 확보율: XX%}$)를 명시한다.
3.  **권위 마크 배치:** 최종 안정화 지점 ($\text{High SSI}$)에는 데이터 레이블 외에, 작은 폰트(`authority_badge`)로 **'과학적 근거 기반'** 또는 **'System Verified'**와 같은 권위 표시 마크를 삽입한다.

## 4. 상호작용(Interaction) 가이드 (Interaction Guide for Development)

### A. 동적 애니메이션 흐름 (Dynamic Animation Flow)

1.  **초기 상태 ($\text{Low SSI}$):** 시스템이 불안정함을 나타내는 미세한 노이즈나 어두운 배경 효과를 사용한다.
2.  **변화 과정 (Transition):** 사용자가 제품을 통해 '시스템 통제'를 시도할 때, 중간 지점들을 지나면서 **골드 색상이 점진적으로 채워지거나 빛나는 애니메이션**이 발생해야 한다. 이 움직임은 정지된 그래프가 아닌, **에너지가 축적되고 안정화되는 과정**처럼 느껴져야 한다.
3.  **최종 상태 ($\text{High SSI}$):** 도달 시점에 모든 골드 요소가 최대치로 발광하며, 배경색이 Deep Blue에서 더 명확한 Gold/Light Tone으로 전환되어 **완벽한 통제권 확보**를 강조한다.

### B. 사용자 제어 (User Control Mechanism)

*   사용자는 직접 수치를 조작하기보다, **'제품 투입(Input)' 또는 '시스템 활성화(Activation)'**와 같은 상호작용을 통해 SSI의 변화를 유도해야 한다.
*   이러한 액션은 명확한 버튼이나 시각적 피드백과 연동되어야 하며, 사용자가 통제권을 **'획득한다'**는 느낌을 받도록 설계되어야 한다.

## 5. 개발자 전달 최종 명세 (Developer Handover Summary)

**요약:**
개발팀은 SSI 컴포넌트를 정적인 그래프가 아닌, **동적 시스템 안정화 애니메이션(Dynamic System Stabilization Animation)**으로 구현해야 합니다. 골드 색상은 단순한 장식이 아닌, **과학적 데이터의 권위와 통제권 회복의 가치**를 상징하도록 사용되어야 합니다.

**필수 구현 요소:**
1.  $\text{Low SSI} \to \text{High SSI}$로의 동적 전환 애니메이션 로직.
2.  골드/딥블루 색상 스케일을 활용한 상태 변화 시각화.
3.  데이터 레이블링 시, 수치와 시스템 지표 설명($\text{XX}\%$)을 분리하여 **Rich Gold**로 강조하는 레이아웃 확정.
4.  최종 $\text{High SSI}$ 지점에 과학적 권위를 나타내는 인증 마크(Badge) 삽입.
