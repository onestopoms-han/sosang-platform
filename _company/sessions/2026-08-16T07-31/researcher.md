# 📜 Actionable Blueprint를 위한 핵심 규제 지표(KPI) 및 로직 정의서

## 🎯 최종 확정 KPI (3가지)

Actionable Blueprint의 성공적인 실행과 사용자 불안 해소를 위해, 재무적 손실과 심리적 불안정성을 법적/행정적 대응으로 연결하는 다음 3가지 핵심 규제 지표를 확정합니다.

1.  **Compliance Score (규제 준수 점수)**
2.  **Actionable Gap Index (실행 격차 지수)**
3.  **Risk-to-Action Ratio (위험-조치 비율)**

---

## 📝 KPI 상세 정의 및 로직 정의서

### 1. Compliance Score (규제 준수 점수)

**목표:** 시스템이 현재 법적/행정적 요구사항 대비 얼마나 안전한 상태인지를 정량화합니다. (핵심 가치: 규제 준수를 통한 법적 안정성 확보)

| 항목 | 정의 | 측정 기준 | 변화 로직 (예시) |
| :--- | :--- | :--- | :--- |
| **점수 범위** | 0점 (최대 위험) $\sim$ 100점 (완전 준수) | 내부 법규, 세무, 행정 보고서의 충족도 및 실시간 모니터링 데이터 기반 | **[로직]**: 각 규제 영역(세금, 인허가, 노동법 등)별 점수를 가중 평균하여 산출. 특정 핵심 위험 항목(예: 미납 세금 발생 시)은 즉시 0점으로 하향 조정되어야 함. |
| **상황별 변화 로직** | **Critical (위기)** | Score $\le 30$점: 즉각적인 법적 조치 필요. 시스템이 '경고'가 아닌 '최우선 실행 경로'를 제시해야 함. | **[예시]**: Compliance Score가 30점 이하로 하락 시, 시스템은 자동적으로 관련 법규 위반에 대한 **"법적 고지 문구의 필수 노출 범위 및 내용"**을 즉시 활성화하고 최상단에 표시한다. (Pain $\rightarrow$ Control 전환) |
| **감성 연동 로직** | **Normal/Warning** | Score $31 \sim 70$점: 선제적 조치 권고 단계. 심리적 안정감을 제공하는 언어 사용. | **[예시]**: Warning 상태에서는 "현재 상황은 통제 가능합니다"라는 메시지를 중심으로, 다음 실행 단계(Actionable Blueprint)를 제시하여 불안정성(Anxiety)을 감소시킨다. |

### 2. Actionable Gap Index (실행 격차 지수)

**목표:** 현재의 리스크 상태와 목표 달성을 위해 사용자가 취해야 할 구체적인 실행 단계(Blueprint)까지의 거리를 측정합니다. (핵심 가치: 행동 가능한 실행 계획 확보)

| 항목 | 정의 | 측정 기준 | 변화 로직 (예시) |
| :--- | :--- | :--- | :--- |
| **지표 범위** | 0% (완벽한 실행 경로) $\sim$ 100% (최대 격차) | 현재 시스템 상태와 목표 달성에 필요한 다음 단계(Task)의 수 및 복잡도. | **[로직]**: Gap Index는 '필요 조치 항목 수'와 '해당 조치의 법적/행정적 복잡성 가중치'를 기반으로 산출. |
| **상황별 변화 로직** | **High Gap (실행 필요)** | Gap Index $> 60$%: 단순 경고를 넘어 구체적인 실행 단계(Actionable Blueprint)가 즉시 요구됨. | **[예시]**: Gap Index가 높을 경우, 시스템은 법적 위험 예측 정보와 함께 **'단계별 실행 가이드'**를 제시한다. (인지 부하 이론 적용: 복잡한 정보를 단순화하여 다음 행동으로의 전환 효율 극대화) |
| **감성 연동 로직** | **Low Gap (안정 상태)** | Gap Index $\le 20$%: 시스템이 안정적으로 관리 중임을 확인시켜 불안감을 해소함. | **[예시]**: Low Gap 상태에서는 '시스템이 안전하게 통제하고 있다'는 메시지를 통해 사용자의 심리적 안정감(Relief)을 제공한다. |

### 3. Risk-to-Action Ratio (위험-조치 비율)

**목표:** 발생 가능한 법적/행정적 위험의 크기 대비, 시스템이 제시하는 실행 계획의 구체성과 실현 가능성을 비교하여 조치의 시급성과 효율성을 판단합니다. (핵심 가치: 예측 중심 $\rightarrow$ 실행 중심 전환)

| 항목 | 정의 | 측정 기준 | 변화 로직 (예시) |
| :--- | :--- | :--- | :--- |
| **지표 범위** | 1:100 (매우 낮음) $\sim$ 100:1 (매우 높음) | 잠재적 법적 손실 규모(Risk Magnitude) 대비, Actionable Blueprint의 구체적인 실행 경로(Actionability)의 명확성. | **[로직]**: $\text{Ratio} = \frac{\text{잠재 위험 값}}{\text{Action Plan 복잡도/구체성 점수}}$ |
| **상황별 변화 로직** | **High Ratio (긴급 조치)** | Ratio $> 50:1$: 위험이 크고, 실행 경로가 모호할 때. 시스템은 즉각적인 개입을 요구함. | **[예시]**: Risk-to-Action Ratio가 높을 경우, 법률 전문가 연결이나 긴급 행정 절차 시작과 같은 **'최소 행동 단위(Minimum Action Unit)'**를 우선적으로 제시한다. (실행 중심 강조) |
| **감성 연동 로직** | **Balanced (관리 상태)** | Ratio $10:1 \sim 50:1$: 위험에 대한 이해와 통제권 확보의 균형이 잡힐 때. | **[예시]**: 이 구간에서는 '예측 중심(Predictive Focus)' 정보 제공과 함께, 사용자가 스스로 결정을 내릴 수 있는 충분한 정보를 제공하여 심리적 자율성을 보장한다. |
