## 📄 랜딩 페이지 와이어프레임 상세 (System Sovereignty Focus)

### 1. 헤드라인 및 히어로 섹션 (Hero Section: Maximum Impact)
**목표:** 즉각적인 불안감(Threat)을 유발하고, 시스템 주권에 대한 해답임을 선언한다.

| 영역 | 구성 요소 | 디자인 지침 (Visual Direction) | 카피 적용 |
| :--- | :--- | :--- | :--- |
| **배경** | 고해상도 이미지/영상 배경 | 어둡고 깊은 포레스트 그린 (#1E4D2B 계열), 미세한 입자(Particle) 또는 물방울 애니메이션을 사용하여 생체 시스템의 복잡성을 암시. | - |
| **H1 (메인 헤드라인)** | 중앙 배치, 최대 크기 | 산세리프체 (예: Montserrat Bold 또는 Inter Black). 흰색/밝은 골드 텍스트. 위협감을 극대화하기 위해 굵고 명료하게 처리. | **당신의 몸은 통제 불능 상태인가? 뇌와 장의 시스템 주권을 되찾는 유일한 방법.** |
| **H2 (서브 헤드라인)** | H1 바로 아래, 중간 크기 | 약간 더 얇은 서체. 과학적 권위를 부여하는 깔끔한 폰트 사용. | 단순한 영양 공급이 아닌, 미생물 기반 생체 시스템을 진단하고 관리하는 과학적 방법론을 경험하세요. |
| **핵심 후크 (Micro-Hook)** | H2 아래 강조 박스 | 배경색: Amber Zone(`#FFC107`). 🚨 아이콘 사용. | **🚨 경고: 당신이 모르는 사이, 장-뇌 축은 이미 불안정한 상태입니다.** |
| **CTA 버튼** | 중앙 배치, 가장 눈에 띄게 | CTA 색상: Deep Gold 또는 Red Accent. 버튼은 클릭 시 시스템 진단 화면으로 즉시 이동하도록 유도. | **시스템 진단 시작하기 (Red Zone 탈출)** |

### 2. 문제 정의 섹션 (Problem Definition: Deepening the Threat)
**목표:** 사용자의 모호한 불편함을 과학적 실패로 명명하여 공감과 절박함을 극대화한다.

| 영역 | 구성 요소 | 디자인 지침 (Visual Direction) | 카피 적용 |
| :--- | :--- | :--- | :--- |
| **섹션 제목** | 좌측 또는 중앙 배치 | 강렬한 톤의 서체. '시스템 실패'를 강조하는 시각적 메타포 사용. | **당신의 활력은 어디로 새고 있는가? (시스템의 균형 상실)** |
| **본문 구성** | 2단 레이아웃 (텍스트 + 시각적 비유) | 왼쪽: 텍스트, 오른쪽: 관련된 미생물/뇌 연결 구조의 추상적인 일러스트레이션 목업. | **[Threat]** 현대인의 스트레스와 불규칙한 식단 속에서, 우리 몸 내부의 미생물 환경(마이크로바이옴)은 지속적으로 교란되고 있습니다. 이 불균형은 단순히 피로가 아니라, 인지 능력 저하와 만성 염증이라는 **시스템 붕괴**를 의미합니다. |
| **원리 제시** | 강조 박스 (Callout Box) | 배경색: Light Blue 또는 Teal 계열. 핵심 원리를 명확하게 분리하여 권위를 부여. | **[Principle]** 장-뇌 축의 연결고리는 당신의 집중력, 활력, 심지어 감정 조절 능력까지 결정합니다. 이 시스템이 무너지면, 아무리 좋은 음식을 섭취해도 진정한 '시스템 주권'은 확보되지 않습니다. |

### 3. 핵심 솔루션 및 방법론 소개 (The System & Methodology)
**목표:** 제품이 단순한 버섯이 아니라 '관리 시스템'임을 명확히 제시한다.

| 영역 | 구성 요소 | 디자인 지침 (Visual Direction) | 내용 구성 예시 |
| :--- | :--- | :--- | :--- |
| **섹션 제목** | 중앙 강조 | 기능적이고 구조적인 느낌을 주는 타이포그래피 사용. | **균주바이오컴버젼: 생체 시스템 관리의 3단계 방법론** |
| **방법론 시각화** | 3단 카드 또는 순환 다이어그램 | 각 단계(진단 $\rightarrow$ 관리 $\rightarrow$ 최적화)를 명확한 화살표와 연결선으로 표시. 각 단계는 아이콘과 함께 배치. | 1단계: 시스템 진단 (Diagnosis) / 2단계: 미생물 관리 (Management) / 3단계: 생체 최적화 (Optimization) |
| **신뢰 구축** | 과학적 근거 제시 | '미토콘드리아 기능 저하'와 같은 핵심 키워드를 인용하여, 데이터에 기반한 접근임을 강조. | 각 단계별로 사용되는 미생물/대사 경로의 간략한 다이어그램을 삽입. |

---

### 4. KPI 진단 및 인터랙티브 대시보드 (The Interactive Core)
**목표:** 사용자에게 현재 상태에 대한 **위협 레벨(Threat Level)**을 즉각적으로 인지시키고, 솔루션의 필요성을 극대화한다. (가장 중요한 섹션)

| 영역 | 구성 요소 | 디자인 지침 (Visual Direction) | 인터랙티브 구현 가이드 |
| :--- | :--- | :--- | :--- |
| **섹션 제목** | 중앙 배치 | 명확하고 행동을 요구하는 제목. | **당신의 시스템 현재 상태: 위험 레벨 진단** |
| **KPI 게이지 (Gauge)** | 핵심 시각화 요소 | 전체 섹션을 차지하는 대형 원형 또는 바 차트 형태. 데이터는 중앙에 크게 표시되어야 함. | **[핵심] 동적 색상 변화 애니메이션:** KPI 수치(예: 미토콘드리아 효율, 염증 지수)에 따라 게이지의 색상이 실시간으로 변해야 함. |
| **위협 레벨 정의** | 색상 코드 매핑 (Color Mapping) | **🔴 Red Zone (Critical)**: `(#D9534F)` - 즉각적인 행동 요구. **🟠 Amber Zone (Warning)**: `(#FFC107)` - 주의 및 경고. **🟢 Green Zone (Stable)**: `(#5CB85C)` - 안정 상태. | 사용자가 진단 결과를 볼 때, 특정 영역이 Red/Amber로 붉게 빛나며 '위험'을 시각적으로 각인시켜야 함. |
| **결과 제시** | 세부 분석 박스 | 게이지 아래에 현재 레벨에 따른 구체적인 해석(Threat Message)을 제공. | *예시: "현재 상태는 Red Zone입니다. 장-뇌 축의 불안정성이 임계치에 도달했습니다."* (이 메시지는 CTA로 연결되어야 함.) |

### 5. 최종 행동 유도 및 신뢰 구축 (Final CTA & Trust)
**목표:** 시스템 주권을 확보하는 행위가 곧 가장 합리적인 선택임을 강조하고 전환을 유도한다.

| 영역 | 구성 요소 | 디자인 지침 (Visual Direction) | 내용 구성 예시 |
| :--- | :--- | :--- | :--- |
| **사회적 증거** | 고객 후기/전문가 코멘트 | 실제 사용자 데이터나 전문가의 인용구를 사용하며, 신뢰를 시각적으로 뒷받침하는 아이콘 배치. | (사용자 경험 기반의 시스템 안정화 사례 강조) |
| **최종 CTA 블록** | 강력한 제안 박스 | 배경색은 Hero 섹션과 대비되는 색상(예: Deep Gold). 긴급성과 가치를 동시에 전달. | **시스템 주권을 확보하세요. 지금 바로 진단하고 관리 서비스를 시작하세요.** (CTA 버튼 재배치) |
