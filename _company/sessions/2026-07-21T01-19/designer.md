## ✨ Ritual Section: 감성 이미지 Mockup 디자인 시스템

**🎨 전체 톤앤매너:** Warm Beige (주 배경), Soft Cream (보조 배경), Deep Blue/Growth Green (포인트 컬러)
**📐 레이아웃 원칙:** 극단적인 여백(Whitespace) 활용, 미니멀한 타이포그래피, 고요함 극대화.

### Mockup A: 아침 기상 루틴 - '고요한 시작' 의식 (Morning Ritual)

**🎯 연결 카피:** "고요함이 깨어남을 맞이합니다." / "내면의 고요한 통제감"
**🖼️ 시각 컨셉:** 새벽빛과 신선한 공기를 연상시키는 청명하고 따뜻한 분위기.

| 요소 | 상세 지시사항 | 디자인 적용 (Color/Font) |
| :--- | :--- | :--- |
| **배경** | 매우 밝은 Warm Beige 또는 Soft Cream. 상단에 미세하게 새벽빛이 스며드는 듯한 그라데이션(Soft Gradient). | `#F5F5DC` (Warm Beige), `#FAF9F6` (Soft Cream) |
| **주요 오브젝트** | 송이버섯의 클로즈업 이미지 또는 이슬 맺힌 참송이골드 버섯의 실루엣. 자연광이 은은하게 비치는 느낌 강조. | 따뜻한 톤의 자연광 효과 적용 |
| **텍스트 배치** | 중앙 하단에 카피를 배치. 타이포그래피는 세리프 계열로 고급스러움을 더함. | **폰트:** Playfair Display 또는 Lora (세리프) / **색상:** Deep Blue (`#193B5A`) |
| **레이아웃** | 화면의 70% 이상을 여백(Negative Space)으로 채우고, 중앙에 오브젝트와 카피를 최소한의 선으로 연결하여 배치. |

### Mockup B: 저녁 취침 전 - '안도감' 의식 (Evening Wind-down Ritual)

**🎯 연결 카피:** "하루를 마무리하는 고요한 안심." / "예측 가능한 평온함"
**🖼️ 시각 컨셉:** 따뜻하고 포근하며, 깊은 휴식을 유도하는 차분한 분위기.

| 요소 | 상세 지시사항 | 디자인 적용 (Color/Font) |
| :--- | :--- | :--- |
| **배경** | 짙고 깊은 Warm Beige 또는 Soft Cream. 약간의 어둠(Deepness)을 암시하여 수면 환경을 연상. | `#E8DCCF` (더 따뜻한 베이지), `#F0F4F8` |
| **주요 오브젝트** | 부드러운 앰버(Amber) 또는 골드 톤의 빛이 드리우는 실루엣 처리된 버섯 이미지. 은은하게 퍼지는 빛 효과 강조. | 골드/앰버 색감의 하이라이트 |
| **텍스트 배치** | 중앙에 카피를 배치하며, 텍스트 주변에 부드러운 그림자(Soft Shadow) 효과를 주어 깊이를 더함. | **폰트:** Serif 계열 / **색상:** Deep Blue (`#193B5A`) |
| **레이아웃** | 수평적인 안정감을 강조하며, 하단에 '안심'이라는 감각적 무게감을 부여하는 여백을 충분히 확보. |

### Mockup C: 주말 휴식 - '균형과 재정립' 의식 (Weekend Reflection Ritual)

**🎯 연결 카피:** "혼란 속에서 발견하는 중심점." / "흔들리지 않는 중심"
**🖼️ 시각 컨셉:** 여유롭고 사색적인 분위기. 일상의 혼란으로부터 잠시 벗어난 고요한 명상 시간.

| 요소 | 상세 지시사항 | 디자인 적용 (Color/Font) |
| :--- | :--- | :--- |
| **배경** | Warm Beige를 메인으로 하되, Soft Cream 영역을 부분적으로 사용하여 대비 효과를 줌. | `#F5F5DC` 및 `#FAF9F6` 혼합 |
| **주요 오브젝트** | 제품과 함께 명상이나 차분한 독서의 분위기를 연출하는 소품(예: 세라믹 잔, 편안한 질감의 천)을 아주 작게 배치. 버섯 이미지는 은은하게 배경에 녹아들도록 처리. | 질감이 느껴지는 텍스처 강조 |
| **텍스트 배치** | 카피를 좌측 또는 우측 정렬하여 여유로운 느낌을 강조하고, 충분한 수직 공간을 확보함. | **폰트:** 미디엄 웨이트 (산세리프) / **색상:** Growth Green (`#4CAF50`) 포인트 사용 |
| **레이아웃** | 가장 넓은 여백을 사용하여 '멈춤'과 '여유'의 심리적 상태를 시각적으로 표현.
