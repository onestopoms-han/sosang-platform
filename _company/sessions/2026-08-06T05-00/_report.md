## HS Code 07.14 분석 보고서: 뿌리/괴경 분류 기준 및 예외 규정

본 보고서는 HS Code Chapter 07의 14호에 명시된 '뿌리/괴경' 품목에 대한 전문을 분석하여, 핵심 분류 기준, 포함되는 주요 품목군, 그리고 명확히 제외되는 가공품 및 유사 상품에 대한 예외 규정을 구조화한 결과입니다.

---

### 1. 핵심 분류 기준 (Core Classification Criteria)

HS Code 07.14는 주로 **전분이나 이눌린(inulin)을 다량 함유한 뿌리 또는 괴경(塊莖)**을 분류하는 것을 목적으로 합니다.

*   **주요 판단 기준:** 해당 품목이 식용 또는 동물의 사료로 직접 사용되는지, 혹은 식품 제조용 또는 공업용품 제조용으로 사용되는지에 따라 분류의 범위가 결정됩니다.
*   **포괄 대상:** 매니옥, 칡뿌리, 고구마 등 전분이나 이눌린을 많이 함유한 뿌리/괴경을 주된 대상으로 합니다.

### 2. 포함되는 주요 품목군 (Included Main Items)

본 호에 포함되는 핵심 물질 및 관련 항목은 다음과 같습니다.

| 분류 대상 | 상세 내용 | 비고 |
| :--- | :--- | :--- |
| **주요 괴경/뿌리** | 매니옥(manioc), 칡뿌리, 살렙(salep), 돼지감자(Jerusalem artichoke), 고구마 등 이와 유사한 전분 또는 이눌린을 다량 함유한 뿌리 및 괴경. | 신선, 냉장, 냉동, 건조 상태 모두 포함. 얇게 썬 것 또는 펠릿 모양에 관계없이 적용됨. |
| **특정 식용 괴경** | 엘레오차리스 덜시스(Eleocharis dulcis)나 엘레오차리스 튜베로사(Eleocharis tuberosa) 종의 식용 괴경 포함. | 이 호에 속하는 뿌리/괴경의 범위를 확장함. |
| **부가 품목** | 사고야자(sago)의 심(pith). | 해당 물질도 본 호에 포함됨. |
| **가공 형태 (펠릿)** | 상기 괴경/뿌리의 조각(예: 칩), 또는 고운 가루, 거친 가루와 가루(제1106호), 전분(제1108호)과 타피오카(제1903호) 등. | 이들은 본 호의 뿌리/괴경을 가공하여 얻은 형태를 분류함. |

### 3. 명확히 제외되는 예외 규정 (Exclusion Regulations)

HS Code 07.14에 포함되지 않는 품목 및 유사 상품에 대한 명확한 예외 규정은 다음과 같습니다.

*   **가공된 최종 제품:** 이 호에 속하는 뿌리나 괴경을 **그 이상으로 조제하여 만든 제품**은 본 호에서 제외되며, 해당 제품은 제1106호(고운 가루/거친 가루와 가루), 제1108호(전분), 제1903호(타피오카) 등 다른 호에 분류됩니다.
*   **제외 대상 괴경:**
    *   살아있는 달리아의 괴경(塊莖) (제0601호).
    *   신선하거나 건조한 감자(제0701호 또는 제0712호에 각각 분류되는 품목).
