## 📄 상세 API 명세서 (핵심 데이터 집중)

### 1. 국가별 관세 정보 API (가장 높은 우선순위)

**목표:** 특정 품목에 대한 직접적인 재무적 리스크(벌금, 세금)를 정량화하는 데 집중합니다.

*   **API 명칭 (예시):** [국가명] 관세/세율 조회 API
*   **데이터 구조 (JSON Schema v1.0):**
    ```json
    {
      "request_id": "UUID",
      "hs_code": "STRING (HS Code)",
      "product_description": "STRING (품목 상세 설명)",
      "tariff_rate": "FLOAT (관세율, %)",
      "duty_amount_base": "DECIMAL (기본 관세액, 통화 단위)",
      "maximum_fine_amount": "DECIMAL (최대 벌금 액수, 법정 기준)",
      "legal_basis_clause": {
        "source_law": "STRING (관련 법령명)",
        "article_id": "STRING (법적 근거 조항 ID)",
        "provision_text": "STRING (해당 조항의 전문 또는 요약)"
      },
      "effective_date": "DATE (정보 유효일)"
    }
    ```
*   **제공 변수 범위:**
    *   `tariff_rate`: 0.0 ~ 100.0%
    *   `duty_amount_base`: 시스템에 따라 최대 수천억 단위까지 허용될 수 있음 (환율 및 품목에 따라 가변적).
    *   `maximum_fine_amount`: 법적 기준에 따라 고정된 값 또는 특정 범위 지정 필요. **(가장 중요)**

### 2. 법령 정보 API (권위 흐름 근거 확보)

**목표:** 시스템이 제시하는 모든 리스크 판단의 법적 토대를 제공합니다.

*   **API 명칭 (예시):** 국가법령정보센터 검색 API
*   **데이터 구조 (JSON Schema v1.0):**
    ```json
    {
      "law_name": "STRING",
      "article_id": "STRING",
      "provision_text": "STRING (해당 조항의 전문)",
      "effective_date": "DATE",
      "amendment_history": [
        {"date": "YYYY-MM-DD", "description": "변경 내용 요약"}
      ]
    }
    ```
*   **제공 변수 범위:**
    *   `article_id`: 고유 식별자. 시스템이 이 ID를 기반으로 다른 법규와 연결할 수 있어야 함.
    *   `provision_text`: 최대 텍스트 길이 제한 필요 (NLP 처리 효율성 고려).
