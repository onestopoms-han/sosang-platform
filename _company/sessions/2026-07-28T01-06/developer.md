### ⚙️ 사용자 플로우 기술 QA 체크리스트 (L1 $\to$ L3)

#### 1. 상태 관리 및 데이터 무결성 검증 (Trust Score Focus)
*   **[S-01] Trust Score 연동 정확성:** L1, L2, L3 전환 시 `Trust Score`의 변화량이 명세된 가치(예: $800\text{ms}, 1200\text{ms}$ 애니메이션)에 비례하여 정확하게 업데이트되는지 확인합니다.
    *   *검증 포인트:* 각 단계 진입/이탈 시점에 백엔드 API 호출 후, 프론트엔드의 상태(State)가 즉시 반영되는지 확인합니다.
*   **[S-02] 데이터 불일치 예외 처리:** API 응답 데이터와 로컬 상태 간에 미세한 불일치가 발생했을 때 (예: `DiagnosisOutputSchema`의 누락된 필드), 시스템이 사용자에게 **'손실 최소화' 원칙**에 따라 적절한 경고 메시지를 표시하는지 검증합니다.
*   **[S-03] 데이터 무결성 검증:** 모든 전환 지점에서 사용된 데이터(KPI, 리스크 예측치)가 백엔드에서 계산된 최종 값과 100% 일치하는지 확인합니다.

#### 2. 애니메이션 및 인터랙션 로직 검증 (`triggerGoldInflow` Focus)
*   **[A-01] 타이밍 정확성:** L2 $\to$ L3 전환 시 `Gold Inflow` 애니메이션의 시작, 지속 시간($1200\text{ms}$), 완료 지점이 명세된 스펙을 **오차 없이** 구현했는지 검증합니다.
*   **[A-02] 트리거 안정성:** 애니메이션이 특정 조건(예: `Trust Score` 임계값 도달, 최종 CTA 클릭)에 의해 정확히 발동되는지 로직 흐름을 추적하여 확인합니다.
*   **[A-03] 시각적 피드백 일관성:** 모든 전환 구간에서 사용된 색상(Deep Charcoal Gray와 Gold Accent) 및 파동 효과의 구현이 디자인 명세(`designer.md`)와 완벽히 일치하는지 검증합니다.

#### 3. 핵심 API 통합 및 예외 처리 (Edge Cases Focus)
*   **[E-01] API 호출 실패 핸들링:** 모든 외부 API(진단 엔진, 데이터 시각화 등) 호출 시 발생하는 네트워크 오류, 서버 5xx 에러, 인증 실패 등의 **모든 예외 상황**에 대해 사용자 친화적인 메시지(`손실 최소화` 원칙 기반)가 명확히 제공되는지 확인합니다.
*   **[E-02] 데이터 누락 처리:** API 응답 시 필수 필드가 누락되었을 경우, 시스템이 멈추는 대신 **대체 값(Fallback Value)** 또는 오류 상태로 전환하여 사용자에게 다음 행동을 유도하는지 검증합니다. (JSON Schema 기반 검증의 완벽성 확인)
*   **[E-03] 비동기 처리 안정성:** 데이터 로딩 및 시각화 과정에서 발생하는 비동기 지연이나 중단 상황에서 UI가 멈추거나 깨지지 않고, 로딩 상태를 명확히 표시하는지 검증합니다.
