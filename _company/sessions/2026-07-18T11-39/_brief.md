# 📋 작업 브리프

**원 명령:** 지금부터 참송이골드는 오직 쇼핑몰 개발에만 집중합니다.
현재 기초 UI가 있으니, 이어서 상품 상세페이지 완성 작업을 진행

## 요약
참송이골드 사업의 전방위적 마케팅 활동을 중단하고 '쇼핑몰 개발'에 모든 역량을 집중합니다. 현재 구축된 기초 UI를 기반으로 핵심 상품인 인공재배송이버섯의 상세페이지(PDP) 완성 작업을 진행해야 합니다.

## 분배
- **🔍 Researcher**: 건강 기능 식품/프리미엄 식물성 제품 카테고리의 국내외 성공적인 이커머스 상품 상세 페이지(PDP) 최신 트렌드를 리서치하라. 특히 구매 전환율을 높이는 '과학적 근거 제시 방식', '사용자 후기 통합 구조', 그리고 '위험성/안전성을 시각적으로 강조하는 요소'에 대한 경쟁사 사례와 핵심 성공 요인 3가지를 정리하여 보고하라.
- **✍️ Writer**: 리서처가 제공한 트렌드를 반영하여, 인공재배송이버섯의 상세페이지를 위한 카피라이팅 초안을 작성하라. 다음 요소를 반드시 포함해야 한다: 1) 구매자의 Pain Point(예: 불규칙한 식단, 불안정한 건강 상태), 2) 제품의 핵심 차별점/효능을 시스템적 통제권 회복 논리('데이터 기반' 등)와 결합하여 설명하는 메인 헤드라인 및 본문 구조, 3) 사용자가 믿음을 갖게 하는 FAQ 또는 Q&A 섹션 카피.
- **🎨 Designer**: 완성된 PDP의 최종 와이어프레임과 디자인 사양을 작성하라. 이 사양은 단순히 예쁜 것을 넘어, 구매 퍼널(Pain → Solution → Trust → Action)에 맞춰 콘텐츠 블록 배치가 명확해야 한다. 특히 '과학적 근거 시각화 영역'과 '구매 버튼/CTA 영역'의 UX를 극대화하고, 골드 앰버(#FFC72C) 색상을 활용하여 중요한 경고 및 주의사항을 강조하는 디자인 브리프를 제공하라.
- **💻 코다리**: 최종 디자인 사양(PDP Spec Sheet)을 기반으로, 상품 상세페이지의 기술적 구현 로직과 컴포넌트 구조를 정의하라. PDP는 여러 개의 독립적인 섹션(Hero/Concept/Science/Testimonial/Purchase)으로 구성되어야 하며, 각 섹션별 필요한 React 컴포넌트 뼈대(`` 등), 상태 관리 흐름(State Flow), 그리고 데이터 연동을 위한 API Mockup 구조를 포함하는 코드 스캐폴딩과 기술 검토 보고서를 작성하라.
