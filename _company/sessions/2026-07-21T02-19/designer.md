## 📝 MVP 웹페이지: Provenance Mark 상호작용 디자인 브리프

### 1. 핵심 목표 (Design Goal)
사용자가 단순한 데이터 기록을 넘어, **'고요한 발견'과 '일상 속 의식(Ritual)'의 과정에 능동적으로 참여하고 있음을 시각적으로 체감**하게 한다. Provenance Mark의 전환 및 루틴 달성 과정을 지루하지 않고 의미 있게 강조하여 심리적 소유감을 부여한다.

### 2. 디자인 컨셉: '고요한 성장 (Quiet Growth)'
Warm Beige와 Dusty Gold의 따뜻하고 고요한 톤을 유지하며, 모든 상호작용은 미묘하고 부드러운 애니메이션(Subtle Animation)과 은은한 색상 변화를 통해 진행된다. 과도한 움직임이나 경고성 피드백은 지양하며, **'성장'의 순간을 명상하듯 경험하게 한다.**

### 3. 핵심 인터랙션 정의 (Visual Feedback Loop Definition)

#### A. 루틴 단계 전환 시 (Step Progression)
사용자가 다음 레벨로 진행할 때 발생하는 피드백.

*   **트리거:** 사용자가 '다음 단계' 버튼을 클릭하거나, 데이터가 성공적으로 기록되어 자동 업데이트될 때.
*   **시각적 피드백:**
    1.  **미세한 부드러운 애니메이션:** 현재 단계(`Level X`)에서 다음 단계(`Level Y`)로 전환될 때, 해당 영역(혹은 마크 자체)이 **Dusty Gold 색상으로 미세하게 채워지거나 반짝이는(Glow/Pulse)** 효과를 적용한다.
    2.  **텍스트 강조:** 성공적으로 완료된 단계는 부드러운 녹색 계열(`Forest Green`의 톤을 참고하여 차분한 녹색)로 표시하고, 다음 목표가 명확히 제시된다.
*   **UX 메시지:** "다음 의식을 시작하세요." 또는 "당신의 여정이 다음 단계로 이어집니다." (감성적 문구 사용)

#### B. Provenance Mark 상태 변화 시 (Mark Status Change)
최종 마크(`Pending` → `Verified` → `Complete`)의 전환 피드백.

*   **트리거:** 최종 데이터 검증이 완료되어 Provenance Mark 상태가 변경될 때.
*   **시각적 피드백:**
    1.  **진입 애니메이션 (Transition):** 마크가 변하는 순간, 화면 전체에 아주 느리고 부드러운 **'고요한 빛의 흐름(Flowing Light)'** 효과를 적용한다. 이는 데이터의 신뢰도 상승을 시각적으로 표현한다.
    2.  **마크 자체 변화:** `Pending` 상태에서는 윤곽선만 보이고, `Verified` 상태가 되면 전체 마크 영역이 Warm Beige/Dusty Gold 톤으로 채워지며, **Basic Provenance Mark의 3단계 시각적 흐름**을 명확히 보여준다.
*   **UX 메시지:** "당신의 참여로 증명되었습니다. (Verified)"

#### C. 데이터 입력 및 기록 시 (Input & Recording)
사용자가 루틴 세부 사항을 입력하는 과정에서의 피드백.

*   **트리거:** 텍스트 필드에 내용이 채워지거나, 저장 버튼 클릭 시.
*   **시각적 피드백:**
    1.  **입력 강조:** 입력 필드는 기본적으로 Warm Beige 배경에 연한 회색 테두리를 유지한다. 사용자가 입력하는 동안 포커스된 필드에는 **Dusty Gold 색상의 얇은 하이라이트(Glow)**가 실시간으로 따라다니며 집중도를 높인다.
    2.  **저장 피드백:** 저장 버튼 클릭 시, 짧고 부드러운 **'성취감의 파동(Ripple Effect)'** 애니메이션을 적용하여 데이터가 안전하게 기록되었음을 사용자에게 전달한다.

### 4. 디자인 가이드라인 요약 (Design System Summary)

| 요소 | 스타일/색상 | 상호작용 정의 | 목적 |
| :--- | :--- | :--- | :--- |
| **전체 톤** | Warm Beige, Dusty Gold | 부드러운 그림자 및 미세한 움직임 사용 | 고요함, 프리미엄 의식 경험 제공 |
| **Progress Bar** | Dusty Gold 채움 | 단계 전환 시 Gradual Fill Animation | 성장 과정의 명확하고 감성적인 표현 |
| **Provenance Mark** | Gold/Beige 톤으로 채워짐 | 상태 변화 시 '빛의 흐름' Transition | 소유권 및 신뢰감의 시각적 증명 |
| **Input Fields** | Warm Beige 배경, Gold 테두리 | 포커스 시 Dusty Gold Glow 적용 | 사용자의 집중 유도 및 몰입 강화 |
