# 🌟 SSI 인터랙티브 위젯 최종 디자인 스펙 (Component Specification)

## 1. 컴포넌트 개요
**컴포넌트 이름:** `SystemStabilityGauge` (시스템 안정성 게이지)
**목적:** 사용자가 제품의 '시스템 통제 경험(SSI)'을 직관적으로 인지하고, 데이터 기반 권위를 시각적으로 체험하게 함으로써 신뢰감과 고급 미식 경험을 제공한다.
**핵심 테마:** 과학적 권위 (Scientific Authority) + 고급 미식 (Gourmet Experience)
**주요 색상 팔레트:**
*   **Primary (불안정/경고):** Deep Red / Amber (잠재적 불안정 상태)
*   **Secondary (중립/관리):** Muted Gold / Bronze (현재 관리 영역)
*   **Success (통제 회복/안정):** Rich Gold / Deep Blue Accent (최적의 통제권 확보 상태)

## 2. 데이터 상태 및 시각화 정의 (State & Visualization Mapping)

SSI 값(0% ~ 100%)에 따라 위젯이 표시해야 할 세 가지 주요 상태를 정의합니다.

| 상태 이름 | SSI 범위 | 시각적 색상 (Gauge Fill) | 애니메이션/텍스트 변화 | 스토리텔링 매핑 |
| :--- | :--- | :--- | :--- | :--- |
| **불안정 (Instability)** | 0% ~ 35% | Deep Red / Amber Gradient | 불안정한 떨림(Flicker) 효과, 경고 텍스트 노출 | **문제 인식:** 시스템이 통제 불능 상태임을 암시 |
| **관리 (Management)** | 36% ~ 75% | Muted Gold / Bronze Gradient | 부드러운 흐름(Smooth Flow), 데이터 추적 애니메이션 | **과정 진행:** 사용자의 개입으로 안정화되는 과정을 시각화 |
| **통제 확보 (Control Achieved)** | 76% ~ 100% | Rich Gold / Deep Blue Accent | 안정적인 고정 상태, 빛나는(Glow) 효과, 최종 통제권 회복 메시지 | **해결책:** 시스템에 대한 완전한 통제권과 최고의 미식 경험을 확보함 |

## 3. 컴포넌트 상세 사양 (Component Details for Developers)

### 3.1. 레이아웃 및 구조 (`SystemStabilityGauge`)
*   **구조:** 중앙 집중형 게이지(Gauge), 핵심 수치 표시 영역, 시스템 지표 설명 영역으로 구성된다.
*   **레이아웃:** 가로형 또는 원형을 기본 형태로 하되, '고급 미식' 테마에 맞춰 **세련된 다이아몬드 형태의 프레임** 안에 게이지를 배치한다.

### 3.2. 시각적 요소 상세 (Visual Element Specification)
*   **게이지 채움:** SSI 값에 비례하여 배경색(Gradient)을 변화시킨다. 단순한 색상 채우기가 아닌, **골드에서 짙은 네이비로 점진적으로 변하는 그라데이션**을 사용하여 고급스러움을 극대화한다.
*   **핵심 수치 표시 (SSI Value):**
    *   가장 크게 표시하며, **Rich Gold** 색상으로 강조한다.
    *   그 아래에 시스템 지표 설명(`시스템 통제권 확보율: XX%`)을 **Small Font (Navy)**로 배치하여 과학적 근거를 명시한다. (데이터 기반 권위 확립)

### 3.3. 인터랙션 및 애니메이션 상세 (Interaction & Animation Flow)
사용자 액션(데이터 로드 또는 상태 변화)에 따른 동적인 흐름을 정의합니다.

| 사용자/시스템 이벤트 | Triggered State | 애니메이션 타이밍/효과 | UI 피드백 메시지 |
| :--- | :--- | :--- | :--- |
| **초기 로딩** (데이터 요청 시) | 관리 (Management) | 부드러운 골드 그라데이션의 서서히 채워짐 (300ms). 미세한 맥동 효과(Subtle Pulse). | "시스템 안정화 과정 중..." (잠시 대기) |
| **불안정 상태** (SSI < 35%) | 불안정 (Instability) | 게이지 전체에 **Deep Red 경고 깜빡임(Flicker)** 적용. 배경에 미세한 떨림 효과 추가. | "시스템 안정성 위험 감지" (경고 아이콘 동반) |
| **통제 확보** (SSI $\ge$ 76%) | 통제 확보 (Control Achieved) | 게이지가 최종 Gold/Blue로 고정되며, 중앙에 **빛나는(Glow) 효과** 발생. 부드러운 파동(Ripple) 애니메이션. | "**최상위 미식 경험 확보**" (성공 메시지) |
| **데이터 업데이트** (실시간 변화 시) | 상태 변화에 따라 즉시 전환 | State Transition에 맞춘 500ms의 부드러운 Cross-fade 애니메이션. | 지표 설명은 즉시 업데이트되어 변경 사항을 명확히 전달. |

## 4. 최종 디자인 가이드라인 요약 (Final Guideline Summary)
1.  **권위 부여:** 모든 시각적 강조(Gold, Glow)는 단순한 미학이 아닌, **데이터 기반 권위**를 뒷받침한다는 점을 애니메이션과 폰트 사용으로 명확히 표현한다.
2.  **서사 강화:** 불안정 상태에서 통제 확보 상태로의 전환은 '고난 극복' 서사를 따라 부드럽지만 확실하게 시각화되어야 한다. (Flicker $\rightarrow$ Smooth Flow $\rightarrow$ Glow)
3.  **미식 접목:** 전체 디자인 톤은 **어둡고 깊이 있는(Deep/Dark)** 배경 위에서 **골드와 네이비의 고급스러운 대비**를 통해 프리미엄 미식 경험을 제공한다.
