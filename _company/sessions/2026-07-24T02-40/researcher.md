### 📋 식약처 기반 데이터 검증 및 필터링 프로토콜 (Compliance Protocol)

본 프로토콜은 연구/리서치 단계에서 수집된 모든 과학적 자료, 임상 논문 요약, 그리고 최종 마케팅 카피가 식품위생법 및 관련 광고 규정을 위반하지 않도록 보장하기 위해 의무적으로 적용됩니다.

#### 1. 데이터 검증 체크리스트 (Data Verification Checklist)

모든 원천 데이터(논문, 임상 결과, 과학적 주장 등)를 검토할 때 다음 항목을 확인해야 합니다.

| No. | 검증 항목 | 세부 기준 (식약처/법규 준수 관점) | 상태 (O/X) | 비고 (위반 시 수정 필요 사항) |
| :---: | :--- | :--- | :---: | :--- |
| **1** | **직접적 효능 주장 여부** | 제품이 특정 질병의 치료, 예방, 진단 또는 건강 개선 효과를 직접적으로 주장하는가? (예: "암 예방에 도움", "혈당 개선") | | |
| **2** | **인체 적용 범위 제한** | 주장이 인체나 신체의 특정 기능(예: 면역력 증진, 대사율 향상)과 관련되어 있다면, 이는 '식품의 기능성 내용'으로 분류되는가? (기능성 원료로 허용되는 범위 확인) | | |
| **3** | **객관적 근거 제시 여부** | 주장을 뒷받침하는 데이터(임상 결과, 과학적 측정값 등)가 명확하게 인용되었는가? 단순 추측이나 비과학적 해석은 포함되지 않았는가? | | |
| **4** | **'시스템 통제권'과의 연관성** | 제시된 데이터가 제품의 본질인 '데이터 기반 시스템 통제권 확보 과정'이라는 맥락에서 논리적으로 해석되고 연결되는가? (효능 중심이 아닌 프로세스 중심으로 해석) | | |
| **5** | **과장 및 허위 표시 금지** | 수치나 결과를 제시할 때, 법적 허용 범위를 초과하여 과장하거나 사실과 다르게 표현하지 않았는가? (특히 임상 데이터의 인용 시 주의) | | |

#### 2. 검증 절차 의무화 (Mandatory Verification Procedure)

모든 연구 산출물은 다음의 **3단계 검증 프로세스**를 거쳐 최종 승인되어야 합니다.

**Step 1: 자료 수집 및 초기 분석 (Data Gathering & Initial Analysis)**
*   연구원(Researcher)은 모든 과학적 데이터와 임상 논문을 수집하고, 핵심 주장과 그 근거를 분리하여 정리합니다.
*   모든 주장에 대해 위 **체크리스트 1**을 적용하여 각 사실의 법적 위험도를 초기 평가합니다.

**Step 2: 내부 필터링 및 해석 (Internal Filtering & Interpretation)**
*   연구원은 데이터가 '시스템적 통제권 확보 과정'이라는 회사 철학에 부합하는지, 그리고 광고 금지 항목(체크리스트 **1**)을 위반하지 않는지를 재검토합니다.
*   만약 특정 주장이 효능 주장으로 해석될 여지가 있다면, 해당 주장은 **"시스템적 통제권 확보 과정의 데이터 흐름 및 관리 효율성 증명"**과 같이 프로세스 중심으로 완전히 재구성하도록 수정합니다.

**Step 3: 최종 승인 (Final Approval)**
*   최종적으로 작성된 모든 리포트, 스크립트 초안, 상세페이지 문구 등은 **Writer 에이전트 및 영숙 팀원의 규제 준수 원칙(SOP)**과 상호 교차 검증을 거쳐 최종 승인되어야 합니다. (이는 Writer와 영숙의 역할에 따라 진행됨)
