# 📋 작업 브리프

**원 명령:** 국과 유럽의 데이터를 같이 활용해서 HS를 결정할때 비교를 해서 진행하고싶어 그러니 알맞게 DB를 구축해줘

## 요약
한국과 유럽의 관세 데이터를 비교하여 하나의 HS 코드를 결정할 수 있는 데이터베이스 및 모듈 구축이 필요합니다. 단순히 정보를 나열하는 것이 아니라, 두 지역 규정 간의 차이점을 비교하고 사용자가 스스로 최적의 코드를 찾아가도록 유도하는 '비교 분석 시스템' 설계가 목표입니다.

## 분배
- **🔍 Researcher**: 한국(HS Code)와 유럽 연합(TARIC/CN)의 관세 분류 체계 및 데이터 구조를 비교 분석하십시오. 특히, 두 지역에서 동일한 품목을 다룰 때 '규정하는 핵심 로직'이나 '차이로 인해 코드가 달라지는 주요 항목' (예: 재질별 구분 방식, 용도별 세부 분류 등)에 대한 최신 데이터를 수집하고 표 형태로 정리해 주세요. 데이터 비교를 위한 공통의 기준점(Common Grounding Factors)을 도출하는 것이 핵심입니다.
- **💻 코다리**: 연구자가 제공한 한국-유럽 HS 코드 비교 분석 데이터를 바탕으로, 'HS Code Cross-Validation Module'이라는 이름의 데이터베이스 및 인터페이스를 설계하십시오. 이 모듈은 사용자가 품목명과 주요 속성(재질, 용도 등)을 입력하면, 두 지역 규정별로 코드를 제시하고 그 차이점을 시각적으로 비교해 주는 로직을 포함해야 합니다. 핵심 기능으로 '규제 충돌 지점 (Compliance Conflict Point)' 경고 시스템을 구현하는 데 집중하십시오.
