# 📚 HS 분류 통합 지식 베이스 (Knowledge Base Draft)

## 1. 최우선 판단 기준 및 철학 (Core Principles)

**핵심 원칙:**
*   **물리적 형태 및 구조 (Physical Form & Structure):** 모든 HS 분류의 **최우선 판단 기준**으로 확정한다. (1순위)
*   **작동 방식 및 기능 (Operating Method & Function):** 재료 구성보다 물품이 실제로 수행하는 **기능과 작동 방식**을 핵심 기준으로 삼는다.

**시스템 적용 목표:**
*   GRI 원칙에 기반한 예외 품목 검증 로직을 시스템에 반드시 추가 구현한다.
*   제외/연동 규칙 등 특화된 분류 원칙은 별도의 API 모듈로 분리하여 설계한다.

## 2. 핵심 분류 흐름 (Classification Flow)

HS 코드를 분류하는 과정은 단순 키워드 매칭이 아닌, 복합적인 물리적 형태 기반의 다단계 검증 플로우를 따른다.

**3단계 흐름:**
1.  **형태 판별 (Form Identification):** 물품의 외형, 재료 구성, 물리적 구조를 1차적으로 판단한다.
2.  **공정 확인 (Process Verification):** 해당 물품이 어떤 제조 공정을 거쳤는지, 어떤 방식으로 가공되었는지를 확인한다.
3.  **최종 매핑 (Final Mapping):** 1단계와 2단계의 정보를 바탕으로 최종 HS 코드에 매핑한다.

## 3. 주요 품목별 판단 기준 및 예외 처리 규칙

### A. 재료 기반 분류 시 (예: 비금속, 합금)

*   **원칙:** 재료 구성 자체보다 **합금 기능 및 용도**를 최우선 판단 기준으로 삼는다.
    *   *(참고 근거: 81.11 - Manganese and articles thereof)*
*   **경계 설정 (Boundary Setting):** Chapter 간 경계(예: Chapter 72와의 경계)에 대해서는 **시스템 레벨의 조건부 검증 체계**를 도입한다.

### B. 도구 및 공구 분류 시 (예: 82류)

*   **원칙:** 재료 구성보다 **공구의 작동 방식과 기능적 역할 정의**에 기반해야 한다.
    *   *(참고 근거: 82.07 Interchangeable tools for hand tools)*
*   **이원화 구조 적용:** HS 코드 분류 기준을 '기계적 메커니즘(82.04)'과 '잔여물 포괄성(82.05)'의 **이원화 구조**로 확립하여 적용한다.

### C. 특수 품목 분류 시 (예: 주석 관련)

*   **원칙:** 구리 제품에 준하여 제7407호 및 제7408호 해설 규정을 적용한다.
    *   *(참고 근거: 80.03 - 주석의 봉ㆍ프로파일(profile)ㆍ선(線))*

## 4. 예외 품목 검증 로직 (Exception Verification Logic)

시스템은 다음과 같은 규칙을 통해 예외 품목을 검증해야 한다.

1.  **제외 품목 경계 설정:** 아연 도금 철강 제품 등 제외 품목에 대한 **경계(Boundary) 설정**을 시스템 최우선 검증 조건으로 지정한다.
2.  **물리적 형태 우선:** 분류 엔진은 단순 키워드 매칭이 아닌, **복합적인 물리적 형태 기반의 검증 플로우**를 적용하여 분류한다.
3.  **오류 피드백:** 예외 처리가 필요한 분류 항목에 대해 오류 발생 시 알림 기능이 포함된 UI 모듈을 디자인하여 적용한다. (사용자에게 직관적인 피드백 제공)
