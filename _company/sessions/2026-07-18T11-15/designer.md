# 📄 랜딩 페이지 상세 디자인 브리프: 시스템적 통제권 회복 대시보드 (Systemic Control Dashboard)

## 1. 디자인 목표 및 컨셉
**목표:** 소비자가 참송이골드를 '건강 보조 식품'이 아닌, **'데이터 기반의 리스크 관리 시스템(Control System)'**으로 인식하게 하여 신뢰와 통제감을 극대화한다.
**컨셉:** **Data-Driven Control Panel (데이터 기반 제어판)**. 미니멀하지만 정보 밀도가 높고, 시각적 경고와 안정화를 통해 심리적 안정을 제공하는 대시보드 형태를 채택한다.

## 2. 비주얼 시스템 정의 (Visual System Definition)

### A. 컬러 팔레트 (Color Palette)
브랜드의 핵심 가치(위험/안정화)를 시각적으로 직관화합니다.

| 역할 | 색상 이름 | HEX 코드 | 용도 및 의미 |
| :--- | :--- | :--- | :--- |
| **경고/주의 (Risk)** | 골드 앰버 (Gold Amber) | `#FFC72C` | 잠재적 손실, 경고, 시스템 오류. **CTA 섹션에 집중 사용.** |
| **안정화 (Control)** | 성장 녹색 (Growth Green) | `#38A169` | 시스템 안정화, 긍정적 결과, 성공적인 통제권 회복. |
| **기본 배경** | 다크 그레이/블랙 | `#121212` | 프리미엄, 전문성, 데이터 시각화에 집중할 수 있는 몰입감 제공. |
| **보조 텍스트** | 라이트 그레이 | `#A0AEC0` | 정보의 계층 구조를 명확히 구분. |
| **강조 (Primary)** | 골드 (Gold Accent) | `#FFD700` | 핵심 가치 및 중요 데이터 강조. |

### B. 타이포그래피 시스템 (Typography System)
전문성과 명료함을 최우선으로 합니다.

*   **헤드라인 (H1, H2):** 산세리프 계열의 굵고 명확한 폰트 (예: Pretendard Bold/SemiBold). 데이터 제목처럼 간결하고 강렬하게 표현합니다.
*   **본문 (Body Text):** 가독성이 높은 서체 (예: Noto Sans KR, Pretendard Regular). 시스템 보고서의 내용처럼 상세하고 명확하게 전달합니다.

### C. 레이아웃 및 컴포넌트 스타일 (Layout & Component Style)
1.  **대시보드 프레임:** 전체 페이지를 다크 모드 배경에 골드/녹색 악센트를 사용하여, 마치 고급 시스템의 대시보드를 보는 듯한 느낌을 연출합니다.
2.  **데이터 위젯:** 모든 핵심 정보(Pain, Solution, Control)는 **'위젯(Widget)'** 형태로 분리하여 배치하며, 각 섹션은 독립적인 데이터 패널처럼 구성합니다.
3.  **애니메이션:** 골드 앰버와 성장 녹색의 전환 애니메이션을 필수적으로 사용하여, 사용자가 '리스크 상태 $\rightarrow$ 안정 상태'로 변화하는 과정을 시각적으로 경험하게 합니다.

## 3. 섹션별 UI/UX 와이어프레임 상세 지시 (Wireframe Detail)

### **[SECTION 1: 헤더 및 후크 (Pain 극대화)]**
*   **레이아웃:** 상단에 미니멀한 로고와 함께, 페이지 전체 너비에 걸쳐 중앙 정렬된 **'경고 위젯'**을 배치합니다.
*   **시각 요소:** 배경은 다크 그레이/블랙. 메인 헤드라인 위에 `#FFC72C` 골드 앰버 색상의 경고 아이콘과 함께 "당신의 건강, 시스템적으로 확인하셨습니까?"라는 질문이 크게 표시되어 즉각적인 불안감을 유도합니다.

### **[SECTION 2: 솔루션 전환 (Solution Reveal)]**
*   **레이아웃:** 화면 중앙에 **'Pain $\rightarrow$ Solution $\rightarrow$ Control'**의 3단계 흐름을 시각적으로 표현하는 수평 또는 수직 진행 바(Progress Bar)를 배치합니다. 현재는 'Pain' 단계에 머물러 있음을 보여줍니다.
*   **내용:** "하지만, 데이터로 이 불확실성을 통제할 수 있습니다."라는 문구와 함께, 참송이골드의 핵심인 **'시스템 무결성 보고서'**의 개념을 설명하는 간결한 텍스트를 배치합니다.

### **[SECTION 3: 신뢰 구축 (Traceability & Control)]**
*   **레이아웃:** 이 섹션은 가장 복잡하지만 가장 신뢰를 주어야 하므로, **'데이터 인터랙션 스크립트'**의 시각화에 집중합니다.
*   **핵심 컴포넌트: Trust Widget (신뢰 위젯)**
    *   공급망 투명성을 보여주는 단계별 프로세스를 시각화합니다. 각 단계(원재료 수집 $\rightarrow$ 배양 $\rightarrow$ 검증 $\rightarrow$ 최종 보고)는 데이터 흐름이 명확하게 연결된 **인터랙티브 그래프** 형태로 디자인합니다.
    *   각 단계의 완료 상태는 `#38A169` (성장 녹색)으로 표시되며, 현재 사용자가 어디에 있는지(Progress)를 시각적으로 보여줍니다.

### **[SECTION 4: 최종 CTA 섹션 (Control 확립)]**
*   **레이아웃:** 페이지의 가장 하단에 배치하며, 모든 시스템이 안정화되었음을 선언하는 영역입니다.
*   **CTA 강조:** 이 영역은 **`#FFC72C` 골드 앰버 색상**을 주조색으로 사용하여 시각적 긴급성과 중요도를 극대화합니다.
*   **CTA 버튼 디자인:**
    *   주요 CTA 버튼(예: '시스템 무결성 보고서 다운로드')은 **골드 앰버 배경에 흰색 텍스트**로 강조하여, 클릭을 유도하고 이 행동이 리스크 통제의 최종 단계임을 암시합니다.
    *   보조 CTA는 성장 녹색으로 처리하여 안정적인 선택지를 제공합니다.

## 4. 디자인 요약 및 실행 지침

1.  **전체 분위기:** 다크 모드, 데이터 대시보드 스타일 (Dark Mode, Dashboard Style).
2.  **핵심 시각 요소:** 골드 앰버($\#FFC72C$)와 성장 녹색($\#38A169$)의 대비를 통해 리스크와 안정화의 감정적 전환을 유도합니다.
3.  **UI/UX 목표:** 사용자가 정보를 읽는 것이 아니라, **시스템을 분석하고 통제하는 경험**을 하도록 설계해야 합니다.
