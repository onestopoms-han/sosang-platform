## 📄 리스크 프리미엄 모델: 데이터 일관성 검토 보고서 (MVP 개발용)

### 1. 핵심 변수 및 산업 데이터 일관성 검토 프레임워크

개발 단계에서 사용될 핵심 입력 변수(지정학적 리스크 지표, 규제 패널티 가중치 등)가 실제 산업 데이터와 일관성을 갖는지 확인하기 위한 프레임워크를 제시합니다.

| 변수 그룹 | 핵심 변수 예시 | 검증 기준 (Industry Consistency Check) | 요구되는 외부 데이터 소스 |
| :--- | :--- | :--- | :--- |
| **지정학적 리스크 ($\text{R}_G$)** | 지정학적 위험 지표 (예: 정치적 불안정성 점수, 무역 장벽 변화율) | 실제 사건 발생 시점과 모델 예측값의 편차 분석. 역사적 데이터와의 상관관계 확인. | IMF/World Bank 데이터, Geopolitical Risk Index 등 외부 API 연동 데이터 |
| **규제 패널티 가중치 ($\text{W}_R$)** | 특정 지역의 환경/노동 규제 위반 시 예상되는 벌금 및 법적 비용의 통계적 분포. | 실제 소송 기록, 정부 발표 자료를 기반으로 가중치의 분포(표준편차)를 측정하여 조정. | 각 국가별 법률 데이터베이스, 산업별 벌금 사례 데이터 |
| **시장 변동성 ($\text{V}_M$)** | 원자재 가격 변동성 (예: 원유, 핵심 광물 가격의 실시간 변동 폭). | 과거 $N$개월간의 실제 시장 변동성과 모델 예측값의 RMSE(평균 제곱근 오차) 비교. | Bloomberg/Refinitiv 등 금융 데이터 API |
| **운영 리스크 ($\text{R}_O$)** | 공급망 중단 확률, 물류 비용 상승률. | 공급망 이벤트 발생 빈도와 실제 비용 증가율 간의 상관관계 분석. | 글로벌 물류 지수 데이터, 공급망 관련 보고서 |

**✅ 일관성 확보 원칙:**
모든 입력 변수는 **'과거 12개월 평균 편차 ($\text{D}_{12M}$)'**를 기준으로 $\pm 15\%$의 허용 오차 범위 내에 있어야 합니다. 이 기준을 벗어날 경우, 시스템은 경고(Warning) 상태로 전환되어야 하며, 개발자는 해당 변수에 대한 **'근거 데이터 보강 요청'**을 받도록 설계합니다.

### 2. 데이터 불일치 시나리오 및 보정 계산 공식 (Correction Formula)

개발 단계에서 발생 가능한 데이터 불일치 상황에 대비하여, 예측 모델의 신뢰성을 유지하면서도 현실적인 결과를 도출하기 위한 세 가지 핵심 시나리오와 대응 공식을 정의합니다.

#### 시나리오 1: 외부 지표의 급격한 변화 (Volatility Shock)
*   **상황:** 지정학적 리스크 ($\text{R}_G$)가 예측치보다 훨씬 빠르게 악화되어 시장 변동성 ($\text{V}_M$)이 비정상적으로 상승했을 때 발생합니다.
*   **문제점:** 기존의 선형적 모델은 이러한 비선형적인 급변을 포착하지 못하여 리스크 프리미엄이 과소평가되거나 과대평가될 수 있습니다.
*   **보정 공식 ($\text{C}_1$):** **비선형 가중치 적용 (Non-linear Weighting)**
    $$\text{Risk\_Premium}_{\text{Adjusted}} = \text{Risk\_Premium}_{\text{Base}} \times (1 + \alpha \cdot |\text{V}_{M} - \text{V}_{\text{Predicted}}|)$$
    *   $\alpha$: 시스템이 설정한 민감도 계수 (기본값: 0.5). 이 계수를 조정하여 리스크 변화에 대한 시스템의 민감도를 조절합니다.

#### 시나리오 2: 규제 패널티 데이터의 누락 또는 오류 (Missing/Erroneous Penalty Data)
*   **상황:** 특정 국가의 규제 패널티 가중치 ($\text{W}_R$) 데이터가 업데이트되지 않았거나, 과거 사례 데이터에 오류가 포함되어 있을 때 발생합니다.
*   **문제점:** 리스크 프리미엄 계산 시 실제 잠재적 비용이 반영되지 않아 '통제권 확보'의 목표가 훼손됩니다.
*   **보정 공식 ($\text{C}_2$):** **최근 동향 기반 추정 (Recent Trend Estimation)**
    $$\text{W}_{R\_Corrected} = \text{W}_{R\_Base} + \beta \cdot (\text{Avg}(\text{W}_{R, \text{Last 6M}}) - \text{W}_{R\_Base})$$
    *   $\text{W}_{R\_Base}$: 기본 설정 가중치. $\text{Avg}(\text{W}_{R, \text{Last 6M}})$: 최근 6개월간의 실제 패널티 평균값. $\beta$: 추정 보정 계수 (기본값: 0.2).

#### 시나리오 3: 사용자 프로필 데이터의 불일치 (User Profile Inconsistency)
*   **상황:** 사용자가 입력한 프로필 데이터 ($\text{User\_Profile\_Data}$)와 시스템이 추론한 잠재적 위험 수준 간에 괴리가 발생할 때 발생합니다.
*   **문제점:** 사용자에게 제시되는 '통제권 확보'의 감성적 서사(Emotional Flow)가 실제 재무 상황과 동떨어져 신뢰도를 잃습니다.
*   **보정 공식 ($\text{C}_3$):** **상관관계 기반 조정 (Correlation-based Adjustment)**
    $$\text{Risk\_Score}_{\text{Final}} = \text{Risk\_Score}_{\text{Input}} + \gamma \cdot (\text{Deviation}(\text{Actual Cost Avoidance}, \text{Predicted Cost}))$$
    *   $\text{Deviation}$: 실제 절감 비용과 예측된 비용 간의 차이. $\gamma$: 결과에 대한 신뢰도를 조정하는 계수 (기본값: 1.0).
