# 👑 Access Pass 경험 목업 프로토타입 설계: 시스템 통제권 확보 여정 (The Control Progression)

## 1. 전체 디자인 컨셉 및 비주얼 시스템 정의

**핵심 철학:** 불안감(불확실성) $\to$ 이해(인지적 통제권) $\to$ 실행(실행적 통제권) $\to$ 예측(전략적 통제권)으로의 **'통제권 이동'**을 시각적으로 극대화한다.

**브랜드 톤 적용:**
*   **색상 팔레트 (Color Palette):** 신뢰감과 전문성을 강조하는 딥 블루 계열과, 진행 단계에 따라 변화하는 액센트 색상을 사용합니다.
    *   Primary: `#0A2A4A` (Deep Navy - 신뢰와 안정)
    *   Secondary: `#3498DB` (Sky Blue - 명확성과 통제)
    *   Progress Accent (L2/L3): Gradient from Light Blue to Teal (`#4CC9F0` $\to$ `#00C4B4`)
    *   Mastery Accent (L4): Gold/Amber (`#FFC300` - 전략적 가치)
*   **타이포그래피:** 산세리프 계열(예: Pretendard 또는 Noto Sans KR). 데이터와 프로세스를 명확히 전달하기 위해 굵기 대비를 활용합니다.

## 2. 인터랙티브 플로우 설계 (L2 $\to$ L3 $\to$ L4)

사용자는 Access Pass 구매 후, 시스템이 제공하는 데이터를 통해 스스로 통제권을 점진적으로 확보하는 과정을 경험해야 합니다. 각 단계는 다음 단계로의 **'통제권 전환(Control Shift)'**을 명확히 보여주어야 합니다.

### A. 도입 화면: 시작점 (L2: 기반 설정 및 이해)

*   **목표:** 시스템의 기본 작동 원리를 인지하고 초기 환경을 안정화하는 경험 제공.
*   **UX 흐름:** 사용자는 '시스템이 어떻게 작동하는가?'에 대한 질문을 던지고, 데이터 입력/확인 과정에서 **인지적 통제권**을 획득합니다.
*   **시각 요소:**
    1.  **Intro Animation:** 복잡한 시스템 구조(노드와 연결)가 점차 단순화되며 명료해지는 애니메이션. (불확실성 $\to$ 이해)
    2.  **Data Input Focus:** 기초 데이터 입력 시, 각 필드 옆에 '시스템의 작동 원리'를 설명하는 미니 툴팁이 활성화되어 사용자가 정보를 통제하고 선택하게 유도합니다.
    3.  **Progress Gauge (L2):** 진행률 표시줄은 단순한 %가 아니라, 시스템 구성 요소 간의 **연결 상태(Connection State)**를 시각적으로 표현합니다.

### B. 전환 화면: 최적화 (L3: 최적화 및 적용)

*   **목표:** 개인 목표에 맞게 변수를 조정하고 실행 능력을 확보하는 경험 제공.
*   **UX 흐름:** 사용자는 L2에서 확보한 이해를 바탕으로 파라미터를 조정(Tuning)하고 결과를 예측하는 과정에서 **실행적 통제권**을 획득합니다.
*   **시각 요소:**
    1.  **Alignment Animation (핵심):** L2 데이터가 L3 데이터로 전환될 때, 화면 중앙에 **'데이터 정렬(Alignment)' 애니메이션**이 발생합니다. 이 과정에서 이전 단계의 불확실성이 새로운 예측 가능한 상태로 치환되는 시각적 효과를 극대화합니다.
    2.  **Parameter Control:** 조정할 수 있는 슬라이더나 입력 필드가 나타나며, 사용자의 조작에 따라 실시간으로 결과(예: 예측된 통제권 지표)가 즉시 변화하는 피드백을 제공합니다.
    3.  **Feedback Loop Visualization:** 설정 변경이 시스템에 미치는 영향을 시각화하여, '내가 원하는 대로 시스템이 반응한다'는 느낌을 강조합니다.

### C. 심화 화면: 전략 (L4: 전략 및 심화)

*   **목표:** 장기적인 비즈니스 목표를 설정하고 선제적으로 대응하는 전략을 수립하는 경험 제공.
*   **UX 흐름:** 사용자는 시스템의 결과(L3)를 바탕으로 미래 시나리오를 탐색하고 최적의 경로를 설정하는 과정에서 **전략적 통제권**을 확보합니다.
*   **시각 요소:**
    1.  **Autonomous State Visualization:** 시스템이 사용자 목표에 맞춰 움직이는 상태를 추상적인 그래프가 아닌, **'미래 시나리오 지도(Future Scenario Map)'** 형태로 표현합니다. (시스템이 나를 위해 움직이는 느낌)
    2.  **ROI/Risk Mapping:** 데이터 기반의 분석 결과(ROI, 리스크)는 복잡한 표 대신, 직관적인 지표와 방향성 화살표로 제시되어 전략적 판단을 돕습니다.
    3.  **Final Control Lock:** 최종 목표 설정 시, 모든 변수가 잠금(Lock) 상태로 고정되며, 사용자가 이 경로를 확신하며 다음 행동으로 나아갈 수 있도록 강력한 **확신(Certainty)**의 느낌을 제공합니다.

## 3. 데이터 연동 및 애니메이션 상세 지시 (Developer Integration Focus)

API로부터 받는 `ProgressData`와 `ProgressStep` 구조는 모든 시각적 전환의 트리거가 됩니다.

| API 데이터 요소 | UX/애니메이션 구현 목표 | 적용 단계 |
| :--- | :--- | :--- |
| `current_level` (L2, L3, L4) | 화면 전체 레이아웃 및 색상 스키마의 근본적인 변화 트리거. | 전체 플로우 |
| `steps` 배열 | 각 단계별로 달성된 경험을 모듈화하여 보여줌. | 모든 단계 |
| `alignment_data` | L2 $\to$ L3 전환 시, 데이터가 매끄럽게 정렬되는 **'시스템적 통제권 확보 애니메이션'**의 핵심 데이터 소스. | L2 $\to$ L3 전환 |
| `total_progress` | 사용자에게 현재 위치와 최종 목표까지 남은 거리(불확실성)를 명확하게 제시. | 모든 단계 |
