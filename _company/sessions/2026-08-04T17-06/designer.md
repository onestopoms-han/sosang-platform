# 🚀 인터랙티브 가치 시각화 페이지: 디자인 시스템 및 와이어프레임 지침서

## 1. 핵심 디자인 철학 (Design Philosophy)

**목표:** 사용자가 가격을 지불하는 것이 아니라, **'통제권(Control)'을 구매한다**는 느낌을 제공합니다.
**핵심 서사:** 불안(Risk) $\rightarrow$ 진단(Diagnosis) $\rightarrow$ 청사진(Blueprint) $\rightarrow$ 실행(Action). 이 여정이 시각적으로 상승 곡선이 되도록 설계합니다.

## 2. 디자인 시스템 적용 (Visual System Application)

기존의 데이터 기반 권위 원칙을 확장하여, **'통제감 게이지(Control Gauge)'**를 핵심 비주얼 요소로 사용합니다.

### A. 색상 팔레트 (Color Palette: Authority Shift)

색상은 리스크 수준과 통제감 레벨을 직접적으로 매핑하며, 이는 시스템 가이드(`designer_system_guide.md`)에 명시된 과학적 근거를 따릅니다.

| 상태/레벨 | 색상 코드 | 의미 | 시각적 효과 (Visualization) |
| :--- | :--- | :--- | :--- |
| **안정 (Low Risk)** | `#1E8449` (Deep Forest Green 계열) | 낮은 리스크, 높은 통제감 (Basic Tier) | 안정적인 푸른색 또는 녹색 그라데이션. 신뢰감을 주는 '확정' 상태. |
| **주의 (Medium Risk)** | `#FFC300` (Amber) | 중간 리스크, 선제적 조치 필요 (Pro Tier 진입점) | 따뜻한 노란색으로 경고 및 주의를 부여. 행동을 유도하는 신호. |
| **위험 (High Risk)** | `#E74C3C` (Red) | 높은 리스크, 즉각적인 실행 요구 (Action 필요) | 강렬한 빨간색으로 긴급성과 위험성을 강조. 즉각적인 행동을 촉구하는 경고등 역할. |
| **최고 통제 (Max Control)** | `#FFD700` (Rich Gold) | 최고 수준의 통제권 확보 (Pro/Top Tier) | 골드 색상을 사용하여 '프리미엄 권위'와 성공적인 결과를 상징합니다. |

### B. 타이포그래피 및 레이아웃 (Typography & Layout)

*   **제목:** 크고 굵게, **행동 지침(Actionable)**에 집중하도록 명확하게 작성합니다.
*   **통제감 시각화:** 모든 티어 비교는 수평적인 가격표가 아닌, 수직적인 **'경로/여정 그래프'** 형태로 표현합니다.
*   **레이아웃 구조:** 좌측에는 '행동 설계자 플로우'를 설명하고, 우측에 '가격 및 통제감 여정'을 시각화하여 사용자가 스스로의 위치를 인지하게 합니다.

## 3. 인터랙티브 와이어프레임 (Interactive Wireframe Concept)

### A. 페이지 제목 및 도입부 (Header & Introduction)

*   **헤드라인:** "당신의 리스크에 따른 통제권 여정: Action Designer 플로우"
*   **도입 문구:** "우리는 단순한 솔루션을 제공하지 않습니다. 우리는 법률적 불안감을 **행동 권한(Authority)**으로 전환하는 3단계 설계자입니다." (핵심 가치 강조)

### B. 핵심 시각화 영역: 통제감 여정 그래프 (The Control Journey Graph)

이 영역은 페이지의 중앙을 차지하며, 사용자의 현재 위치와 다음 목표를 명확히 보여줍니다.

1.  **수직 축 (Y-Axis):** **통제감 레벨 (Control Level)** - 3단계로 설정합니다: 인지적 통제 $\rightarrow$ 전략적 통제 $\rightarrow$ 실행 통제.
2.  **수평 축 (X-Axis):** 서비스 패키지/가격 (Basic / Pro / Pro+).
3.  **경로 시각화:** 각 티어는 하나의 **상승하는 경로(Path)**로 표현됩니다. 사용자가 Basic에서 Pro로 이동할 때, 그래프의 색상은 Deep Forest Green $\rightarrow$ Amber $\rightarrow$ Rich Gold 순으로 변화하며, 그 사이의 간격은 '취득한 통제감'의 질적 차이를 시각화합니다.

### C. 상세 비교 테이블 (Detailed Comparison Table)

그래프 아래에 명확한 정보를 제공하는 보조 테이블을 배치합니다.

| 항목 | Basic (인지적 통제) | Pro (전략적 통제) | Pro+ (실행 통제) |
| :--- | :--- | :--- | :--- |
| **핵심 모듈** | 실시간 진단 모듈 (기본) | **동적 규제 민감도 모듈 (활성화)** | 맞춤형 실행 로드맵 및 자동화 도구 |
| **경고 시스템** | 3단계 시나리오 (단일 경고) | 동적 리스크 경보 & 대응 매트릭스 | API 연동 기반 실시간 행동 지침 제공 |
| **핵심 가치** | **진단 (Diagnosis)** | **설계 (Blueprint)** | **실행 (Action)** |
| **가격** | $X,XXX /월 | $Y,YYY /월 | $Z,ZZZ /월 |
| **시각적 강조** | Deep Forest Green | Amber/Gold 혼합 | Rich Gold 집중 |

### D. 상호작용 지침 (Interaction Guidance)

*   **마우스 오버 시:** 각 티어 위로 마우스를 올리면 해당 티어가 제공하는 '통제감의 질적 변화'에 대한 짧은 설명(예: "Pro는 리스크를 예측하고 전략을 세우게 합니다.")이 툴팁으로 표시되어야 합니다.
*   **선택 시:** 사용자가 특정 티어를 클릭하면, 해당 경로가 활성화되며, 그래프 상에서 해당 지점이 **Rich Gold**로 하이라이트되고, 그 아래에 '이 패키지를 선택했을 때 얻게 되는 통제권의 변화'에 대한 서사가 팝업으로 제공되어야 합니다.
