## 📊 SSI 핵심 데이터 포인트 및 변화 로직 정의

제품 가치를 '시스템 통제권 확보 경험'으로 재정립하기 위해, 단순한 결과 지표가 아닌 **불안정성, 수렴, 안착**이라는 감성적/심리적 상태를 정량화하는 데 초점을 맞추어 다음 4가지 핵심 지표를 제안합니다.

### 1. 변동성 지수 (Volatility Index)
*   **측정 대상:** 실제 결과값(예: 수확량, 품질 변이 등)의 표준편차 또는 상대적 변화율.
*   **핵심 역할:** 시스템의 '불안정성(Unstable)' 상태를 측정합니다.

| 단계 | 지표 변화 로직 (수학적 표현) | 학술적 근거 및 해석 | 시각화 방향 |
| :--- | :--- | :--- | :--- |
| **불안정 (Unstable)** | $\text{Volatility} \uparrow$ (높은 표준편차) | 불확실성이 높을수록 결과값의 분포가 넓어짐. 이는 예측의 어려움과 높은 위험(Risk)에 해당함. | 파도 모양, 넓게 퍼진 분포 |
| **수렴 (Converging)** | $\text{Volatility} \downarrow$ (표준편차 감소) | 데이터가 특정 범위로 좁혀지기 시작하며, 시스템이 안정화되는 과정. 변동성이 감소하는 추세. | 수축하는 곡선 또는 좁아지는 영역 |
| **안착 (Stable)** | $\text{Volatility} \approx \text{Min}$ (낮은 표준편차) | 시스템이 목표 상태에 도달하여 결과가 매우 일관됨. 예측 가능성이 극대화됨. | 평평한 선, 최소값에 수렴하는 점 |
*   **데이터 연동:** $\text{StabilityMetrics}$ 중 **Variance Score**와 직접 연결됩니다.

### 2. 목표 편차 지수 (Deviation Index)
*   **측정 대상:** 현재 결과값과 사용자가 설정한 이상적인 목표 값(Target Value) 간의 거리 또는 오차.
*   **핵심 역할:** 시스템이 목표 상태로부터 얼마나 벗어나 있는지를 측정하며, '통제권 확보' 과정의 진행 정도를 보여줍니다.

| 단계 | 지표 변화 로직 (수학적 표현) | 학술적 근거 및 해석 | 시각화 방향 |
| :--- | :--- | :--- | :--- |
| **불안정 (Unstable)** | $\text{Deviation} \gg \text{Threshold}$ (목표로부터 크게 벗어남) | 목표 달성이 불확실하며, 큰 오차 범위 내에 존재함. 통제권이 약함을 반영. | 목표선에서 멀리 떨어진 위치 |
| **수렴 (Converging)** | $\text{Deviation} \rightarrow \text{Threshold}$ (점진적으로 목표에 접근) | 사용자가 개입하여 시스템을 조정하면서 목표값으로 이동하고 있음을 나타냄. | 목표선에 점차 가까워지는 경로 |
| **안착 (Stable)** | $\text{Deviation} \approx 0$ (목표 값과 일치) | 시스템이 목표 지점에 도달하여 완벽한 통제 상태를 의미함. | 목표선 위에 정확히 위치 |
*   **데이터 연동:** 사용자가 설정한 $\text{Target Value}$ 대비 실시간 측정값을 비교하는 방식으로 표현됩니다.

### 3. 제어 일관성 지수 (Control Consistency Index)
*   **측정 대상:** 시스템이 지정된 제어 범위 내에서 얼마나 일관되게 작동했는지의 비율. (예: 설정한 온도/습도 범위 내에 유지된 시간 비율).
*   **핵심 역할:** 사용자의 '행동 가능한 실행 계획(Actionable Blueprint)' 준수 정도, 즉 통제권 확보의 질을 측정합니다.

| 단계 | 지표 변화 로직 (수학적 표현) | 학술적 근거 및 해석 | 시각화 방향 |
| :--- | :--- | :--- | :--- |
| **불안정 (Unstable)** | $\text{Consistency} \downarrow$ (범위 이탈 빈번) | 시스템이 제어 범위를 벗어나 불안정한 상태를 반복함. 통제 실패의 증거. | 범위 밖으로 벗어나는 시각적 오류나 경고 표시 |
| **수렴 (Converging)** | $\text{Consistency} \uparrow$ (범위 내 유지 시간 증가) | 사용자의 조정(Actionable Blueprint 실행)이 성공적으로 시스템을 제어하기 시작함. 일관성이 높아짐. | 제어 범위 내에 머무는 지속 시간 강조 |
| **안착 (Stable)** | $\text{Consistency} = 100\%$ (지속적 유지) | 시스템이 설정된 최적의 상태를 지속적으로 유지함. 완벽한 통제권 확보. | 채워진 영역 또는 완전한 범위 표시 |
*   **데이터 연동:** 사용자가 정의한 **KPIs**와 **E2E 테스트 결과**를 기반으로 계산됩니다.

### 4. 인식된 위험/신뢰 지수 (Perceived Risk / Trust Index)
*   **측정 대상:** 시스템의 현재 상태(SSI 수준)가 사용자에게 주는 심리적 안정감과 신뢰도. 이는 실제 데이터 외적인 감성적 요소를 반영합니다.
*   **핵심 역할:** 재무적 손실 회피(Loss Aversion)를 다루는 UX 철학에 따라, 불안정성 감소가 어떻게 **안도감(Relief)**으로 전환되는지를 표현합니다.

| 단계 | 지표 변화 로직 (수학적 표현) | 학술적 근거 및 해석 | 시각화 방향 |
| :--- | :--- | :--- | :--- |
| **불안정 (Unstable)** | $\text{Risk Index} \uparrow$ (높은 불안감) | 불확실성은 심리적 고통(Anxiety)을 유발하며 손실 회피 행동을 촉진함. | 붉은색 계열, 긴장된 애니메이션 |
| **수렴 (Converging)** | $\text{Risk Index} \downarrow$ (불안감 감소) | 통제권이 확보되기 시작하면서 심리적 안정감을 경험함. 불안정성 감소가 직접적인 안도감으로 전환됨. | 주황색/노란색 계열로 점진적 변화 |
| **안착 (Stable)** | $\text{Risk Index} \approx 0$ (최소 위험) | 시스템에 대한 절대적인 신뢰와 안정감을 확보함. '통제권 회복'이라는 감성적 보상 제공. | 녹색 계열, 평온하고 확고한 애니메이션 |
*   **데이터 연동:** $\text{Volatility Index}$ 및 $\text{Deviation Index}$의 변화율을 기반으로 **Emotion Flow Manager**에 입력됩니다.
