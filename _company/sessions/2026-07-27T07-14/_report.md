### 1. 기술 스택 정의 (Technology Stack Definition)

쇼핑몰 MVP의 핵심 요구사항인 **결제 시스템 연동**과 **사용자 계정 관리 모듈**을 위해 다음 기술 스택을 제안하며, 이는 기존에 구축된 백엔드 로직(`action_plan_service.py`, `data_schema.ts` 등)과의 통합 가능성을 고려했습니다.

| 모듈 | 핵심 기능 | 추천 스택 | 선정 이유 (WHY) |
| :--- | :--- | :--- | :--- |
| **Backend / API** | 주문, 재고, 사용자 인증/인가 처리 | **Node.js (Express/NestJS)** 또는 **Python (FastAPI)** | 기존에 사용된 기술과의 일관성 유지 및 비동기 처리의 효율성 확보. 특히, 데이터 흐름 검증을 위해 강력한 타입 시스템(TypeScript 권장)이 필수적입니다. |
| **Database** | 상품 정보, 사용자 데이터, 주문 기록 저장 | **PostgreSQL** | 트랜잭션 무결성이 매우 중요하며, 복잡한 관계형 데이터와 학술적 지표(KPI)의 구조화된 저장을 위해 가장 안정적인 선택입니다. |
| **Payment Integration** | 결제 프로세스 및 보안 | **Stripe API (또는 국내 PG 연동)** | 외부 시스템과의 안전하고 표준화된 인터페이스를 통해 민감한 금융 거래의 보안 및 규정 준수를 확보해야 합니다. |
| **Authentication/Auth** | 사용자 로그인, 권한 관리 | **JWT + 세션 기반 인증** | 시스템 통제권 확보라는 목표에 따라, 토큰 기반으로 상태 변화(L1 $\to$ L2 $\to$ L3)에 따른 권한을 명확하게 분리하고 검증합니다. |
| **Frontend (UI/UX)** | 사용자 인터페이스 및 데이터 시각화 | **React / Next.js** | 기존의 프론트엔드 경험과 시각적 요구사항(골드 액센트, 파동 효과)을 가장 효율적으로 구현하며, 데이터 흐름 기반의 동적인 UI를 구축하기에 적합합니다. |

### 2. 최우선 기능 목록 (Feature List - MVP Scope)

MVP 단계에서는 핵심 비즈니스 가치(시스템 통제권 확보 경험)를 증명하는 데 집중해야 합니다. 다음은 필수 기능과 차별화 기능을 구분한 목록입니다.

#### A. Core Feature (필수 구현 - 시스템 안정성 확보)

1.  **사용자 계정 관리 (User Management Module):**
    *   회원가입, 로그인/로그아웃 (JWT 기반 인증).
    *   사용자 프로필 관리 (개인 정보 및 권한 수준(L1/L2/L3) 설정 기능 포함).
2.  **상품 등록 및 관리 (Product Management Module):**
    *   상품 정보 CRUD (생산자 정보, 가격, 재고).
    *   상품 상태 관리 (판매 가능/비활성).
3.  **주문 시스템 (Order System):**
    *   사용자가 상품을 선택하고 주문을 요청하는 기능.
    *   주문 상태 추적 (대기 $\to$ 결제 진행 중 $\to$ 완료).

#### B. Critical Feature (핵심 가치 증명 - 전환 경험 확보)

1.  **결제 시스템 연동 (Payment Integration):**
    *   선택된 PG사 또는 Stripe를 통한 안전한 결제 흐름 구현.
    *   결제 성공/실패에 따른 백엔드 상태(Order Status) 자동 업데이트 로직 구현.
2.  **데이터 시각화 및 보고 (Data Visualization & Reporting):**
    *   사용자별 **'시스템 통제권 확보 경험' 지표** 대시보드 구축.
    *   ROI 시뮬레이션 결과(`roiCalculator.ts` 연동)를 사용자에게 제공하는 화면 구현.

#### C. Future Feature (Phase 2/3 - 확장 고려 사항)

1.  **재고 자동화 (Inventory Automation):** 실시간 재고 반영 로직 및 외부 시스템(생산자 DB)과의 동기화.
2.  **커뮤니티 기능:** 생산자와의 데이터 흐름을 강화하는 소통 채널 구축.
3.  **고급 리포팅:** 거시 경제 지표와 시스템 사용 패턴 간의 상관관계를 시각화하는 심층 분석 대시보드.

### 3. 초기 개발 로드맵 (Initial Development Roadmap)

MVP 목표는 **시스템 안정성 확보**에 중점을 두고, 가장 핵심적인 데이터 흐름을 완성하는 것입니다.

| 단계 | 목표 (Goal) | 주요 작업 내용 (Key Tasks) | 예상 기간 (Est.) | 검증 포인트 (Verification Focus) |
| :--- | :--- | :--- | :--- | :--- |
| **Phase 1: Foundation (기반 구축)** | 사용자 인증 및 데이터 모델 확정 | DB Schema 정의 (`User`, `Product`, `Order` 테이블). JWT 기반 Auth API 구현. `data_schema.ts`와 백엔드 엔드포인트 명세서 최종 확정. | 2주 | 데이터 무결성(Schema Validation) 테스트 통과 확인. |
| **Phase 2: Transaction (거래 흐름)** | 주문 및 결제 시스템 통합 | 상품 등록/조회 API 구현. 주문 생성 $\to$ 결제 요청 $\to$ 상태 업데이트의 End-to-End Flow 구현. PG사 연동 모듈 개발. | 3주 | 결제 실패 시 에러 처리 로직(Error Handling) 완벽 검증. |
| **Phase 3: Value Delivery (가치 제공)** | 데이터 시각화 및 전환 경험 통합 | 사용자 대시보드 API 구축. ROI 계산 결과를 프론트엔드로 전달하는 API 연동. L1 $\to$ L2 $\to$ L3 상태 변화에 따른 UI/UX 애니메이션 구현. | 3주 | `KPI_Gauge`의 실시간 데이터 바인딩 및 애니메이션(골드 액센트) 일관성 확인. |
