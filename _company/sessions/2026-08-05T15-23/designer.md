# 🖼️ 비전 선언문 기반 와이어프레임 디자인 브리프

## 🎯 디자인 목표
사용자에게 복잡한 리스크 환경에서 **'실행 가능한 통제권(Action Authority)'**을 부여한다는 플랫폼의 핵심 가치를 직관적이고 강력하게 전달한다. 시각적 계층 구조를 통해 사용자의 불안감을 해소하고, 시스템의 예측 능력과 행동 권한을 강조한다.

## 📐 레이아웃 구조 (3-Part Flow)
전체 와이어프레임은 위에서 아래로 흐르는 **'인식 $\rightarrow$ 분석 $\rightarrow$ 통제'**의 논리적 흐름을 따라 구성한다. 각 섹션은 명확한 경계선과 대비되는 색상(Deep Forest Green, Amber, Red)을 활용하여 감정 상태 변화를 반영한다.

### 1. 누구 (Who): 사용자 및 페르소나 설정 영역
**목표:** 사용자의 현재 위치와 그들이 느끼는 심리적 상태('불안')를 명확히 정의하여 공감대를 형성하고, 플랫폼의 타깃을 명시한다.

| 요소 | 추천 그래픽 요소 | 디자인 지침 | 목적 |
| :--- | :--- | :--- | :--- |
| **사용자 페르소나** | 아바타/아이콘 (실제 직원 이미지 대신 추상적 형태) | 최소화된 인물 실루엣 또는 마스크 형태로 처리하여 익명성과 보편성을 확보. | 사용자가 자신을 투영하게 함. |
| **현재 상태 표시** | **Pain Gauge 위젯 (Risk Meter)** | 현재 리스크 레벨(Low/Medium/High)을 시각화하는 게이지 바 및 색상 변화 적용 (Deep Green $\rightarrow$ Amber $\rightarrow$ Red). | 사용자의 '불안' 수준을 즉각적으로 인지시킴. |
| **핵심 메시지** | 타이포그래피 강조 | "당신의 현재 상태는 [Risk Level]입니다."와 같이 명확한 진단 문구를 배치. | 플랫폼이 단순 정보가 아닌 '진단 도구'임을 강조. |

### 2. 무엇을 해결하는가 (Problem): 현황 분석 및 리스크 제시 영역
**목표:** 데이터 기반의 복잡한 규제 환경과 잠재적 위험 요소를 시각화하여, 현재 상황의 비효율성과 위험성을 명확히 드러낸다.

| 요소 | 추천 그래픽 요소 | 디자인 지침 | 목적 |
| :--- | :--- | :--- | :--- |
| **규제/시장 복잡성** | **인과관계 플로우차트 (Flowchart)** | 규제 변화가 어떻게 리스크로 이어지는지(A $\rightarrow$ B $\rightarrow$ C)를 화살표와 박스로 표현. | 문제의 구조적 이해를 돕고, 인과관계를 시각화. |
| **리스크 지표** | **다중 차트 (Multi-Metric Chart)** | 여러 규제 변수(예: 정치적 안정성, 시장 변화율 등)를 비교하는 복합 대시보드 형태의 그래프. | 데이터 기반 분석이 필요함을 시사. |
| **위험 경고** | **Red Zone 강조 영역** | 가장 위험한 지표에 **Red 배경**을 적용하고 텍스트를 볼드 처리하여 즉각적인 긴급성을 부여. | 위험 상황에 대한 사용자의 감정적 반응(경고)을 극대화. |

### 3. 우리가 제공하는 가치 (Solution): 통제권 확보 및 실행 영역
**목표:** 플랫폼이 제공하는 독창적인 방법론('진단 $\rightarrow$ 예측 $\rightarrow$ 행동')을 명확하게 제시하며, 사용자가 얻게 될 '통제권'과 '실행력'을 강조한다.

| 요소 | 추천 그래픽 요소 | 디자인 지침 | 목적 |
| :--- | :--- | :--- | :--- |
| **핵심 프로세스** | **3단계 인터랙티브 플로우 (Process Flow)** | 1단계(진단) $\rightarrow$ 2단계(예측) $\rightarrow$ 3단계(행동 권한)를 명확하게 연결하는 선형 또는 순환형 화살표 구조. | 시스템의 작동 방식과 논리적 흐름을 직관적으로 설명. |
| **통제권 시각화** | **Control Indicator (Gold Emphasis)** | 각 단계가 완료될 때마다 '통제권 확보율'이 점진적으로 상승하는 게이지나 궤적(Trajectory) 애니메이션 적용. | 사용자가 능동적으로 통제권을 얻고 있음을 시각적으로 증명. |
| **CTA 강조** | **Action Button Group** | 각 단계 종료 지점에 맞춰, 다음 행동을 유도하는 명확하고 강력한 CTA 버튼 배치 (예: "다음 단계로 이동", "행동 옵션 선택"). | 사용자가 주저 없이 '실행'하도록 유도. |
