# 📋 작업 브리프

**원 명령:** 게 쇼핑몰에들어가되 되낭

## 요약
쇼핑몰 MVP 구현에 집중하며, 이전에 확정된 L1→L2→L3 단계별 시스템 구조를 실제 기능적 웹페이지로 옮기는 작업입니다. 특히, 최신 지침(친근한 상거래 용어 사용)을 반영하여 과학적 권위와 사용자 친화적인 디자인 사이의 균형점을 찾는 것이 핵심 목표입니다.

## 분배
- **💻 코다리**: 현재까지 확정된 L1→L2→L3 단계별 차등 단가 로직(State-Driven)을 기반으로, 쇼핑몰의 '시스템 진단 위젯'과 연동되는 결제 플로우(Checkout Flow)의 인터랙티브 컴포넌트 MVP 코드를 작성하고 테스트하세요. 특히, L1에서 L2로 전환될 때 발생하는 가격/권위 지수 변화를 시뮬레이션할 수 있도록 상태 관리 로직을 견고하게 구현해야 합니다.
- **🎨 Designer**: 개발자가 구현할 '시스템 진단 위젯'과 연동되는 쇼핑몰 UI의 최종 디자인 브리프를 업데이트해 주세요. '과학적 권위'는 유지하되, 사용자가 거부감 없이 느끼도록 색상 팔레트와 타이포그래피에서 지나치게 기계적이거나 통제적인 느낌을 완화하는 구체적인 시각적 액션(Visual Actions)과 가이드를 추가해야 합니다.
- **✍️ Writer**: 쇼핑몰 페이지 내에 들어갈 주요 카피라이팅 세트를 순화하여 재작성해 주세요. 의학 용어나 '통제(Control)' 같은 단어 대신, '베타글루칸이 풍부하게 함유되어 건강한 일상에 도움을 줄 수 있습니다'와 같이 일반 식품법을 준수하는 친근하고 대중적인 상거래 문구로 대체해야 합니다. (예: 제품 설명, 장점 리스트, CTA 버튼 문구 등)
