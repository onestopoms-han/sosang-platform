# 🚀 SSI 인터랙티브 프로토타입 사용자 여정 카피라이팅 (Core Copy Set)

이 카피는 랜딩 페이지의 각 섹션(혹은 단계별 모달/애니메이션)에 적용되어 사용자의 감정 변화를 유도합니다.

## Stage 1: 불안정 인식 (Anxiety & Problem Identification)
**목표:** 사용자가 현재 자신의 상태가 '통제되지 않고 불확실하다'는 느낌을 명확히 인지하게 하여 문제 해결의 필요성을 각인시킵니다. (Focus: **불안정**)

| 요소 | 카피라이팅 제안 | 의도 및 톤앤매너 |
| :--- | :--- | :--- |
| **메인 헤드라인 (H1)** | **당신의 신체 시스템, 과연 안정적인가?** | 질문을 던져 사용자의 내적 불안감을 즉각적으로 자극하며 주의를 집중시킵니다. |
| **서브 카피 (Subcopy)** | 복잡한 일상 속에서, 몸 내부의 균형은 언제나 예측 불가능합니다. 미세한 불균형이 누적되어 활력과 집중력을 앗아가는 근본적인 원인을 확인하십시오. | 문제의 심각성을 시스템적 관점에서 제시하며 공감대를 형성합니다. (학술적 권위 유지) |
| **CTA 버튼** | 현재 상태 진단하기 | 행동을 유도하되, '진단'이라는 과학적 용어를 사용하여 신뢰감을 부여합니다. |

## Stage 2: 솔루션 및 신뢰 확보 (Solution & Trust Building)
**목표:** 송이버섯이 단순한 영양제가 아닌, '데이터 기반 시스템 안정화의 핵심 도구'임을 제시하여 사용자의 불안을 해소하고 신뢰를 구축합니다. (Focus: **신뢰**)

| 요소 | 카피라이팅 제안 | 의도 및 톤앤매너 |
| :--- | :--- | :--- |
| **섹션 헤드라인** | **시스템의 안정성을 설계하다: 데이터가 보여주는 변화의 과정** | 제품이 단순한 보충제가 아닌, 체계적인 '관리 솔루션'임을 강조합니다. |
| **본문 도입부 (Body Intro)** | 우리는 단순한 영양 공급을 넘어, 미생물 대사학 및 환경 데이터를 기반으로 신체 내부 시스템의 변화를 측정합니다. 참송이골드는 이 데이터 흐름을 시각화하여, 당신이 통제할 수 있는 명확한 경로를 제시합니다. | 과학적 근거(데이터)와 '통제권'이라는 핵심 가치를 연결하여 권위를 높입니다. |
| **핵심 메시지 (Mechanism)** | **불안정($\rightarrow$) 안정:** 보이지 않는 환경 변화를 측정하고, 최적의 균형 상태로 전환하는 명확한 시스템을 경험하십시오. | 개발팀이 구현할 '불안정 $\rightarrow$ 안정' 애니메이션에 직접적으로 연결되는 핵심 로직을 설명합니다. |
| **CTA 버튼** | 나의 SSI 데이터 확인하기 | 구체적인 결과(데이터)를 보겠다는 명확한 기대감을 심어줍니다. |

## Stage 3: 통제권 회복 (Control & Empowerment)
**목표:** 사용자가 최종적으로 자신의 건강 시스템에 대한 '통제권'을 되찾았다는 성취감과 자신감을 느끼도록 동기를 부여합니다. (Focus: **통제**)

| 요소 | 카피라이팅 제안 | 의도 및 톤앤매너 |
| :--- | :--- | :--- |
| **최종 헤드라인** | **이제, 당신의 건강 시스템을 완벽하게 통제하십시오.** | 사용자에게 최종적인 주체성(Agency)을 부여하며 강력한 동기 부여를 제공합니다. |
| **마무리 서브카피** | 데이터는 곧 지식이며, 이 데이터를 기반으로 당신은 가장 현명하고 안정적인 선택을 할 힘을 얻게 됩니다. 스스로 변화의 주체가 되십시오. | 수동적인 소비자가 아닌, 능동적인 관리자(Master)로 포지셔닝합니다. |
| **최종 CTA** | 맞춤형 시스템 시작하기 | 행동으로 이어지되, '시작'이 단순한 구매가 아닌 '관리 여정의 개시'임을 강조합니다. |
