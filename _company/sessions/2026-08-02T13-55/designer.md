## 🖼️ 실시간 자문단 컴포넌트 상태 매핑 가이드 (Advisory Flow Visual Mapping Guide)

다음은 API의 주요 상태(`connect`, `speak`, `state` 등)와 이에 대응하는 시각적 디자인 토큰 및 인터랙션 규칙을 정의합니다. 핵심 색상인 **다크 미드나잇 퍼플**과 **골드 브라운 계열**을 기준으로 설정합니다.

### 1. 핵심 상태별 디자인 정의

| API 상태 (Backend Logic) | 사용자 경험 (Frontend State) | 주요 시각적 요소 및 색상 토큰 | 인터랙션 가이드라인 |
| :--- | :--- | :--- | :--- |
| **Connecting** | 연결 중 (Waiting for Agents) | 배경: Deep Navy (#0A0A1A). 로딩 인디케이터: 골드 브라운 스피너 애니메이션. | 시스템이 외부 자문단과의 WebSocket 연결을 시도하고 있음을 명확히 표시. 사용자는 대기 상태임을 인지. |
| **Speaking** | 대화 중 (Active Interaction) | 카드/모달 배경: Glassmorphism 효과 적용 (반투명 골드). 텍스트 색상: 밝은 미드나잇 퍼플 (#B189FF). | 메시지 입력창은 활성화 상태로 유지. 자문단 응답이 들어오면 실시간으로 텍스트가 스트리밍되도록 구현. |
| **Thinking** | AI 사고 중 (Processing) | 배경: 차분한 미드나잇 퍼플 그라데이션. 애니메이션: 골드 브라운의 점진적 확산(Pulse). | 답변이 생성되는 동안 사용자에게 '시스템이 고차원적인 분석을 수행 중'임을 시각적으로 전달하여 인내심 유도. (답변 지연 시 명확한 로딩 표시) |
| **State Update** | 상태 변화 (권한 양도 등) | 전환 효과: 부드러운 Morphing 애니메이션. 권한/상태 변경 시, 골드 라인 또는 아이콘에 미세한 빛 번짐(Glow) 적용. | '발언권 양도'와 같은 중요한 결정 사항은 명확하고 확정적인 시각적 피드백을 제공해야 함. |
| **Result** | 최종 결과 제시 (Conclusion) | 배경: 가장 안정적인 골드 브라운 톤. 레이아웃: 정보의 계층 구조를 강조하는 깔끔한 카드 배치. | 모든 대화 흐름이 종료되었음을 알리고, 핵심 결론(`Action Blueprint`)을 시각적으로 압도적으로 제시. |

### 2. 디자인 시스템 보강 (Interaction Guidelines)

#### A. Glassmorphism 적용 규칙
모든 상호작용 패널(Card/Modal)에는 **Glassmorphism** 효과를 기본으로 적용합니다. 이는 데이터의 투명성을 강조하여, 사용자가 AI의 복잡한 분석 과정에 '참여하고 있다'는 느낌을 줍니다.

*   **배경:** 배경은 어두운 계열(Deep Navy 또는 Midnight Purple)로 설정하여 콘텐츠가 부각되도록 합니다.
*   **경계선 (Border):** 테두리는 매우 얇고 은은한 **골드 브라운 (#C5A880)** 색상으로 처리하여, 고급스럽고 과학적인 느낌을 유지합니다.

#### B. 타이포그래피 및 강조 규칙
1.  **핵심 지표 강조:** `Control Score`와 같은 핵심 KPI는 항상 **Rich Gold** 폰트와 가장 큰 크기로 배치하고, 그 아래에 시스템 지표 설명은 작은 폰트(8px)로 표시하여 시각적 권위를 확보합니다. (이는 기존 `designer_system_guide.md`의 원칙을 준수함.)
2.  **상태 피드백:** 'Thinking' 상태에서 사용자의 입력창 주변에 **골드 브라운 색상의 미세한 깜박임(Pulse)** 효과를 적용하여, 시스템이 능동적으로 처리 중임을 직관적으로 알립니다.

#### C. 애니메이션 흐름 (Flow Animation)
상태 전환 시, 단순히 텍스트가 바뀌는 것이 아니라, **데이터의 변화**가 시각화되어야 합니다.

*   `Connecting` $\rightarrow$ `Speaking`: 연결이 성공하면, 골드 라인이 빠르게 활성화되는 애니메이션을 사용하여 신속한 연결을 강조합니다.
*   `Thinking` $\rightarrow$ `Result`: 사고 과정이 완료되면, 퍼플 색상이 서서히 풀리면서 최종 골드 결과 카드가 부드럽게 나타나는 전환 효과를 적용하여, **불안(Thinking)에서 통제권 확보(Result)**로의 감성 흐름을 시각적으로 완성합니다.
