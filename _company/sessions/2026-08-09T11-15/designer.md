## 💡 제안 산출물: HS 코드 분류 인터랙티브 가이드라인 디자인 원칙 (Visual Guide Blueprint)

이 가이드는 사용자가 품목 코드를 입력했을 때, **'형태(Form)'**와 **'공정(Process)'**이라는 두 가지 핵심 축을 중심으로 분류 경로를 제시하는 데 중점을 둡니다.

### 1. 핵심 디자인 원칙 (Visual Design Principles)

| 요소 | 적용 원칙 | 목적 |
| :--- | :--- | :--- |
| **레이아웃** | 수직 흐름 기반의 트리 구조 (Vertical Flow/Tree Structure) | 복잡한 논리를 위에서 아래로 따라가며 단계적으로 이해하도록 유도. |
| **색상 시스템** | 상태(State) 및 공정(Process)에 따른 3단계 색상 팔레트 적용 | 사용자가 즉각적으로 해당 품목의 '위험도'와 '형태'를 인지하게 함. |
| **인터랙션** | 선택 기반 분기 (Branching Selection) | 특정 상태 입력 시, 다음 단계의 분류 규칙으로 즉시 이동하는 동적 흐름 제공. |
| **계층 구조** | 가장 큰 요소는 '상태(Form)', 중간 요소는 '공정(Process)', 가장 작은 요소는 '코드(Code)'로 설정. | 정보의 중요도에 따른 시각적 계층을 명확히 함. |

### 2. Decision Flowchart 설계 (Flowchart Blueprint)

사용자가 특정 품목이나 형태를 선택했을 때 따라가야 할 논리적 경로입니다. 이는 인터랙티브 시스템의 백본이 됩니다.

**[시작점: 품목 입력] $\rightarrow$ [1단계: 물리적 형태 판별] $\rightarrow$ [2단계: 제조 공정 확인] $\rightarrow$ [3단계: 최종 HS 코드 매핑]**

#### A. 1단계: 물리적 형태 (Form) 분기 (Primary Branching)
사용자가 입력한 품목이 다음 중 어디에 해당하는지 즉시 판단합니다.

*   **노드 1.1 (가루 상태):** $\rightarrow$ **[8101.10] 가루** (Powder)로 연결
*   **노드 1.2 (비가공/벌크 형태):** $\rightarrow$ **[8101.94] 괴(Block)/잉곳** 또는 **[8101.97] 웨이스트/스크랩**으로 연결
*   **노드 1.3 (가공된 금속):** $\rightarrow$ **[8101.96] 선(Line)**, **[8101.99] 기타** 또는 세부 가공 형태(판, 바)로 분기

#### B. 2단계: 제조 공정 (Process) 심화 (Secondary Branching)
선택된 물리적 형태에 따라 적용될 제조 공정을 확인합니다.

*   **If Node 1.1 (가루 상태):** $\rightarrow$ **[소결(Sintering)]**으로 연결 $\rightarrow$ *다음 노드로 이동하여 최종 코드 확정.*
*   **If Node 1.2 (비가공 형태):** $\rightarrow$ **[압연(Rolling) 또는 인발(Drawing)]**로 연결 $\rightarrow$ *최종 제품 형태(바, 판, 시트)를 도출.*
*   **If Node 1.3 (가공된 형태):** $\rightarrow$ **[형태 확인]**으로 연결 $\rightarrow$ *선(Line), 바(Bar), 판(Plate), 시트(Sheet) 중 최종 형태 선택.*

#### C. 3단계: 최종 매핑 및 예외 처리
최종적으로 도출된 형태와 공정 조합을 기반으로 HS 코드 목록을 제시합니다.

*   **결과 박스:** 도출된 **[8101.10 / 8101.96 / 8101.94]** 등 최종 코드를 **골드 강조**로 표시하고, 하단에 **`[근거: Writer 매뉴얼]`**을 작은 폰트로 명시합니다.

### 3. 인터랙티브 가이드라인 디자인 제안 (Visual Guide Implementation)

사용자가 실제로 시스템을 사용할 때 적용할 구체적인 시각적 구현 방식입니다.

#### A. 컬러 코드 정의
| 상태/공정 | 색상 코드 | 의미 | 사용 예시 |
| :--- | :--- | :--- | :--- |
| **안정/원재료** | **Deep Forest Green (#1E4D2B)** | 가공 전 원자재, 안정된 벌크 형태. | 블록(Block), 잉곳(Ingot) |
| **변환/과정** | **Amber (#FFC300)** | 소결, 압연 등 물리적 변형 과정 중. | Sintering, Rolling 단계 |
| **최종 제품** | **Rich Gold (#FFD700)** | 최종 가공된 형태(선, 판, 바) 및 분류 코드. | Bar, Plate, Line (8101.96) |
| **예외/주의** | **Red (#CC0000)** | 제외 품목 또는 잠재적 위험 요소 경고. | 장신구류, 특수 합금(제85류 참조) |

#### B. 시각적 흐름 예시 (Mockup Concept)
1.  **입력 창:** 사용자가 `Tungsten Bar`를 입력합니다.
2.  **분기 박스 1 (Form):** "형태 확인: **바(Bar)**"가 Rich Gold로 표시됩니다.
3.  **분기 박스 2 (Process):** "제조 공정: **압연/인발(Rolling/Drawing)**"이 Amber로 강조됩니다.
4.  **결과 영역:** 최종적으로 `8101.96` 코드가 가장 크고 골드 색상으로 표시되며, 그 아래에 작은 글씨로 `[근거: Writer 매뉴얼]`이 명시됩니다.
