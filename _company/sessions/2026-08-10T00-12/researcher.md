## 📦 HS Code 8423 (계량 기기) 데이터 분석 및 지식 베이스 업데이트

### 1. 주요 Subheading별 정의와 사용 사례 요약

HS Code 8423은 **계량 기기(Weighing machinery)**를 포괄하며, 측정 원리(전자식, 무게 균형 등)에 따라 세부적으로 분류됩니다. 핵심은 '무게 측정'을 자동화하거나 보조하는 모든 장치를 포함한다는 점입니다.

| Subheading | 주요 정의 및 범위 | 주요 사용 사례 (Industry Focus) |
| :--- | :--- | :--- |
| **8423** (전체) | 5cg 이상의 민감도 균형(90.16 제외)을 가지는 모든 계량 기기. 무게를 측정하거나, 무게에 따라 물품을 분류/포장하는 모든 장치 포함. | 모든 제조, 유통, 식품 가공 분야의 원자재 및 완제품 중량 관리 시스템. |
| **8423.10** | 개인용 계량 기기 (예: 아기 체중계, 가정용 저울). | 소매업체(소매점) 또는 최종 소비재 생산 시 사용되는 개인 단위의 정밀 측정 장비. |
| **8423.20** | 컨베이어 벨트 위에서 상품을 연속적으로 계량하는 저울 (총계기 또는 통합식). | 대규모 제조 공장, 물류 센터에서의 자동화된 원자재/반제품 흐름 관리. |
| **8423.30** | 정량된 무게를 포장재(봉투/용기)에 투입하거나 배출하는 데 사용되는 정량 저울 (호퍼 저울 포함). | 식품 및 화학 물질의 정량 투입, 완제품 포장 작업 시 사용되는 정밀 계량 장치. |
| **8423.81** | 최대 중량 용량이 30kg 이하인 계량 기기. | 소규모 생산 시설이나 개인 사업자의 측정 장비. |
| **8423.82** | 최대 중량 용량이 30kg 초과 ~ 5,000kg 이하인 계량 기기. | 중소 규모의 제조 공장 또는 물류 창고 관리 시스템. |
| **8423.90** | 모든 종류의 계량 기기 및 계량 기기의 부품 (예: 커서 무게, 기타 부속품). | 계량 장치 자체와 그 구성 요소에 대한 세부 관세 분류 및 부품 거래 관리. |

### 2. 고객 혼동 리스크 포인트 (Risk Points)

HS Code 8423은 광범위하며, 특히 다른 섹션과의 구분점과 부품 분류에서 오류가 발생하기 쉽습니다.

| 리스크 포인트 | 상세 설명 | 위험 유형 | 해결 방안 (서비스 모듈 적용) |
| :--- | :--- | :--- | :--- |
| **90.16 제외 항목의 혼동** | 8423은 '균형(Balance)'을 제외하며, 균형(예: 수은 온도계 등)은 90.16에 속합니다. 이 경계를 명확히 이해하지 못하면 계량 기기 자체와 측정 도구 간의 분류 오류가 발생할 수 있습니다. | 관세 오분류 리스크 | 사용자가 '균형'과 '측정 장치'의 차이를 인지하도록 UX/UI에서 명시적인 안내 제공. |
| **부품(PARTS) 분류** | 계량 기기의 부속품(Scale beams, 플랫폼 등)이 8423 아래에 포함되지만, 다른 섹션(예: 71.16 금속 가공품)과의 관계에서 모호성이 발생할 수 있습니다. | 원산지 증명 및 부가가치세 계산 오류 리스크 | 부품 분류에 대한 명확한 규칙집(Rulebook)을 구축하고, 각 부품의 사용 목적을 명시적으로 기록하여 DB화. |
| **기능 기반 vs. 형태 기반 분류** | 장치의 물리적 형태(예: 테이블형)보다는 **무게 측정 원리**와 **사용 목적(연속 계량, 정량 투입)**에 따라 분류해야 함을 이해하는 데 혼란이 있을 수 있습니다. | 잘못된 HS 코드 적용 리스크 | 기능별 분류 기준을 시스템 내부에 명확히 정의하고, 고객에게는 '기능 기반의 분류 체계'를 교육 자료로 제공. |
| **용량 기반 분류 (8423.81 vs 8423.82)** | 중량 용량(30kg) 기준에 따른 세부 분류가 복잡하여, 실제 장비의 사양과 관세율 적용 간의 연관성을 명확히 파악해야 함. | 세율 적용 오류 리스크 | 시스템이 사용자가 입력한 용량을 기준으로 적절한 하위 코드를 자동 추천하는 기능을 강화. |

**목표:** HS 코드 8423 분류가 관세율, 원산지 규정 및 부품 거래에 미치는 영향을 이해하고, 정확한 분류를 통해 리스크를 최소화하는 실행 방안을 습득한다.
