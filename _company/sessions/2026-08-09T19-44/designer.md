# 🚀 Authority Flow: 최종 프로토타입 디자인 시퀀스 및 상호작용 스펙 (Developer Specification)

## 1. 디자인 시스템 재확인 (System Recap)
모든 화면은 다음의 핵심 원칙을 준수해야 합니다.

*   **핵심 색상:**
    *   **Deep Forest Green (`#3CB371`):** 안정/통제 상태, 성공적인 행동 지침.
    *   **Amber (`#FFBF00`):** 중간 리스크, 선제적 조치가 필요한 경고 상태.
    *   **Red (`#FF4500`):** 높은 위험, 긴급 조치 필요 상태.
    *   **Rich Gold (`#FFD700`):** 통제권 확보의 상징 (Control Symbol).
    *   **Deep Blue (`#004D66`):** 기본 배경 및 안정적인 정보 표시.
*   **타이포그래피:** 핵심 수치(Severity, Actionable Insight)는 **Bold & Large**, 근거 표시는 가장 작고 회색으로 처리하여 시각적 계층 구조를 확립합니다.
*   **데이터 권위 표시:** 모든 수치 옆에는 시스템 지표 설명(`시스템 통제권 확보율: XX%`)을 작은 폰트로 명시하며, 결과 값은 **Rich Gold**로 강조합니다.

## 2. 핵심 화면 시퀀스 (Key Screens Sequence)

다음은 사용자가 '불안 $\rightarrow$ 안도 $\rightarrow$ 통제권 회복' 흐름을 경험하는 핵심 단계입니다.

### Screen 1: Risk Assessment & Entry (위험 평가 및 진입 화면)
**목표:** 사용자에게 현재 상태의 위험도를 즉각적으로 인지시키고 다음 단계로 유도합니다.
**레이아웃 특징:** 중앙에 가장 큰 '위험 지수' 게이지가 배치됩니다.

| 요소 | 디자인 스펙 | 상호작용 (State Change) 스펙 |
| :--- | :--- | :--- |
| **헤드라인** | "당신의 현재 위험 상태는?" (Deep Blue) | 정적 |
| **핵심 지표** | `Risk Score: [XX]%` (가장 크게, Rich Gold 강조) | 사용자가 진입 시 즉시 계산된 값 표시. |
| **게이지** | 대형 원형 게이지. 채워지는 색상은 위험도에 따라 Red $\rightarrow$ Amber $\rightarrow$ Green으로 동적 변화. | **[Interaction]**: 화면 로드 시, 초기 Risk Score에 해당하는 색상(예: High Risk 시 Red)으로 게이지가 즉시 채워지며 경고음(Soft Tone Alert) 발생. |
| **CTA 버튼** | "위험 요인 진단 시작" (Growth Green 배경) | **[Interaction]**: 클릭 시, 다음 화면(Screen 2)으로 부드럽게 전환하며, 로딩 애니메이션을 통해 데이터 처리 중임을 표시. |

### Screen 2: Data & Insight Reveal (데이터 및 통찰 공개 화면)
**목표:** 위험 점수의 근거가 되는 구체적인 데이터를 제시하고, '왜' 이런 결과가 나왔는지 설명합니다.
**레이아웃 특징:** 리스크 지표와 관련된 데이터 블록을 카드 형태로 구성합니다.

| 요소 | 디자인 스펙 | 상호작용 (State Change) 스펙 |
| :--- | :--- | :--- |
| **핵심 내용** | '위험 점수' 외에 구체적인 원인(예: 모호성 입력 데이터, 규제 미준수 항목 등)을 명시. | 정적 데이터 표시. |
| **데이터 시각화** | 각 위험 요인별로 별도의 카드. 리스크 수준에 따라 색상 구분 (Red, Amber). | **[Interaction]**: 사용자가 특정 위험 카드를 클릭하면, 해당 위험에 대한 상세 설명(시스템 지표 포함)이 확장되어 표시됨 (Accordion Style). |
| **통찰 제공** | "당신의 불안은 다음 3가지 요인에서 기인합니다."와 같은 명확한 요약 문구. | **[Animation]**: 데이터 블록들이 아래에서 위로 부드럽게 등장하며, 핵심 통찰이 강조됨 (Fade-in & Slide-up). |

### Screen 3: Authority Flow Visualization (권한 흐름 시각화 화면)
**목표:** 위험 인지에서 통제권 회복으로 이어지는 과정(Authority Flow)을 명확하게 보여줍니다.
**레이아웃 특징:** 전체 여정을 단계별로 연결된 경로(Flow Map) 형태로 시각화합니다.

| 요소 | 디자인 스펙 | 상호작용 (State Change) 스펙 |
| :--- | :--- | :--- |
| **흐름 경로** | 시작점(불안) $\rightarrow$ 중간점(인지/분석) $\rightarrow$ 종점(통제권 회복)을 화살표로 연결한 선형 또는 순환 경로. | **[Interaction]**: 사용자가 각 단계(Node)를 클릭하거나 스크롤할 때마다, 해당 단계의 정보가 강조되고 다음 단계로 부드럽게 포커스가 이동함. |
| **상태 표시** | 각 단계별로 현재 확보된 '통제권' 비율을 표시 (예: Stage 1: 통제권 20%). | **[Animation]**: 사용자가 경로를 따라 스크롤할 때, 선(Path)이 실시간으로 그려지며, 진행률에 따라 연결선이 Rich Gold 색상으로 활성화됨. |
| **결과 강조** | 최종 도달점(통제권 회복)은 가장 밝고 안정적인 Green 톤으로 강조되어야 함. | **[Final State]**: 최종 화면에서 '완료' 상태를 시각적으로 확정하며, 모든 위험 지표가 안정된 Deep Forest Green으로 전환됨. |

### Screen 4: Action Blueprint & Guidance (행동 지침 및 청사진 화면)
**목표:** 사용자가 즉시 실행 가능한 구체적인 행동 계획(Blueprint)을 제공합니다.
**레이아웃 특징:** 명확한 단계별 체크리스트와 연관된 조치 항목으로 구성됩니다.

| 요소 | 디자인 스펙 | 상호작용 (State Change) 스펙 |
| :--- | :--- | :--- |
| **Blueprint 목록** | 각 행동 지침(Action Item)은 명확한 제목과 필수 체크리스트로 구성. | 정적 정보 표시. |
| **단계별 연결** | 각 행동 지침 옆에 해당 행동이 Screen 3의 어느 단계와 연결되는지 표시 (예: Action A $\rightarrow$ Stage 2 분석). | **[Interaction]**: 사용자가 특정 행동을 완료할 때마다, 해당 경로가 활성화되며 다음 단계로 이동하는 것을 시각적으로 확인. |
| **실행 버튼** | "다음 단계 실행" 버튼 (Amber 색상) | **[Interaction]**: 클릭 시, 시스템이 사용자 입력(선택된 Action)에 따라 동적으로 다음 스텝의 권한 흐름을 재계산하고 화면을 업데이트함. |

### Screen 5: Final Control & Outcome (최종 통제 및 결과 화면)
**목표:** 모든 과정이 완료되었음을 확정하고, 사용자에게 얻은 최종적인 가치(통제권 회복)를 명확히 전달합니다.
**레이아웃 특징:** 성공과 안정감을 극대화하는 디자인으로 구성됩니다.

| 요소 | 디자인 스펙 | 상호작용 (State Change) 스펙 |
| :--- | :--- | :--- |
| **최종 결과** | "Authority Flow Complete: 통제권 회복 달성!" (가장 큰 텍스트, Rich Gold 강조). | 정적. 배경은 안정적인 Deep Forest Green 계열로 전환됨. |
| **성과 요약** | 사용자가 얻은 핵심 성과 지표(KPIs)를 명확한 수치와 함께 제시. | **[Animation]**: 모든 성공 지표가 동시에 부드럽게 나타나며, 최종적으로 화면 전체에 안정감 있는 Glow 효과가 적용됨. |
| **다음 단계** | "성장 로드맵 확인" 또는 "다음 목표 설정" CTA. | **[Interaction]**: 클릭 시, 잠금 해제된 다음 단계의 콘텐츠(예: 장기 목표 설정 화면)로 부드럽게 이동. |
