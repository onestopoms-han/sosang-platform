CEO의 지시와 Writer가 제공한 스토리텔링 프레임워크를 기반으로, '홈페이지 메인 비주얼(Hero Banner)'에 대한 디자인 브리프와 와이어프레임을 구체적으로 작성합니다. 모든 디자인 요소는 브랜드 정체성('딥 차콜 그레이'와 '골드 액센트') 및 핵심 가치('데이터 기반 권위')를 극대화하는 방향으로 설계되었습니다.

## 🖼️ Hero Banner 디자인 브리프: 데이터 기반 권위 (Authority Focus)

### 1. 최종 선택된 카피 (Selected Copy)
**선택:** A. 권위 강조형 (Authority Focus)
> **메인 헤드라인:** "당신의 건강 시스템, 데이터로 설계하고 통제하십시오."
> **서브 헤드라인:** "균주바이오컴버젼이 증명하는, 장-뇌 축의 최적화된 인프라"

### 2. 레이아웃 구도 (Layout Geometry & Structure)
**구조 목표:** 시선은 중앙의 강력한 메시지에서 시작하여, 신뢰를 뒷받침하는 데이터 위젯으로 자연스럽게 이동하며, 최종적으로 행동(CTA)으로 연결되도록 유도합니다.

| 요소 | 비율/좌표 | 설명 | 디자인 역할 |
| :--- | :--- | :--- | :--- |
| **배경** | Full Screen (100% x 100vh) | **Deep Charcoal Gray** (#1A1A1A 또는 #252525) 적용. 미세한 질감(Texture) 삽입 고려. | 권위, 고급스러움, 깊이 부여 |
| **메인 카피 영역 (H1)** | 중앙 상단 40% 높이 | 메인 헤드라인 배치. 폰트 크기 최대화하여 시각적 압도감 제공. | 핵심 메시지 전달 |
| **보조 설명/권위 증명** | H1 바로 아래, 중앙 정렬 | 서브 헤드라인 배치. 골드 액센트로 강조. | 메시지의 구체적인 근거 제시 |
| **핵심 데이터 위젯 영역 (Authority Gauge)** | 화면 하단 60% 높이 | 좌우 분할 또는 중앙 집중형으로 배치. '시스템 통제권 확보율' 등 핵심 수치 게이지를 배치하는 공간. | 데이터 기반 신뢰 구축 |
| **주요 CTA 버튼** | 화면 중앙 하단 (데이터 영역 위) | 가장 눈에 띄는 골드 색상 버튼. `[CTA 예시: 시스템 진단 시작하기]` | 행동 유도 (Action Point) |

### 3. 컬러 및 타이포그래피 가이드라인 (Color & Typography Guide)

| 요소 | 값 | 코드/설명 | 적용 원칙 |
| :--- | :--- | :--- | :--- |
| **주조색 (Background)** | Deep Charcoal Gray | `#1A1A1A` (또는 `#252525`) | 깊은 밤하늘의 신뢰감. 시각적 안정성 제공. |
| **액센트 색상 (Accent)** | Gold | `#D4AF37` (골드 계열) | 프리미엄, 희소성, 권위 강조. 모든 강조 요소에 사용. |
| **보조 텍스트** | Soft White / Light Gray | `#F0F0F0` | 가독성 극대화. 차콜 배경 위에서 대비 확보. |
| **메인 타이포 (H1)** | Serif 계열 (예: Playfair Display, Cinzel) | 굵기: Bold/ExtraBold | 지적이고 권위 있는 느낌 강조. |
| **데이터 수치** | 산세리프 계열 (예: Montserrat, Roboto Mono) | 숫자 자체는 매우 크게, 단위(%) 옆에 작은 글씨로 효능 설명 추가. | 데이터의 명확성과 과학적 느낌 부여. |

### 4. 인터랙션 및 애니메이션 스펙 (Interaction & Animation Specs)
**목표:** '골드 인플로우'와 '데이터 증명'을 통해 프리미엄 감성을 유지합니다.

1.  **로딩 시점 (Initial Load):** 배경(Deep Charcoal Gray)이 부드럽게 페이드인(Fade-in)됩니다.
2.  **텍스트 등장:** 메인 헤드라인과 서브 헤드라인은 0.8초에 걸쳐 천천히 나타납니다.
3.  **골드 액센트 활성화 (Gold Inflow):** H1 아래의 서브 헤드라인 및 핵심 데이터 위젯(Gauge)이 로딩 후 **약 1.2초 동안** '골드 인플로우' 애니메이션을 통해 부드럽게 채워지며 나타납니다.
4.  **CTA 반응:** CTA 버튼은 마우스 오버 시, 골드 색상이 미세하게 밝아지거나(Lighten) 테두리가 확장되는 효과를 주어 즉각적인 클릭 유도를 합니다.

### 5. 개발자 전달용 요약 (Developer Summary)
*   **전체 분위기:** 어둡고, 깊으며, 금빛 액센트가 권위를 발산하는 **Dark Luxury** 스타일.
*   **핵심 지시사항:** 모든 골드 요소는 `#D4AF37` 코드를 사용하며, 데이터 위젯의 채움 효과에는 `Gold Inflow` 애니메이션을 적용하여 프리미엄 인상을 극대화할 것.
