## 📊 가상 테스트용 Mock Data Set: 시스템 안정성 지수 (SSI) 여정 시뮬레이션

이 Mock Data는 사용자가 '불안정성(Unstable)'에서 '통제권 회복(Control Arc)'을 경험하는 과정을 3단계로 시각화하며, 각 단계별로 재무적 불안정성과 심리적 안정성이 어떻게 변화하는지를 수치화합니다.

### 1단계: 불안정 (Unstable) - 시스템 혼란 및 높은 불안정성
이 단계는 사용자가 통제력을 상실하고 시스템에 대한 불확실성이 극대화된 상태를 나타냅니다.

| 지표 | 초기 상태 (T=0) | 변화율/추세 | 설명 | 관련 감성 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **시스템 안정성 지수 (SSI)** | 35 / 100 | -15% 하락 (초기 충격) | 데이터 흐름이 예측 불가능하며, 시스템 통제권 상실. | 불안정성 (Anxiety) |
| **예상 이익 변동성 (Margin Volatility)** | 65% | +20% 상승 | 원자재 및 운영 비용의 급변으로 수익 예측 불가. | 손실 회피 (Loss Aversion) |
| **위기 회피 비용 (Risk Aversion Cost)** | $1,500 / 월 | 유지 | 불확실성 때문에 의사결정 지연 발생. | 불안정성/손실 회피 |
| **통제권 확보 깊이** | 10% | -5% 하락 | 사용자는 자신이 시스템을 통제하고 있다는 느낌을 상실함. | 무력감 (Helplessness) |

### 2단계: 수렴 (Converging) - 안정화 과정 및 통제권의 재정립
사용자가 시스템에 개입하여 데이터를 관리하고 통제권을 되찾기 시작하는 전환 단계입니다.

| 지표 | 중간 상태 (T=50%) | 변화율/추세 | 설명 | 관련 감성 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **시스템 안정성 지수 (SSI)** | 60 / 100 | +25% 상승 | 데이터 모니터링을 통해 패턴을 인식하고 시스템에 개입하기 시작함. | 집중/학습 (Focus) |
| **예상 이익 변동성 (Margin Volatility)** | 40% | -30% 하락 | 통제된 환경 내에서 비용과 수입의 변동성이 감소. | 안정감 (Security) |
| **위기 회피 비용 (Risk Aversion Cost)** | $800 / 월 | -45% 하락 | 예측 가능성이 높아지면서 심리적 부담이 경감됨. | 통제권 확보 (Control) |
| **통제권 확보 깊이** | 45% | +10% 상승 | 사용자가 시스템의 변화를 감지하고 대응하기 시작함. | 효능감 (Efficacy) |

### 3단계: 안착 (Stable) - 통제권 회복 및 최적 상태
사용자가 시스템을 완전히 이해하고, 안정성을 확보하며, 최대의 통제권을 행사하는 최종 상태입니다.

| 지표 | 최종 상태 (T=100%) | 변화율/추세 | 설명 | 관련 감성 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **시스템 안정성 지수 (SSI)** | 95 / 100 | +35% 상승 | 시스템이 최적 상태로 유지되며, 외부 충격에 강해짐. | 평온함 (Serenity) |
| **예상 이익 변동성 (Margin Volatility)** | 15% | -70% 하락 | 예측 가능한 수익 구조를 기반으로 안정적인 성과 창출. | 자신감 (Confidence) |
| **위기 회피 비용 (Risk Aversion Cost)** | $200 / 월 | -75% 하락 | 불확실성이 제거되어 심리적 여유가 확보됨. | 안도감 (Relief) |
| **통제권 확보 깊이** | 98% | +53% 상승 | 시스템 전체를 완벽하게 관리하고 예측함. | 완전한 통제 (Mastery) |

## 📄 API 연동 구조 명세서: SSI 데이터 스트리밍 및 시각화

Writer가 스토리라인에 필요한 데이터를 추출하고, Designer가 이를 기반으로 UI/UX 컴포넌트를 개발할 수 있도록 백엔드(API)와 프론트엔드의 데이터 흐름을 명확히 정의합니다.

### 1. API 엔드포인트 정의 (Backend: `Dashboard_API`)

모든 핵심 지표는 단일 엔드포인트를 통해 요청할 수 있으며, 시간 경과에 따른 변화를 반영해야 합니다.

| Endpoint | Method | Description | Request Parameters | Response Schema (JSON) |
| :--- | :--- | :--- | :--- | :--- |
| `/api/v1/stability_flow` | `GET` | SSI 여정 전체 데이터 시퀀스 요청 (스토리라인용) | `userId`, `startDate`, `endDate` | `{ "flow": [ { "stage": 1, "data": {...} }, { "stage": 2, "data": {...} }, ... ] }` |
| `/api/v1/stability_metrics` | `GET` | 특정 시점의 핵심 지표 조회 (UI 컴포넌트용) | `userId`, `timestamp` | `{ "SSI": 60.5, "MarginVolatility": 40.2, "RiskAversionCost": 850 }` |
| `/api/v1/interaction_history` | `GET` | 사용자 개입(Action)에 따른 시스템 반응 기록 (E2E 테스트용) | `userId`, `filter` | `{ "actions": [ { "timestamp": "...", "actionType": "Adjustment", "result": "SSI_Change" } ] }` |

### 2. 데이터 흐름 및 시각화 명세 (Frontend: UI/UX)

| 단계 | 데이터 활용 목표 | 핵심 시각화 요소 | 애니메이션/UX 지침 |
| :--- | :--- | :--- | :--- |
| **1단계: 불안정** | 문제 인식 (Pain Point) | **Volatility Gauge:** 폭발적인 변동성 그래프. 붉은색 계열 강조. | 빠른 변화, 떨림(Shaking), 경고음(Alert). |
| **2단계: 수렴** | 과정 인지 (Process) | **Control Arc Line:** SSI가 상승하는 곡선과 함께 Margin Volatility의 하락 추이 시각화. | 부드러운 수렴, 점진적인 안정화 애니메이션. |
| **3단계: 안착** | 결과 확인 (Achievement) | **Stability Scorecard:** 최종 SSI 값(95+)을 중앙에 배치하고, Risk Aversion Cost가 최소치로 떨어지는 것을 표시. | 고정된 상태, 녹색 계열 강조, 확정(Lock-in) 애니메이션. |
