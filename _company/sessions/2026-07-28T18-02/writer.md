# 👑 참송이 골드 마스터 카피 세트 (Master Copy Set)

## 1. 메인 페이지 (Homepage) 카피 블록

**목표:** 방문자의 불안정성을 즉각적으로 인식시키고, 제품이 제공하는 '시스템 관리 솔루션'의 존재를 제시하며 신뢰감을 확보합니다.

### A. 메인 헤드라인 (Hero Headline)
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **메인 후크** | **당신의 몸속 시스템, 통제력을 되찾으세요.** | 불안정성 인식 ($\rightarrow$) 통제권 회복 |
| **서브 헤드라인** | 미식의 정점, 과학적 균형을 통해 내면의 안정감을 설계하는 새로운 경험. | 시스템 통제 과정(SSI) + 최고급 경험(Gourmet) |
| **핵심 CTA** | **[나만의 시스템 시작하기]** (구독/탐색 버튼) | 행동 유도 |

### B. 핵심 가치 섹션 (Value Proposition Block)
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **섹션 제목** | **불안정한 환경 속, 당신의 시스템은 어디에 있습니까?** | 불안정성 인식 |
| **본문** | 복잡한 일상 속에서 우리는 끊임없이 외부 변수에 반응하며 에너지를 소모합니다. 참송이 골드는 단순한 식재료가 아닌, 이 모든 혼란 속에서 내면의 균형을 재조정하는 과학적 인프라입니다. | 문제 제기 및 공감대 형성 |
| **시스템 전환** | **과학적 통제 경험(SSI)으로, 내 몸의 환경을 설계하세요.** | 시스템 통제 과정 강조 |
| **결과 제시** | **최고급 미식의 정점**, 가장 순수한 성분으로 완성된 차원이 다른 미각 경험. | 최고급 경험 제시 |

## 2. 제품 상세 페이지 (Product Detail Page, PDP) 카피 블록

**목표:** 과학적 데이터(신뢰)와 미식적인 감성(고급스러움)을 결합하여, 소비자가 이 버섯이 단순한 식품이 아닌 '관리 솔루션'임을 납득하게 합니다.

### A. 제품 타이틀 및 요약
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **제품명** | 참송이 골드: 시스템 안정화를 위한 프리미엄 미식 인프라 | 고급화된 명칭 부여 |
| **요약 문구** | 자연의 정밀한 균형, 과학적 관리가 빚어낸 최상의 송이알코올 농축 경험. | 품질과 과학의 결합 |

### B. 시스템 통제 과정 시각화 섹션 (SSI Visualization)
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **섹션 제목** | **데이터 기반의 정밀한 관리: 송이알코올, 그 시스템 지표** | 과학적 권위 강조 |
| **본문** | 우리는 단순한 효능을 넘어, 환경 변수를 통제하는 핵심 지표에 집중합니다. 경쟁 제품 대비 **송이알코올 22배 이상**의 압축된 성분은 자연 시스템이 최적의 상태로 정렬되었음을 증명합니다. | 데이터 기반의 우위 제시 |
| **시각화 지침** | (개발자 지침) 송이알코올 농축도 비교 그래프(Control Data Block)를 중앙에 배치하고, 주변에는 미식적인 질감을 강조하는 고화질 이미지와 고급스러운 색감(다크 포레스트 그린 & 골드)을 사용합니다. | 시각적 테마 적용 |

### C. 최종 경험 및 CTA
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **최종 메시지** | 당신의 미식 여정은 이제 통제된 완벽함으로 완성됩니다. | 최고급 경험 마무리 |
| **CTA** | **[최고의 시스템을 소유하기]** (구매 버튼) | 강력한 구매 유도 |

## 3. 컨설팅/구독 소개 페이지 카피 블록

**목표:** 제품 판매를 넘어, 지속적인 '시스템 관리'라는 LTV(고객 생애 가치) 기반의 구독 모델의 가치를 극대화하고 전문성을 어필합니다.

### A. 서비스 헤드라인
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **메인 후크** | **단순한 공급이 아닌, 당신의 성장을 위한 시스템 컨설팅.** | 관리 솔루션 강조 |
| **서브 헤드라인** | 데이터 기반 성장 컨설턴트가 설계하는, 지속 가능한 미식 및 건강 관리 로드맵. | 전문성과 장기적 가치 제시 |

### B. 구독 플랜 상세 설명 (Value Stack)
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **플랜 1: [Foundation]** | **시스템 인식 단계:** 핵심 데이터 진단 및 초기 안정화 가이드 제공. (기초 안정성 확보) | 불안정성 인지 & 기초 통제 |
| **플랜 2: [Control]** | **시스템 최적화 단계:** 개인별 환경 변수 분석 기반, 맞춤형 영양 관리 전략 컨설팅. (능동적 통제 시작) | 시스템 통제 과정(SSI) 심화 |
| **플랜 3: [Master]** | **최고급 경험 단계:** 지속적인 데이터 피드백과 전문가의 코칭으로, 미식 경험을 최고 수준으로 완성하는 통합 관리. (최고급 경험 극대화) | 최고급 경험 및 LTV 강조 |

### C. 최종 CTA
| 구분 | 카피 내용 | 포커스 |
| :--- | :--- | :--- |
| **마무리 문구** | 더 이상 추측에 의존하지 마세요. 과학적 통제 하에, 당신의 잠재력을 극대화하세요. | 권위 기반 행동 촉구 |
| **CTA** | **[나에게 맞는 관리 시스템 선택하기]** (구독 버튼) | 명확한 다음 단계 제시 |
