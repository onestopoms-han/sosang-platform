## 1. 통합 디자인 시스템 (Visual & Color System Redesign v2.0)

이 시스템은 사용자의 심리적 여정($\text{Red} \rightarrow \text{Gold} \rightarrow \text{Green}$)을 따라 시각적 피드백을 제공하는 것을 목표로 합니다.

### 1.1. 핵심 색상 팔레트 정의 (Core Color Palette)

| 상태/역할 | 색상 이름 | HEX 코드 | 용도 및 심리적 의미 | 적용 범위 |
| :--- | :--- | :--- | :--- | :--- |
| **불안정성 (Uncertainty)** | **Red (위기)** | `#D9534F` (혹은 더 강한 경고색) | 위험, 불안, 통제 상실. 초기 상태를 강조. | 경고 표시, 불안정 지표, CTA 비활성화 시. |
| **전환/통제권 확보** | **Gold (확신)** | `#FFD700` (Rich Gold) | 통제권 획득, 가치 발견, 중요한 전환점. | 핵심 KPI 강조, 진행 바(Progress Bar), 주요 CTA 활성화 시. |
| **안도감/성장 (Relief/Growth)** | **Deep Green** | `#3CB371` (Growth Green) | 안도감, 안정, 성공적인 통제권 확보. 최종 상태. | 성공 지표, 긍정적 피드백, 완료 상태 표시. |
| **기반/신뢰 (Foundation)** | **Deep Blue** | `#004D66` | 브랜드 신뢰도, 안정성, 기본 배경색. | 주 배경(Background), 헤더, 주요 텍스트. |
| **보조 (Accent)** | Light Gray | `#AAAAAA` | 보조 정보, 시스템 지표 설명. | 작은 폰트 및 데이터 레이블. |

### 1.2. 타이포그래피 시스템 (Typography System)

신뢰도와 명확성을 위해 가독성이 높은 산세리프 계열을 사용하며, 핵심 수치에 시각적 위계를 부여합니다.

| 레벨 | 역할 | 폰트 스타일 | HEX/크기 예시 | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **H1 (메인 헤드라인)** | 최종 메시지 | Bold, Sans-serif | `#004D66` / 3rem | 랜딩 페이지의 핵심 후크. |
| **KPI/Score** | 핵심 지표 값 | ExtraBold, Gold | `Control Score: 98.5%` (가장 크게) | 통제권 확보율 등 핵심 수치. |
| **Value Label** | 시스템 설명 | Regular, Deep Green | `시스템 통제권 확보율:` (작게) | 지표의 의미를 설명하는 레이블. |
| **Detail Text** | 보조 설명 | Regular, Gray | `(근거: 데이터 기반 권위)` (매우 작게) | 근거 표기 및 미세 정보 제공. |

### 1.3. 핵심 컴포넌트 디자인 스펙 정의

#### A. KPI\_Gauge (통제권 확보 게이지) 상세 스펙

이 게이지는 사용자의 심리적 상태 변화를 시각화하는 핵심 요소입니다.

| 속성 | Red State (불안정) | Gold State (전환 중) | Green State (안도감) |
| :--- | :--- | :--- | :--- |
| **배경색** | `#D9534F` (Red 계열) | `#FFD700` (Gold 계열) | `#3CB371` (Green 계열) |
| **테두리 색상** | Red | Gold | Deep Green |
| **텍스트 색상** | White | Black/Deep Blue | White |
| **애니메이션 흐름** | 불안정 상태에서 시작하여 Gold 영역으로 부드럽게 채워짐. | Gold 영역을 지나며 안도감으로 전환됨. | 최종적으로 녹색으로 안정화되어 고정됨. |
| **레이블 스타일** | `Control Score: XX%` (Gold 강조) | `Control Score: XX%` (Gold 강조) | `Control Score: XX%` (Green 강조) |

#### B. Trust Widget (신뢰 위젯) 상세 스펙

이 위젯은 데이터 기반 권위를 시각적으로 증명하는 역할을 합니다.

*   **구조:**
    1.  **최상단 지표 (핵심):** `Control Score: XX%` (가장 크게, Gold 색상으로 강조).
    2.  **시스템 설명 (중간):** `시스템 통제권 확보율: XX%` (작게, Deep Green 색상으로 표시하여 성취감 부여).
    3.  **근거 표시 (하단):** `(근거: 데이터 기반 권위)` (매우 작게, Light Gray로 표시).

*   **색상 적용:**
    *   `Control Score` 값 자체는 **Gold**로 강조하여 성과를 부각합니다.
    *   시스템 지표(`시스템 통제권 확보율`)는 **Deep Green**으로 처리하여 최종 목표 달성의 안도감을 시각화합니다.

## 2. 디자인 가이드라인 요약 (Design Guideline Summary)

모든 콘텐츠(CTA 버튼, 배경, 차트 등)는 다음의 심리적 흐름을 반영해야 합니다.

1.  **Red Zone:** 초기 진입 또는 문제 제기 시, **경고 및 긴장감**을 유발하여 즉각적인 주의를 요구합니다. (불안정성 인식)
2.  **Gold Zone:** 사용자가 행동을 취하고 시스템과 상호작용하는 구간입니다. **긍정적 가치와 통제권 획득의 경험**을 부여하며, 시각적으로 가장 높은 주목도를 갖습니다. (통제권 확보 여정)
3.  **Green Zone:** 목표 달성 또는 안정화 상태를 나타냅니다. **안도감과 성공**을 제공하며, 최종적인 신뢰감을 구축합니다. (안도감 및 성장)

### 2.1. CTA 버튼 디자인 규칙

| 상태 | 색상 | 스타일 | 설명 |
| :--- | :--- | :--- | :--- |
| **불안/비활성** | `#D9534F` (Red) | 불투명도 낮음, 테두리만 표시. 마우스 오버 시 경고 메시지 팝업. | 사용자가 불안정 상태에서 행동을 유보하도록 유도. |
| **전환/기본 CTA** | `#FFD700` (Gold) | 고대비, 채워진 배경. 클릭 시 다음 단계로 이동하는 명확한 경로 제공. | 핵심적인 다음 단계(예: 컨설팅 신청)를 강조. |
| **완료/성공** | `#3CB371` (Deep Green) | 안정된 색상. 성공적으로 완료되었음을 확신시킴. | 최종 구매 또는 등록 완료 시 사용. |

### 2.2. 최종 적용 지침

개발자는 이 스펙을 기반으로 모든 컴포넌트(`KPI_Gauge`, `Trust Widget`)에 위에서 정의한 **색상 매핑**과 **애니메이션 타이밍(150ms 준수)**을 적용해야 합니다. 특히, 색상의 변화는 단순한 미학이 아닌, 사용자의 심리적 여정($\text{Red} \rightarrow \text{Gold} \rightarrow \text{Green}$)을 측정하는 데이터 지표임을 명확히 해야 합니다.
