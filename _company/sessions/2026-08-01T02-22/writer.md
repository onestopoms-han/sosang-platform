## 🧠 UX 단계별 카피라이팅 및 내러티브 구조 (Design System 연동 버전)

### Phase 1: 불안정성 인식 (Red)
**목표:** 사용자가 현재의 불편함과 불안정성을 명확하게 인식하고, 문제에 깊이 공감하도록 유도합니다. (시스템 색상: Red)

| 요소 | 메시지 내용 | 의도 및 역할 |
| :--- | :--- | :--- |
| **Headline (H1)** | **"당신의 활력은 어디서 오나요? 무너진 균형의 시작점."** | 가장 강력한 불안감을 건드려 시선을 붙잡고, 현재 상태가 '문제'임을 인지시킵니다. |
| **Subhead (H2)** | "복잡한 일상 속에서 신체 내부의 미세한 불균형이 당신의 집중력과 활력을 앗아가고 있습니다." | 개인적인 경험(피로, 집중력 저하)과 연결하여 문제의 심각성을 구체화합니다. |
| **Body Copy** | "우리는 매일 수많은 선택과 스트레스 속에서 살지만, 정작 가장 중요한 우리의 '내부 환경'은 방치되어 왔습니다. 몸이 보내는 미묘한 신호를 놓쳤을 때, 우리는 시스템 통제권을 잃게 됩니다." | 감정적 공감을 극대화하며, 외부 환경(스트레스)과 내부 상태(불균형)의 연결고리를 제시합니다. |
| **CTA (Action)** | *(잠시 대기 또는 다음 단계로 이동 유도)* "이 불균형을 인지하고, 이제 통제권을 되찾을 준비가 되셨나요?" | 사용자가 스스로 다음 단계로 나아가도록 심리적 허들을 설정합니다. |

---

### Phase 2: 통제권 확보의 시작 (Gold)
**목표:** 솔루션(제품)이 이 불안정성을 해결할 수 있는 과학적 원리와 통제권을 제공한다는 확신을 심어줍니다. (시스템 색상: Gold)

| 요소 | 메시지 내용 | 의도 및 역할 |
| :--- | :--- | :--- |
| **Headline (H1)** | **"건강 시스템을 설계하다: 데이터로 당신의 통제권을 되찾으세요."** | 제품이 단순한 영양제가 아닌 '관리 솔루션'임을 강조하며, 주도권을 사용자에게 돌려줍니다. |
| **Subhead (H2)** | "장-뇌 축의 안정화 원리를 기반으로, 최적의 환경을 조성하는 과학적인 해답을 만나보세요." | 핵심 USP(과학적 근거)를 명확히 제시하여 신뢰도를 구축합니다. |
| **Body Copy** | "참송이골드는 단순한 영양 공급을 넘어, 몸속 환경을 데이터 기반으로 분석하고 조절하는 인프라입니다. 경쟁 제품 대비 22배 이상 높은 핵심 성분 농축도는 당신의 통제권을 실질적으로 증명합니다." | 구체적인 수치(데이터)를 제시하여 감성적 불안감을 이성적 확신으로 전환시킵니다. (Control Data Block 연동 지점) |
| **CTA (Action)** | **"통제권 확보 시작하기 $\rightarrow$"** *(가장 중요한 전환 버튼)* | 사용자가 다음 단계로 나아갈 명확하고 강력한 행동을 유도합니다. |

---

### Phase 3: 안도감/성장 (Green)
**목표:** 솔루션 적용 후 얻게 될 안정감, 성장, 그리고 지속 가능한 건강이라는 최종적인 긍정적 결과를 제시합니다. (시스템 색상: Deep Green)

| 요소 | 메시지 내용 | 의도 및 역할 |
| :--- | :--- | :--- |
| **Headline (H1)** | **"완벽한 균형의 경험: 지속 가능한 활력과 명료함."** | 최종적인 목표(활력, 명료함) 달성을 약속하며, 심리적 안도감을 극대화합니다. |
| **Subhead (H2)** | "이제 당신은 스스로 건강 시스템을 관리하는 주체입니다. 흔들림 없는 안정감 속에서 진정한 집중력을 경험하세요." | 통제권 확보의 최종 결과를 감정적으로 표현하고, 사용자의 자율성을 강조합니다. |
| **Body Copy** | "참송이골드와 함께라면, 복잡한 외부 환경에 흔들리지 않고 스스로 최적의 건강 상태를 유지할 수 있습니다. 이는 단순한 건강을 넘어, 삶의 질과 집중력이라는 가장 중요한 자원을 확보하는 경험입니다." | 제품 사용이 가져오는 장기적인 긍정적 가치(삶의 질 향상)를 제시하며 마무리합니다. |
| **CTA (Action)** | **"나만의 시스템 구축 시작하기 $\rightarrow$"** *(구매 또는 구독 유도)* | 최종적인 행동을 촉구하여, 불안함에서 안도감으로의 전환을 실질적인 행동으로 연결합니다. |
