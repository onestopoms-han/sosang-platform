### 👑 Authority Gauge: 심리적 흐름 기반 마이크로 카피 (5세트)

**핵심 전략:** 각 레벨은 '통제력 부족'의 정도에 따라 메시지의 깊이와 해결책(CTA)을 점진적으로 상승시킵니다.

#### **Level 0: 인식 단계 (The Acknowledgment)**
*   **목표:** 현재 상태의 불안정성을 인지시키고, 변화의 필요성을 암시합니다.
*   **핵심 감정:** 혼란스러움, 불확실성.

| 요소 | 카피라이팅 |
| :--- | :--- |
| **헤드라인 (Headline)** | 당신의 시스템은 지금 어디에 있습니까? |
| **본문 핵심 문장 (Body)** | 복잡한 일상 속에서, 우리는 종종 내부 환경의 통제력을 잃어버립니다. 이 불안정성이 당신의 활력을 저해하고 있다는 것을 인지하세요. |
| **CTA 버튼 텍스트** | 현재 상태 진단하기 |

#### **Level 1: 필요성 단계 (The Need for Structure)**
*   **목표:** 통제력 부족이 특정 영역(신체)에 영향을 미친다는 점을 연결하고, 구조화된 접근의 필요성을 제시합니다.
*   **핵심 감정:** 의문, 탐색.

| 요소 | 카피라이팅 |
| :--- | :--- |
| **헤드라인 (Headline)** | 시스템 안정화의 첫걸음: 환경을 점검하세요. |
| **본문 핵심 문장 (Body)** | 신체 내부의 균형이 무너졌다면, 체계적인 관리가 필요합니다. 참송이골드는 혼란스러운 환경 속에서 내면의 조화를 되찾는 기초를 제공합니다. |
| **CTA 버튼 텍스트** | 시스템 점검 시작하기 |

#### **Level 2: 관리 단계 (The Implementation)**
*   **목표:** 구체적인 방법론과 솔루션이 존재함을 제시하며, 체계적인 관리를 통해 변화가 가능하다는 희망을 심어줍니다.
*   **핵심 감정:** 학습 의욕, 계획성.

| 요소 | 카피라이팅 |
| :--- | :--- |
| **헤드라인 (Headline)** | 통제권을 확보하는 체계적인 관리 시스템 |
| **본문 핵심 문장 (Body)** | 단순한 섭취를 넘어, 과학적 근거 기반의 관리 프레임워크가 필요합니다. 참송이골드는 당신의 라이프스타일에 맞춰 내면 환경을 정밀하게 조정하는 가이드라인입니다. |
| **CTA 버튼 텍스트** | 맞춤 시스템 설계 보기 |

#### **Level 3: 통제 단계 (The Authority)**
*   **목표:** 사용자가 스스로 변화를 이끌어낼 수 있는 '권위(Authority)'가 생기고 있음을 강조하며, 제품이 그 과정의 핵심 도구임을 명시합니다.
*   **핵심 감정:** 자신감, 주도성.

| 요소 | 카피라이팅 |
| :--- | :--- |
| **헤드라인 (Headline)** | 당신이 바로 시스템의 설계자입니다. |
| **본문 핵심 문장 (Body)** | 데이터에 기반한 이해를 통해, 이제 당신은 자신의 신체 환경을 완벽하게 통제할 수 있는 권위를 얻습니다. 참송이골드는 그 통제력의 핵심 인프라입니다. |
| **CTA 버튼 텍스트** | 통제권 확보 과정 시작하기 |

#### **Level 4: 마스터 단계 (The Mastery & Gold)**
*   **목표:** 최종 목표인 '완벽한 시스템적 통제권'을 제공하며, 이를 달성하는 것이 가장 높은 가치(Gold)임을 선언합니다.
*   **핵심 감정:** 완전한 안정, 성취감.

| 요소 | 카피라이팅 |
| :--- | :--- |
| **헤드라인 (Headline)** | 궁극의 시스템 통제: 골드 레벨로 도약하세요. |
| **본문 핵심 문장 (Body)** | 모든 데이터와 관리 권한을 통합하여, 당신의 건강 시스템에 대한 완벽한 지배권을 확립하십시오. 참송이골드 골드 레이어는 이 통제권 확보를 위한 최종 인프라입니다. |
| **CTA 버튼 텍스트** | 골드 레벨로 업그레이드하기 |
