## CCRM 모듈 상호작용형 분류 시뮬레이션 테스트 케이스 (5가지)

### 테스트 케이스 1: 잔재물/부산물 분류의 모호성 검증
**목표:** 특정 공정을 거쳐 생성된 부산물의 HS 코드 분류와 제외 품목 적용의 경계 조건을 검증합니다.

1.  **입력 조건 (Input Condition):**
    *   **물품 명칭:** 금속 표면처리용 침지 조제품에서 발생한 잔재물 (납땜/용접 공정 후 남은 화학적 부산물).
    *   **추가 정보:** 해당 잔재물은 특정 유기 용제와 반응하여 생성된 미세 입자 형태이며, 최종 제품의 기능적 역할은 없음.
2.  **시스템 예측 위험 단계 (System Predicted Risk Level):**
    *   **예측:** **고위험 (High Risk)**. 단순 성분 분류가 아닌 '공정 단계별 기능적 역할'에 기반하여 잠재적인 화학물질 위험을 내포하고 있음.
3.  **최종 권장 행동 지침 (Final Recommended Action Guidance):**
    *   **지침:** **CCRM Flowchart 경로 $\rightarrow$ 제외 품목(Chapter 29, 30) 자동 검증 실행.** 해당 부산물은 최종 제품의 기능적 역할이 없으므로, 잔재물 분류 시 '특정 공정에서 생성된 비표준 물질'로 간주하고, 관련 폐기물 처리 규정을 우선 적용하여 **분리 수거/처리 주체(가정/산업)에 따른 책임 소재**를 명확히 하여 배출 관리 시스템에 등록하도록 지시한다.

### 테스트 케이스 2: 반응 촉진제의 HS 코드 검증
**목표:** 특정 화학물질(촉진제)이 포함된 제품의 분류 시, 관련 제외 품목(예: 3815)과의 상호작용을 검증합니다.

1.  **입력 조건 (Input Condition):**
    *   **물품 명칭:** 납땜/융제 용도로 사용되는 반응 개시제 및 촉진제 혼합물.
    *   **추가 정보:** 제품 자체는 '화학제품'으로 분류되나, 최종 사용 목적은 금속 표면의 물리적 상태 변화를 유도하는 데에 국한됨 (화학적 변환이 주 목적 아님).
2.  **시스템 예측 위험 단계 (System Predicted Risk Level):**
    *   **예측:** **중간 위험 (Medium Risk)**. 반응 개시제 성분으로 인해 특정 화학물질 규제의 잠재적 회피 가능성이 존재함.
3.  **최종 권장 행동 지침 (Final Recommended Action Guidance):**
    *   **지침:** **'3815 분류 판단 Flowchart' 실행.** 시스템은 해당 물질이 단순 화학제품인지, 혹은 특정 제한 품목(예: 26.20 등)의 구성 요소로 포함되는지를 검증한다. 만약 제외 기준에 해당하는 성분이 포함된다면, 최종 HS 코드를 선택하기 전에 **반드시 '제외 품목 관련 법적 경계 조건 체크리스트'를 확인**하고, 필요 시 해당 물질을 별도 폐기물 또는 특수 규제 물질로 분류하여 처리하도록 한다.

### 테스트 케이스 3: 모호성 점수 기반의 자동 검증
**목표:** 시스템이 자체적으로 산출한 '모호성 점수'를 바탕으로 사용자가 추가적인 판단을 요구하는 시나리오를 검증합니다.

1.  **입력 조건 (Input Condition):**
    *   **물품 명칭:** 특정 유기 화합물이 포함된 복합 소재 (화학공업 관련).
    *   **추가 정보:** 성분 분석 결과는 존재하나, 해당 물질의 최종 사용처나 공정 단계에 대한 상세 설명이 부족함.
2.  **시스템 예측 위험 단계 (System Predicted Risk Level):**
    *   **예측:** **고위험 (High Risk)**. `ambiguity_score`가 0.7 이상으로 산출되어 추가 검증 필요 신호 발생.
3.  **최종 권장 행동 지침 (Final Recommended Action Guidance):**
    *   **지침:** **'모호성 점수 $\rightarrow$ 전문가 개입 요청'.** 시스템은 `ambiguity_score`가 높음을 명시하고, 사용자에게 해당 물질의 **'분리 수거된 개별 재료 분류 기준'** 및 **'특정 공정을 거쳐 생성되거나 회수 목적의 부산물 제외 여부'**에 대한 구체적인 근거 자료를 요청한다. 사용자는 이 지침을 바탕으로 최종 HS 코드 결정 전에 내부 전문가(또는 관련 법규 해석)의 검토를 받도록 안내한다.

### 테스트 케이스 4: 환경 및 폐기물 분류의 주체 기반 검증
**목표:** 폐기물 분류 시, 물리적 상태보다는 '발생 주체'와 '처리 상태'가 분류에 미치는 영향을 검증합니다.

1.  **입력 조건 (Input Condition):**
    *   **물품 명칭:** 특정 화학 공정에서 발생한 생활 폐기물 및 잔재물 혼합물.
    *   **추가 정보:** 해당 폐기물은 가정에서 발생했으며, 산업적 규모의 공정 후 남은 부산물이 섞여 있음.
2.  **시스템 예측 위험 단계 (System Predicted Risk Level):**
    *   **예측:** **중간 위험 (Medium Risk)**. 주체(가정/산업)와 상태(폐기물/부산물)에 따라 분류 기준이 상이함.
3.  **최종 권장 행동 지침 (Final Recommended Action Guidance):**
    *   **지침:** **'발생 주체 및 처리 상태 우선 적용'.** 시스템은 폐기물의 발생 주체(가정 또는 산업)와 현재의 물리적/화학적 처리 상태를 1차 기준으로 설정하고, 이에 따라 해당 물질이 일반 폐기물인지 특정 품목인지 판단하도록 유도한다. **분리 수거된 개별 재료는 반드시 해당 재료의 특정 품목으로 분류**하여 관리하며, 공정 부산물은 별도로 분리하여 처리하도록 지시한다.

### 테스트 케이스 5: 통제권 확보 시뮬레이션 (Authority Flow)
**목표:** 시스템이 제시하는 권위 흐름(Authority Flow)을 기반으로 사용자가 최종 의사결정을 내리는 과정을 검증합니다.

1.  **입력 조건 (Input Condition):**
    *   **물품 명칭:** 특정 화학 물질의 공급망 관련 문서 및 성분 데이터.
    *   **추가 정보:** 공급망 투명성 지수(30% 우위)와 시스템 통제권 확보 시뮬레이션 결과를 함께 제시함.
2.  **시스템 예측 위험 단계 (System Predicted Risk Level):**
    *   **예측:** **낮음 $\rightarrow$ 중간 (상황에 따라 변동).** 투명성 지수가 높으므로 잠재적 리스크가 통제 가능하다고 판단됨.
3.  **최종 권장 행동 지침 (Final Recommended Action Guidance):**
    *   **지침:** **'권위 흐름 기반 의사결정'.** 시스템은 '통제권 확보 시뮬레이션' 결과를 제시하여, 현재의 분류 결정이 법적 경계 조건 내에서 이루어졌음을 확인시킨다. 원스탑 직원은 이 시뮬레이션 결과에 따라, **데이터 기반으로 최종 HS 코드를 확정**하며, 리스크가 높다고 판단될 경우 즉시 백엔드 모듈에 '통제권 확보' 요청을 발동하여 관련 증빙 자료를 자동으로 생성하도록 지시한다.
