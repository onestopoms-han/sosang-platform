## 🎯 MVP 비즈니스 모델 설계: '통제권 확보' 기반 접근

핵심 가치인 **'불안정성 인식 $\rightarrow$ 통제권 확보'** 여정을 서비스 구조에 직접적으로 반영하여, 사용자가 비용 부담 없이 초기 진단 및 조치를 취할 수 있도록 설계합니다.

### 1. 티어링 구조 (Freemium & Value-Based Tiers)

MVP 단계에서는 **'진입 장벽 최소화(Free)'**와 **'전문성 확보(Paid)'**의 균형을 맞추는 것이 중요합니다. 초기에는 AI 에이전트 협업을 통해 서비스 운영 비용을 낮추고, 유료 전환은 명확한 ROI 기반으로 설계합니다.

| 티어 명 | 대상 고객 | 핵심 기능 (Value Proposition) | 가격 전략 | 주요 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **Foundation (무료)** | 초기 사용자, 소규모 개인 사업자 | 💡 **Pain Point 진단:** 계약서/규제 환경에 대한 초기 위험 점수 및 체크리스트 제공. (Risk Assessment) | $0 | 사용자 확보(Acquisition), 서비스 경험 제공 |
| **Growth (프리미엄)** | 성장 단계 중소기업, 실질적 해결 니즈가 있는 사용자 | 🔍 **AI 기반 솔루션:** 특정 Pain Point에 대한 맞춤형 초안 생성, 법률 자문 에이전트 연동(협업), ROI 분석 시뮬레이션. | 월 $29 - $49 | 전환율 극대화(Conversion), 반복 구매 유도 |
| **Enterprise (B2B)** | 다수 지점 운영 기업, 복잡한 규제 준수가 필요한 대기업 | ⚙️ **통합 관리:** 내부 시스템 연동 API 제공, 실시간 컴플라이언스 모니터링 대시보드, 맞춤형 법률 대응 프로세스 자동화. | 계약 기반 (Custom Pricing) | 안정적 수익 확보(Stability), 장기 파트너십 구축 |

### 2. 핵심 KPI 측정 항목 설계

KPI는 단순 트래픽이 아닌, 사용자가 **'통제권 확보'**라는 목표에 얼마나 가까워졌는지 측정해야 합니다.

| KPI 카테고리 | 핵심 지표 (Metric) | 측정 목적 | 연관된 가치 흐름 |
| :--- | :--- | :--- | :--- |
| **사용자 참여 및 인식 (Engagement)** | 1. 진단 완료율: 무료 진단 후 다음 단계(유료 전환)로 이동한 비율 | 사용자가 문제 인식을 넘어 해결 의지를 보였는지 측정 | 불안정성 인식 $\rightarrow$ 통제권 확보 시작 |
| | 2. 세션당 평균 체류 시간 (Time on Task) | AI 솔루션을 통해 실제적인 정보를 얻는 데 걸리는 시간 측정 | 신뢰도 구축 |
| **서비스 품질 (Outcome)** | 3. 상담/솔루션 완료 건수: 유료 티어에서 생성된 최종 보고서 또는 초안의 수 | 서비스가 실질적인 결과물(Actionable Blueprint)을 제공했는지 측정 | 통제권 확보 달성 |
| | 4. 리스크 감소 지표 (Risk Reduction Score): 진단 전후의 법적/재무 위험 점수 변화율 | AI 서비스의 가장 직접적인 ROI 증명 | 불안정성 감소 |
| **수익화 (Monetization)** | 5. 전환율 (Conversion Rate): 무료 $\rightarrow$ 성장 티어로의 전환 비율 | 각 단계별 가치 인식에 따른 지불 의사 측정 | 지속 가능한 비즈니스 모델 |
| | 6. 고객 생애 가치 (LTV) | 장기적인 구독 유지율 측정 | 지속 가능성 검증 |

### 3. 초기 수익화 로드맵 (Monetization Roadmap)

초기에는 **'신뢰 구축(Trust Building)'**에 집중하고, 점진적으로 **'실질적 해결(Actionable Solution)'** 단계에서 수익을 창출합니다.

| 단계 | 기간 | 핵심 전략 | 수익 모델 초점 | 예상 전환 시점 |
| :--- | :--- | :--- | :--- | :--- |
| **Phase 1: Validation (MVP)** | 0 ~ 3개월 | **무료 제공 및 데이터 확보.** AI 에이전트 협업을 통한 운영 비용 최소화. Foundation 티어 집중. | 광고/파트너십 연계 (제한적) | 사용자 피드백 기반 기능 정의 시점 |
| **Phase 2: Traction (Growth)** | 3 ~ 9개월 | **성장 티어 도입.** 실질적인 법률 초안 생성 및 맞춤형 분석 기능(ROI 측정)을 유료화. | 구독 모델 (Subscription) | 사용자당 평균 수익(ARPU)이 초기 목표치 달성 시점 |
| **Phase 3: Scale (Enterprise)** | 9개월 이후 | **엔터프라이즈 티어 도입.** B2B 통합 솔루션 및 API 제공을 통해 대규모 고객 확보. | 라이선스/구독 + 컨설팅 서비스 결합 | 법률 자문 시장 내 AI 플랫폼 선두주자 포지셔닝 시점 |

### 4. 비즈니스 전략 요약 (A/B 근거)

**추천 전략: '진단 기반의 점진적 통제권 확보' 모델 (Risk-Based Progression)**

*   **근거:** 가장 높은 Pain Point(노무/규제 준수)에 대한 위험 예측(Risk Assessment)을 무료로 제공하여 사용자에게 즉각적인 가치를 전달하고, 이 데이터를 기반으로 유료 전환을 유도합니다.
*   **A안 (권장):** **Foundation $\rightarrow$ Growth**의 흐름을 강화하여, 사용자가 '위험 인식'에서 '구체적 해결책 확보'로 이동할 때마다 명확한 가치(ROI)를 제공하여 자연스러운 상향 전환을 유도합니다.
*   **B안 (대안):** 초기부터 **Growth 티어**에 집중하여 빠른 수익화를 시도하지만, 이는 신뢰 구축 단계에서 필요한 데이터 축적을 희생할 위험이 있습니다.
