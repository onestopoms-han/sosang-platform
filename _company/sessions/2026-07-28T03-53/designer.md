# ✨ 시스템 통제 대시보드 최종 QA 패스 (Final QA Pass)

**목표:** 데이터 변화 시각화가 단순한 움직임이 아닌, **'시스템 통제권 확보 경험(System Control Experience)'**을 제공하도록 애니메이션과 레이아웃을 최적화합니다.

## 1. 디자인 철학 요약 (Design Philosophy Summary)

*   **핵심 목표:** 사용자가 데이터를 '보는' 것이 아니라, 시스템이 '통제하는 과정'을 **체험(Experience)**하게 만든다.
*   **톤앤매너:** 학술적 권위(Scientific Authority) + 프리미엄 기술감(Premium Technology Feel).
*   **시각화 원칙:** 모든 시각적 강조는 데이터의 변화에 대한 **과학적 근거**를 명확히 제시해야 한다.

## 2. 색상 및 타이포그래피 가이드 (Color & Typography Guide)

| 요소 | 설정값 | 적용 목적 | 근거/설명 |
| :--- | :--- | :--- | :--- |
| **Primary Accent Color** | `#D4AF37` (Rich Gold) | 핵심 데이터 및 통제 지표 강조 | '골드'는 프리미엄성과 가치를 상징하며, 과학적 근거 기반의 권위를 부여함. |
| **Background Color** | `#F9F9F9` (Off-White/Light Gray) | 전반적인 배경 | 시각적 피로도를 낮추고 Gold 색상을 돋보이게 함. |
| **System Status Indicator** | Green (`#28A745`) / Amber (`#FFC107`) / Red (`#DC3545`) | 상태 변화 표시 | 명확한 시스템 상태(Control/Warning/Critical)를 직관적으로 전달. |
| **Data Value Display** | `Rich Gold` (가장 큰 폰트) | 핵심 수치 강조 | 데이터의 중요도를 시각적으로 최상위로 끌어올림. |
| **System Label Text** | Dark Gray (`#333333`) / Small Font Size | 시스템 지표 설명 (`control_score: XX%` 아래) | 과학적 근거(지표 설명)를 보조 정보로 배치하여 신뢰도를 뒷받침함. |

## 3. 동적 애니메이션 및 트랜지션 명세 (Dynamic Animation & Transition Specification)

이 섹션은 개발자가 코드를 구현할 때 반드시 준수해야 할 **정량적 기준**입니다.

### A. 데이터 변화 시퀀스 (Data Change Sequence)

데이터가 업데이트될 때, 단순한 값의 점프가 아닌 '시스템 처리 과정'을 표현해야 합니다.

1.  **트리거 지점:** 특정 단계(`step`)로 진입하거나(Phase 1 $\to$ Phase 2), 핵심 지표(`control_score`)가 임계값($X\%$)을 넘길 때를 트리거로 설정합니다.
2.  **애니메이션 방식:** **'Smooth Interpolation (부드러운 보간)'** 방식을 사용합니다. 급격한 변화 대신, 지정된 시간 동안 점진적으로 색상과 값의 변화를 반영해야 합니다.
3.  **색상 전환 로직:**
    *   `Phase 1` $\to$ `Phase 2` 전이 시: **Gold Accent**가 서서히 밝아지며(Lightening), 데이터 라인 자체가 부드럽게 이동하며(Smooth Movement) 다음 단계의 지표로 자연스럽게 연결되어야 합니다.
    *   색상 변화는 **Gold Gradient** 내에서 발생하여, '에너지 흐름' 또는 '통제권 이동'의 느낌을 시각적으로 전달해야 합니다.

### B. 트랜지션 시간 명세 (Transition Time Specification)

애니메이션의 속도는 '신중함'과 '프리미엄 경험'을 반영해야 합니다.

*   **기본 전환 시간:** 모든 주요 상태 변화(Step 전환, 지표 업데이트)는 **$1.5 \text{초} \sim 2.0 \text{초}$**를 기준으로 설정합니다. (느리고 신중한 진행감 부여)
*   **미세 조정 (Micro-Adjustment):** 데이터가 안정화된 후 최종 값(Final Value)이 표시될 때까지는 **$0.5 \text{초}$**의 잔여 애니메이션을 유지하여, 시스템이 완전히 '통제'했음을 시각적으로 확인시켜야 합니다.

## 4. UI 흐름 및 레이아웃 가이드 (UI Flow & Layout Guidance)

### A. 레이아웃 구조 (Layout Structure)

1.  **상단:** 대시보드 제목(`Title`)과 현재 시스템 상태(Overall Status Bar)를 가장 눈에 띄게 배치합니다.
2.  **중앙:** 동적 데이터 시뮬레이터(KineticGraph)가 화면의 **70% 이상**을 차지하도록 하여, '데이터 경험'에 집중할 수 있도록 합니다.
3.  **하단:** 핵심 지표(`Control Score`, `System Indicator`)를 카드 형태로 분리하여 배치하며, 여기에 **Gold Accent Color**를 사용하여 권위를 시각적으로 강조합니다.

### B. 사용자 여정 흐름 (User Journey Flow)

1.  **진입:** 사용자는 복잡한 수치에 압도되지 않고, Gold 색상과 깔끔한 레이아웃을 통해 '프리미엄 분석 도구'라는 인상을 받는다.
2.  **탐색:** 마우스 오버(Hover) 시, 시스템 지표 설명(`System Indicator Description`)이 부드럽게 나타나며 과학적 근거를 제공한다.
3.  **상호작용:** 데이터가 변할 때, 애니메이션은 **'처리 중'**의 느낌을 주어야 하며, 최종 결과는 **'통제 완료'**의 명확한 시각적 피드백으로 마무리되어야 합니다.
