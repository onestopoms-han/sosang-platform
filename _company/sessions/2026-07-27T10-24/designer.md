## Homepage 랜딩 페이지 기술 명세서: Authority Gauge 및 공급망 투명성 위젯

본 문서는 홈페이지의 핵심 요소인 'Authority Gauge'와 '공급망 투명성 위젯'의 최종 시각적 구현, 인터랙션 로직, 그리고 개발자 핸드오프를 위한 상세 기술 사양을 정의합니다. 모든 구현은 브랜드 정체성(Deep Charcoal Gray & Gold Accent)과 시스템 통제권 프리미엄을 극대화하는 데 초점을 맞춥니다.

---

### 1. Authority Gauge (권위 게이지) 기술 스펙

**목표:** 사용자가 시스템 통제권의 상승 과정을 시각적으로 인지하고, 제품에 대한 신뢰도를 즉각적으로 증명하도록 설계합니다.

#### 1.1. 애니메이션 시퀀스: '골드 인플로우' 효과
| 상태 변화 | 트리거 지점 (Trigger Point) | 지속 시간 (Duration) | 애니메이션 상세 (Visual Effect) | CSS/JS 이벤트 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 $\to$ L2** | 데이터 로드 완료 시 (State Change: `authorityLevel = 2`) | 800ms | 골드 액센트가 내부로 '흐르는(Inflow)' 모션. 게이지 채움이 부드럽게 변화하며 권위 레벨 표시. | `transition: all 0.8s cubic-bezier(...)` |
| **L2 $\to$ L3** | 데이터 로드 완료 시 (State Change: `authorityLevel = 3`) | 1200ms | 더 깊고 역동적인 골드 파동(Ripple) 효과 동반하며 최대치에 도달. 최종 권위 레벨 강조. | `animation-duration: 1.2s;` + `pulse-gold-ripple` class |
| **정적 상태** | 로딩 중 또는 최종 값 표시 시 | N/A | 정적인 골드 채움으로 현재 권위 수준을 명확히 표시. | `display: block;` (Static) |

#### 1.2. 상태 변화 로직 및 데이터 시각화 기준
*   **색상 스케일:** Gold Accent의 채움 정도는 L1(약한 황금빛) $\to$ L2(중간 골드) $\to$ L3(깊은 황금/골드 톤)으로 점진적으로 변화해야 합니다.
*   **데이터 연동:** 각 레벨(L1, L2, L3)에 도달할 때마다, 해당 권위와 연관된 핵심 데이터 지표(예: 공급망 투명성 지수, 농축도)가 아래 텍스트 영역에서 **강조 표시(Bold)** 되거나 **배경 색상이 미세하게 변화**하여 시각적 증거를 제공합니다.
*   **레이아웃:** 게이지 자체는 원형 또는 세로 막대 형태를 채택하며, 중앙에 현재 레벨 숫자(`L2`)와 전체 범위 내의 퍼센트 값(예: 66.6%)을 명확히 표시합니다.

#### 1.3. 개발자 핸드오프 가이드 (CSS/JS)
*   **컴포넌트 이름:** `.authority-gauge`
*   **기본 스타일:** `background-color: #1a1a1a; /* Deep Charcoal Gray 배경 */ padding: 20px; border-radius: 12px;`
*   **골드 액센트 변수:** `--gold-accent: #FFD700;` (또는 실제 사용된 골드 코드)
*   **상태 클래스 정의:**
    *   `.gauge-level-1`: 채움 비율 33% 이하, 색상 옅은 골드.
    *   `.gauge-level-2`: 채움 비율 66.6%, 기본 골드 인플로우 적용.
    *   `.gauge-level-3`: 채움 비율 100%, 최대 골드 파동 애니메이션 적용.
*   **인터랙션:** JavaScript의 `scroll` 또는 API 호출에 따라, 해당 클래스를 동적으로 토글하며, CSS 변수를 업데이트하여 실시간으로 시각화합니다.

### 2. 공급망 투명성 위젯 기술 스펙

**목표:** 제품의 근원지 및 생산 과정에 대한 데이터 기반의 신뢰(Trust)를 즉각적으로 제공하고, '데이터 기반 권위'를 시각적으로 입증합니다.

#### 2.1. 레이아웃 및 구조
*   **구성:** 수평 스크롤 가능한 카드 형식으로 구성하며, 각 공급망 단계(예: 재배 $\to$ 수확 $\to$ 가공)는 독립적인 위젯으로 존재합니다.
*   **디자인 원칙:** 배경은 어두운 차콜 그레이를 유지하고, 데이터 값과 핵심 정보에만 골드 텍스트 및 액센트를 적용하여 시선을 집중시킵니다.

#### 2.2. 데이터 시각화 기준 (Data Visualization)
*   **핵심 지표 표시:** 각 단계별로 다음 두 가지 정보를 필수적으로 노출합니다.
    1.  **정량적 수치:** 실제 측정된 데이터 (예: 농축도 $\text{X} \times$ 배, 수확 일수).
    2.  **시스템 증명:** 해당 수치가 어떤 시스템(AI 인공재배)에 의해 관리되었는지 명시하는 아이콘 또는 텍스트 레이블.
*   **권위 연계:** 각 지표 옆에는 **[근거: 데이터 기반 권위]**라는 작은 폰트로 해당 정보가 '시스템 통제권'의 일부임을 암시합니다.

#### 2.3. 개발자 핸드오프 가이드 (CSS/JS)
*   **컴포넌트 이름:** `.supply-chain-widget` 및 내부 `.stage-card`
*   **레이아웃:** Flexbox 또는 Grid를 사용하여 수평 스크롤을 지원하며, 카드 간 간격은 16px을 유지합니다.
*   **스타일링:**
    *   `.stage-card`: `background-color: #2a2a2a; border: 1px solid #444;` (차콜 그레이 계열)
    *   `data-value`: **골드 액센트**(`color: var(--gold-accent); font-size: 2.5rem;`)를 사용하여 핵심 수치를 강조합니다.
    *   `system-tag`: 작은 골드 색상의 배지 형태로, 해당 정보의 신뢰도를 나타냅니다.
