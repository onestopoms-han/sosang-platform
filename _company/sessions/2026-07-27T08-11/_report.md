---
### 1. 프로젝트 개요 & 목적
*   **제품군**: 바이오컴버젼 기술과 스마트방주 AI 인공재배 시스템으로 길러낸 프리미엄 "참송이버섯" (선물 세트, 패키지 상품 등).
*   **목표**: 세련되고 모던한 상품 상세페이지(PDP)를 개발하고, 실제로 사용자가 장바구니에 제품을 담고 가상 결제(Checkout)를 거쳐 마이페이지에서 주문 내역을 조회할 수 있는 완성도 높은 단일 페이지 앱(SPA) 쇼핑몰 구축.
*   **기술 스택**: React + TypeScript + Vite + Vanilla CSS
### 2. UI/UX 디자인 가이드라인
*   **비주얼 컨셉**: 자연(자연산 참송이버섯)과 첨단 기술(AI 바이오컴버젼)이 결합된 신비롭고 프리미엄한 이미지 구축.
*   **주요 색상**: 고급스러운 '딥 차콜 그레이(Deep Charcoal Grey)' 배경에 세련된 '골드(Gold)' 포인트 컬러를 얹어 고품격 브랜드 느낌을 극대화.
*   **시각화 요소**: 상품 상세 정보에 참송이버섯의 핵심 성분 함량 비율(예: 베타글루칸 등 영양 성분 수치)을 보여주는 깔끔한 원형/막대형 프로그레스 그래프 UI 포함.
### 3. 핵심 구현 기능 목록
1.  **브랜드 인트로/히어로 섹션**: 고화질 버섯 이미지와 프리미엄 카피라이팅이 포함된 매력적인 메인 배너.
2.  **상품 패키지/옵션 선택 영역**:
    *   참송이버섯 선물세트 1호, 2호, VIP 명품 세트 등 등급별 패키지 구성.
    *   포장 옵션 선택(일반 포장 / 고급 오동나무 박스 패키징 등) 및 실시간 가격 합산 로직.
3.  **장바구니 시스템**:
    *   선택한 상품과 수량, 패키지 옵션을 담을 수 있는 슬라이드 오프(Slide-over) 방식의 장바구니 UI.
    *   상품 수량 변경, 개별 삭제, 전체 총액 실시간 계산.
4.  **주문/결제 모달**:
    *   배송 정보(수령인, 연락처, 주소, 배송 메모) 입력 폼 제공.
    *   시뮬레이션 주문 승인 프로세스.
5.  **마이페이지 탭**:
    *   사용자가 시뮬레이션으로 완료한 가상 주문 내역 리스트 확인 영역.
    *   배송 상태 시뮬레이션(배송 준비중 -> 배송중 등).
---
이 설정을 기반으로 `src/App.tsx`와 `src/App.css`를 구조적이고 아름다운 프리미엄 디자인으로 재구성하는 개발 계획을 먼저 브리핑해 주세요.
