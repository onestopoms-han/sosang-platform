## 🎬 Instagram Reels 광고 캠페인 최종 기획안 (3종)

모든 캠페인은 **'Authority Flow'**의 시각적 전환(Red $\rightarrow$ Green/Gold)을 핵심으로 하며, 각기 다른 감정적 접근 방식을 통해 잠재 고객의 클릭과 참여를 유도합니다.

### 캠페인 1: 불안 해소 집중 (The Anxiety Relief Path)
*   **핵심 목표:** 복잡함에서 오는 **불안감**을 즉각적으로 해소하고 시스템에 대한 신뢰를 심어줌.
*   **적합한 카피 활용:** 버전 2 (불안 해소 및 시스템 강조)
*   **주요 타겟 감정:** 불안(Anxiety) $\rightarrow$ 안도(Relief)

| 항목 | 세부 기획 내용 |
| :--- | :--- |
| **릴스 콘셉트** | "관세 복잡성으로 인한 불안감, 이제 끝내고 명확한 안정감을 확보하세요." (문제 제시 후 즉각적인 해결책 제시) |
| **영상 길이** | 8~12초 (빠른 몰입 유도) |
| **훅 (Hook)** | 화면 시작과 동시에 강력한 질문 또는 문제 제기. |
| **Shot List & 연출 지침** | **[0-3s] 불안감 극대화:** 복잡한 관세 서류, 그래프가 뒤섞여 빠르게 지나가는 장면. 화면 전체에 강렬한 **Red** 필터 적용. (긴장감 조성) / **[3-6s] 전환점:** 화면 중앙에 리스크 점수(Score)가 빨간색으로 강조되며 멈춤. '당신의 통제권은 어디에 있나요?' 자막 오버레이. / **[6-10s] 해결책 제시:** AI 대시보드가 등장하며, 리스크 점수가 녹색/골드로 변하는 마이크로 인터랙션 시퀀스(Designer 기획 적용). 'Actionable Blueprint'가 깔끔하게 정리되어 나타남. (안도감 극대화) |
| **Voiceover/자막** | *VO:* "복잡한 관세, 더 이상 불안해하지 마세요." / *자막:* "불안 $\rightarrow$ 통제권 회복" |
| **추천 게시 시간** | 화요일 또는 목요일 저녁 7시 (업무 시작 전/후 휴식 시간) |
| **후속 스토리 아이디어** | Q&A 스티커: "관세 리스크, 가장 불안한 부분은 무엇인가요?" (참여 유도 및 Pain Point 수집) |
| **차별화 해시태그** | `#관세불안해소` `#통제권회복` `#리스크관리AI` `#무역자동화` `#사업자안심` `#AuthorityFlow` `#CustomsTech` |

### 캠페인 2: 권위 확보 집중 (The Authority Flow Path)
*   **핵심 목표:** AI가 단순한 정보 제공자가 아닌, **권위를 확보해주는 파트너**임을 강조.
*   **적합한 카피 활용:** 버전 1 (통제권 회복 강조)
*   **주요 타겟 감정:** 불확실성(Uncertainty) $\rightarrow$ 자신감(Confidence)

| 항목 | 세부 기획 내용 |
| :--- | :--- |
| **릴스 콘셉트** | "단순히 법을 지키는 것을 넘어, 당신의 비즈니스를 완벽하게 통제하는 권한을 되찾으세요." (AI를 통한 권위 확보 시연) |
| **영상 길이** | 10~15초 (정보 전달 및 신뢰 구축) |
| **훅 (Hook)** | 전문가적인 어조로 시작하며, 기존 방식의 한계를 지적. |
| **Shot List & 연출 지침** | **[0-4s] 문제 제기:** 전통적인 서류 작업이나 복잡한 계산에 시달리는 모습 (약간 어두운 톤). / **[4-8s] AI 등장 및 변화:** 화면이 전환되며, AI 인터페이스가 등장. 데이터 분석 과정(백엔드 로직)을 간결하게 보여주며 '숨겨진 리스크'를 찾아내는 과정을 시각화. (Authority Flow의 논리적 연결 강조) / **[8-15s] 결과 제시:** 최종적으로 시스템이 명확한 'Actionable Blueprint'를 제시하는 장면. 사용자(직원)가 자신감 있게 다음 행동을 실행하는 모습으로 마무리. |
| **Voiceover/자막** | *VO:* "당신의 비즈니스를 완벽하게 통제하는 권한을 되찾으세요." / *자막:* "준수 $\rightarrow$ 통제권 확보" |
| **추천 게시 시간** | 월요일 오전 10시 (전문적인 시작) 또는 금요일 오후 (주간 정리) |
| **후속 스토리 아이디어** | 설문 스티커: "당신은 현재 얼마나 많은 리스크를 '통제'하고 있나요?" (자체 진단 유도) |
| **차별화 해시태그** | `#AuthorityFlow` `#AIforBusiness` `#무역권위` `#데이터기반결정` `#BDS플랫폼` `#리스크관리시스템` `#SmartCustoms` |

### 캠페인 3: 실질적 행동 집중 (The Actionable Solution Path)
*   **핵심 목표:** 시스템이 제공하는 **실행 가능한 결과물(Blueprint)**에 초점을 맞춰 즉각적인 사용을 유도.
*   **적합한 카피 활용:** 버전 4 (직접적인 해결책 제시 CTA)
*   **주요 타겟 감정:** 막막함(Overwhelmed) $\rightarrow$ 명료함(Clarity)

| 항목 | 세부 기획 내용 |
| :--- | :--- |
| **릴스 콘셉트** | "당신의 다음 행동 계획(Blueprint)을 즉시 확인하고 실행하기." (가장 실용적인 가치 제공) |
| **영상 길이** | 7~10초 (정보 전달의 효율성 강조) |
| **훅 (Hook)** | '무엇을 해야 할지 모르는' 혼란스러운 상태를 직접적으로 보여줌. |
| **Shot List & 연출 지침** | **[0-2s] 혼란:** 수많은 법규 문서와 체크리스트가 화면을 가득 채우며 빠르게 스크롤됨. (Overwhelmed) / **[2-5s] 시스템 개입:** 모든 정보가 AI 대시보드 안으로 깔끔하게 정리되며, 복잡한 데이터가 'Actionable Blueprint'라는 명확한 단계로 압축되는 시각적 연출. (Clarity 확보) / **[5-10s] 실행 강조:** 가장 중요한 다음 단계(Step 1: 확인 경로 확보 등)에 커서가 포커스되며, 사용자가 자신감 있게 마우스/손가락으로 클릭하는 모습 클로즈업. |
| **Voiceover/자막** | *VO:* "더 이상 고민하지 마세요. 당신의 다음 행동 계획을 확인하고 실행하세요." / *자막:* "복잡함 $\rightarrow$ 명료한 실행" |
| **추천 게시 시간** | 수요일 오후 2시 (업무 중 집중력 향상 시점) |
| **후속 스토리 아이디어** | 링크 스티커: 'Actionable Blueprint 바로가기' (릴스 시청자에게 직접적인 다음 행동 유도) |
| **차별화 해시태그** | `#ActionableGuide` `#실행가능한솔루션` `#CustomsBlueprint` `#AI워크플로우` `#시간절약` `#BDS솔루션` `#BusinessAutomation` |
