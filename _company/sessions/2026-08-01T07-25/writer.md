# 🚀 랜딩 페이지 카피 흐름 재구성: 불안 $\rightarrow$ 통제권 확보

## 1단계: 불안 인식 (Anxiety Recognition)
**목표:** 잠재 고객이 현재 느끼는 혼란과 위험을 정확히 포착하여 즉각적인 공감을 유도합니다. (Hook 영역)
**톤앤매너:** 긴급함, 경고, 공감적 질문.

| 카피 유형 | 마이크로카피 세트 (선택) | 강조점 |
| :--- | :--- | :--- |
| **메인 헤드라인 (H1)** | **당신의 비즈니스, 통제 불능 상태인가요?** | 직접적인 질문으로 즉각적인 주의 집중. |
| **서브 헤드라인** | 눈에 보이지 않는 리스크가 성장을 멈추게 합니다. | 불안의 근원을 시스템 문제로 연결. |
| **Pain Point (Bullet)** | ✅ 재정적 불확실성: 다음 분기 예산은 예측 불가능합니다. | 구체적인 비즈니스 고통 제시. |
| | ✅ 운영 효율성: 숨겨진 병목 현상이 성장을 방해합니다. | |
| | ✅ 규제 위험: 복잡한 법규 속에서 리스크를 놓치고 있진 않나요? | |

## 2단계: 해결책 제시 (Solution Presentation)
**목표:** RRS라는 시스템적 측정값을 통해 고객의 불안을 구체적인 데이터로 전환하고, 서비스가 그 해답임을 제시합니다. (Body/Mechanism 영역)
**톤앤매너:** 권위적, 과학적, 명확한 프로세스 제시.

| 카피 유형 | 마이크로카피 세트 (선택) | 강조점 |
| :--- | :--- | :--- |
| **솔루션 프레임** | **불안을 숫자로 측정하고, 통제권을 되찾으세요.** | 핵심 가치(RRS)를 명확히 정의. |
| **메커니즘 설명** | 우리는 단순한 정보가 아닌, **리스크 감소 점수(RRS)**라는 객관적 지표를 제공합니다. | 서비스의 차별점(데이터 기반 접근) 강조. |
| **변화 과정** | **Red $\rightarrow$ Yellow $\rightarrow$ Gold:** 리스크가 관리 가능한 행동으로 전환되는 실시간 여정. | 시각화된 변화 프로세스 제시. |
| **핵심 문구** | 당신의 모든 위험 요소를 정량화하여, 최적의 대응책을 설계합니다. | 시스템 설계자로서의 포지셔닝 강조. |

## 3단계: 통제권 확보 (Control Acquisition & CTA)
**목표:** 다음 행동에 대한 명확한 이유를 제공하고, 망설임을 제거하며 즉각적인 행동(유료 전환)을 유도합니다. (CTA 영역)
**톤앤매너:** 자신감, 실행 지향적, 확신 부여.

| 카피 유형 | 마이크로카피 세트 (선택) | 강조점 |
| :--- | :--- | :--- |
| **최종 제안** | **더 이상 추측하지 마세요. 데이터 기반으로 다음 행동을 결정하십시오.** | 실행의 당위성 부여. |
| **CTA 버튼 1 (Primary)** | **나의 리스크 점수 확인하고 액션 플랜 받기** | 결과(점수)와 행동(플랜)을 연결하여 클릭 유도. |
| **CTA 버튼 2 (Secondary)** | RRS 기반 상세 로드맵 보기 | 심화 정보에 대한 접근성 제공. |
| **긴급성 부여** | 통제권은 지금, 당신의 손에 있습니다. | 즉각적인 행동 촉구. |
