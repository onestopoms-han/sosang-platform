<create_file path="sessions/2026-8-15T12-58-00/authority_flow_tech_spec.md"># Authority Flow 시각화 컴포넌트 핸드오프 스펙 (V2.0)\n\n## 1. 목표 및 원칙\n이 문서는 'Authority Flow' 상태 변화(Risk $\rightarrow$ Control)에 따른 Pain Gauge/KPI의 동적 시각화 로직을 개발팀에 전달하기 위한 기술 명세입니다. 모든 애니메이션은 **데이터 기반 권위(Data-based Authority)**를 시각적으로 증명해야 합니다.\n\n## 2. 색상 및 상태 매핑\n| 상태 (State) | 색상 (Color) | 의미 (Authority Flow) | 시스템 지표 (KPI Mapping) | 주요 애니메이션 목표 | 근거 | \n| :--- | :--- | :--- | :--- | :--- | :--- | \n| **High Risk** | Red (`#FF4500`) | 즉각적 개입 필요 (Loss Zone)\n| **Warning/Action** | Amber (`#FFD700`) | 선제적 조치 필요 (Mitigation Zone)\n| **Control Achieved** | Gold (`#FFD700`) | 통제권 확보 단계 (Recovery Zone)\n| **Stable/Safe** | Deep Forest Green (`#3CB371`) | 안정 상태 (Safety Zone)\n\n## 3. 애니메이션 상세 스펙 (Red $\rightarrow$ Gold $\rightarrow$ Green Transition)\n애니메이션은 단순한 색상 변화가 아닌, **'위험 인식(Risk Acknowledgment)'**에서 **'통제권 확보(Control Acquisition)'**로의 심리적 흐름을 반영해야 합니다.\n\n### 3.1. 키프레임 및 속도 설정 (CSS Animation)\n애니메이션은 `transition` 대신 명확한 `keyframes`를 사용하여 상태 변화의 의도를 강조합니다.\n\n```css\n@keyframes authority-transition {\n  0% { /* High Risk: Red */\n    background-color: #FF4500; /* Red */\n    box-shadow: 0 0 10px rgba(255, 69, 0, 0.7); \n  }\n  30% { /* Transition to Warning/Action: Amber */\n    background-color: #FFD700; /* Amber */\n    box-shadow: 0 0 10px rgba(255, 215, 0, 0.7); \n  }\n  60% { /* Transition to Control Achieved: Gold */\n    background-color: #FFD700; /* Gold - 통제권 확보 시점 강조 */\n    box-shadow: 0 0 15px rgba(255, 215, 0, 1); \n  }\n  100% { /* Stable/Safe: Deep Forest Green */\n    background-color: #3CB371; /* Green */\n    box-shadow: 0 0 15px rgba(60, 179, 113, 1); \n  }\n}\n\n/* 적용 예시 */\n.pain-gauge { \n  animation: authority-transition 4s ease-in-out forwards; \n}\n```\n\n### 3.2. 마이크로 인터랙션 지점별 요구사항 (Pseudo Code Level)\n사용자가 특정 임계값을 넘을 때(예: Red $\rightarrow$ Amber, Amber $\rightarrow$ Gold) 시각적 피드백과 함께 **명확한 행동 유도**를 제공해야 합니다.\n\n```javascript\n// 상태 변화 로직 예시 (React/State Machine 기반)\nfunction handleAuthorityChange(currentState, nextState) {\n  let animationDuration = 4000; // 기본 전환 시간\n  let feedbackAction = '';\n\n  switch (currentState) {\n    case 'High Risk':\n      // Red -> Amber (경고 발생 시)\n      if (nextState === 'Warning') {\n        animationDuration = 1500; // 짧고 긴급한 경고\n        feedbackAction = 'Immediate Action Required: Mitigation Step A';\n      }\n      break;\n    case 'Warning':\n      // Amber -> Gold (통제권 확보 성공 시)\n      if (nextState === 'Control') {\n        animationDuration = 2500; // 성취감을 강조하는 전환\n        feedbackAction = 'Authority Acquired: System Control Restored';\n      }\n      break;\n    case 'Control':\n      // Gold -> Green (안정 상태 진입 시)\n      if (nextState === 'Stable') {\n        animationDuration = 3000; // 안정감을 주는 전환\n        feedbackAction = 'System Stable: Authority Flow Complete';\n      }\n      break;\n  }\n\n  // UI에 피드백 메시지 삽입 로직\n  if (feedbackAction) {\n    displayNotification(feedbackAction, animationDuration);\n  }\n\n  // CSS 애니메이션 클래스 업데이트\n  applyClassName(nextState);\n}\n```\n\n## 4. 데이터 레이블링 및 권위 표시\n모든 시각화 요소는 **'데이터 기반 권위'**를 명시해야 합니다.\n\n*   **핵심 수치 강조:** `Control Score: XX%` (골드 색상으로 강조)\n*   **시스템 지표 설명:** 그 아래에 작은 폰트로 `시스템 통제권 확보율: XX%`를 배치하여 시각적 강조가 과학적 근거에 기반함을 명시합니다.
