### 2. 'Authority Flow Risk Score' 계산을 위한 핵심 입력 변수 검토

현재 요구사항(HS Code 기반 리스크 지표, 원산지법 관련 규정 등)이 Authority Flow 모델에 충분히 커버되는지 검토한 결과는 다음과 같습니다.

| 필요한 입력 변수 | 현재 데이터 접근성 (검증 필요) | 권장 조치 사항 |
| :--- | :--- | :--- |
| **HS Code 기반 리스크 지표** | **데이터 확보가 가장 시급함.** (관세청 통계/규정 연동 필요) | HS Code별로 분류된 과거 통관 데이터 또는 법적 규제를 매핑하는 로직 개발에 집중해야 함. |
| **원산지법 관련 규정** | **문서 기반 분석이 필수적.** (FTA 및 국내법 텍스트 분석 필요) | 특정 원산지 규칙(Rules of Origin)을 AI가 해석하여 리스크 가중치로 변환하는 자연어 처리(NLP) 모듈 개발에 집중해야 함. |
| **운영 효율성 데이터** | **외부 데이터 연동 필요.** (물류 비용, 선적 시간 등) | 실제 운송 데이터를 통합할 수 있는 외부 API 또는 연동 방안을 다음 단계에서 탐색해야 함. |

**결론:** 공공 데이터의 존재는 확인되나, 이 데이터를 'Authority Flow' 계산에 바로 투입 가능한 **정량화된 지표(Metric)**로 변환하는 과정이 현재 가장 큰 리서치 과제입니다.
