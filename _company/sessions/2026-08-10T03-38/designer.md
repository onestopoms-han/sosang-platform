## 📄 인포그래픽 브리프: HS Code 84.84 분류 결정 플로우 차트

본 문서는 HS Code 84.84 항목에 대한 복잡한 규정(A, B, C 분류)을 사용자가 직관적으로 이해하고 정확하게 분류할 수 있도록 **'Decision Flow Chart (결정 흐름도)'** 와이어프레임 구상 및 디자인 지침을 제공합니다.

---

### 1. 디자인 목표 (Design Goal)

사용자가 품목의 본질(구조, 구성, 기능)을 스스로 판단하여 최종 HS Code를 도출하도록 유도하는 **'인지 부하 최소화'** 와이어프레임을 제작합니다. 시각적 계층 구조와 명확한 분기를 통해 규정의 모호함을 제거하고 '통제권 확보'의 느낌을 전달해야 합니다.

### 2. 레이아웃 및 구성 (Layout & Structure)

*   **레이아웃 형태:** 수직형(Vertical Flow), 또는 중앙 집중형(Centralized Hub)의 다이아몬드 분기 구조를 권장합니다.
*   **핵심 요소:** 각 단계는 명확한 질문과 그에 따른 **Yes/No 분기**로 구성되어야 합니다.
*   **색상 시스템 적용 (Designer System Guide 기반):**
    *   **시작 노드 (Start Node):** 차분한 톤 (Deep Forest Green 계열).
    *   **질문 노드 (Decision Nodes):** 경고/주의 상태 (Amber 계열).
    *   **결과 노드 (Outcome Nodes - HS Codes):** 통제권 확보의 상징인 **Rich Gold**를 사용하여 최종 결과를 강조합니다.

### 3. 플로우 차트 상세 와이어프레임 구상 (Flow Chart Wireframe Blueprint)

다음은 실제 디자인에 적용할 수 있는 단계별 구조입니다.

| 단계 | 노드 유형 | 질문 내용 (사용자에게 제시) | 분기 선택지 | 연결될 다음 단계 | 예상 HS Code 매핑 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Start** | 시작점 (Green) | **품목의 핵심 기능은 무엇입니까?** | 1. 고정된 결합부인가? / 2. 움직이는 부품 간의 밀봉(Seal)인가? / 3. 여러 재질이 포장되어 있는 세트인가? | → Step 1 또는 Step 2 또는 Step 3 | N/A |
| **Step 1** | 구조 질문 (Amber) | **[구조 확인] 이 품목은 금속 시트와 다른 재료의 결합(가스켓/접합부)을 포함합니까?** | Yes / No | → Step 2 또는 Step 3 | 8484.10 (Yes), 나머지 (No) |
| **Step 2** | 세트 질문 (Amber) | **[구성 확인] 이 품목은 서로 다른 재질의 가스켓/접합부들이 포장재(주머니, 박스 등)에 담긴 '세트'입니까?** | Yes / No | → Step 3 | 8484.90 (Yes), 나머지 (No) |
| **Step 3** | 기능 질문 (Amber) | **[기능 확인] 이 품목은 움직이는 표면 사이의 누설 방지(Mechanical Seal)를 위한 기계적 어셈블리입니까?** | Yes / No | → 최종 결과 | 8484.20 (Yes), 나머지 (No) |
| **End** | 결과 노드 (Gold) | **최종 분류 코드 선택:** | - | - | **8484.10, 8484.20, 8484.90** |

### 4. 시각적 디자인 지침 (Visual Design Guidelines)

1.  **폰트 및 강조:**
    *   질문 텍스트는 명확하고 읽기 쉬운 산세리프체(예: Inter, Pretendard)를 사용하며, **Bold** 처리합니다.
    *   Yes/No 분기 버튼은 크고 직관적인 원형 또는 사각형으로 디자인하여 클릭 유도성을 높입니다.
2.  **색상 활용:**
    *   Green $\rightarrow$ 안정성 (Start)
    *   Amber $\rightarrow$ 판단 필요 (Decision Points)
    *   Gold $\rightarrow$ 최종 권위/결과 (HS Code Output)
3.  **데이터 레이블링 (권위 강화):**
    *   각 분기 노드 옆에는 해당 분류 기준(A, B, C 중 어느 것에 해당하는지)을 매우 작은 폰트(`font-size: 10px;`, 회색)로 명시하여, 시각적 강조가 **'과학적 근거'**에 기반함을 다시 한번 확립합니다. (이전 가이드라인 참조)
