# 🖥️ 랜딩 페이지 와이어프레임 초안: System Sovereignty 버전

**🎨 디자인 컨셉:** **Bio-System Dashboard (생체 시스템 대시보드)**
**주요 컬러:** Deep Forest Green (배경, 안정감) + Gold Accent (데이터 강조, 프리미엄 가치)
**톤앤매너:** 과학적 권위, 고급스러운 투자 보고서, 데이터 중심의 통제권.

## 1. 헤더 및 도입부 (Authority & Hook)

| 섹션 | 제목/내용 | 시각적 요소 (Visual Elements) | 디자인 지침 (Design Directives) |
| :--- | :--- | :--- | :--- |
| **Header** | 로고, 내비게이션 (시스템 진입, 데이터 대시보드, 구독 모델 등) | 미니멀하고 고급스러운 골드 라인 사용. | 배경은 어두운 포레스트 그린 톤 유지. |
| **Hero Section** | **메인 슬로건:** "당신의 생체 시스템을 설계하다: 바이오컴버젼 송이버섯, 시스템 주권을 확보하는 프리미엄 자산." | 중앙에 고해상도 참송이골드 이미지 (신선함 강조). 배경에 은은한 데이터 패턴 또는 미생물 네트워크 시각화 오버레이. | H1 텍스트는 화이트 또는 골드로 강하게 대비. CTA 버튼은 Gold Accent 색상으로 강조. |
| **Sub-Hook** | "더 이상 추측은 없다. 데이터 기반으로 당신의 건강 시스템을 최적화하고 통제하세요." (Writer 카피 인용) | 핵심 가치 3가지(시스템 주권, 예측, 투자)를 아이콘과 함께 배치. | 신뢰감을 주는 미니멀한 인포그래픽 스타일. |

## 2. 문제 인식 및 솔루션 제시 (The Reframing)

| 섹션 | 제목/내용 | 시각적 요소 (Visual Elements) | 디자인 지침 (Design Directives) |
| :--- | :--- | :--- | :--- |
| **Section 2.1** | **"왜 일반적인 건강 관리는 실패하는가?"** (Pain Point 명확화) | 불확실성을 상징하는 어두운 배경과 대비되는 불안정한 라인 그래프 또는 모호한 이미지. | 사용자의 현재 상황에 대한 공감을 유도하며, '통제권 부재'를 문제로 설정. |
| **Section 2.2** | **"시스템 자산으로서의 참송이골드"** (Solution Introduction) | 균사 네트워크(Mycelium Network)의 추상적이고 아름다운 3D 시각화 모션 또는 정적인 일러스트. | 제품을 단순한 버섯이 아닌, 복잡하게 얽힌 생체 시스템의 '핵심 인프라'로 정의하는 시각적 강조. |

## 3. 핵심 차별화 (The Proof - Interactive Data Focus)

**💡 이 섹션은 랜딩 페이지의 권위를 결정하며, 사용자에게 '데이터 기반'이라는 느낌을 심어줍니다.**

| 섹션 | 제목/내용 | 시각적 요소 (Visual Elements) | 디자인 지침 (Design Directives) |
| :--- | :--- | :--- | :--- |
| **Section 3.1** | **[핵심 차별점] 데이터가 증명하는 시스템의 진화** | **인터랙티브 그래프 배치:** **'시스템 안정성 점수 변화 그래프 (System Stability Score)'** | **차트 디자인:** Deep Forest Green 배경에 Gold 라인과 포인트 사용. X축은 시간/단계, Y축은 시스템 점수(0~100). 각 단계(Core $\rightarrow$ Elite $\rightarrow$ Sovereignty+)별로 곡선이 명확하게 분리되어 상승하는 모습을 시각화. |
| **Section 3.2** | **[독점적 데이터] 예측 엔진의 작동 방식** | **미생물 다양성 매트릭스 (Microbial Diversity Matrix)** | 복잡한 데이터(15차 융합 과정)를 단순화된 히트맵 또는 매트릭스로 표현. '독점적 시스템 솔루션'이 어떻게 데이터를 생성하고 예측하는지 간결하게 보여주는 인포그래픽. |
| **Section 3.3** | **"시스템 운영자(System Operator)"의 여정** | Funnel 구조를 시각적으로 재배치. Core $\rightarrow$ Elite $\rightarrow$ Sovereignty+ 단계가 명확한 레벨로 표시됨. | 각 단계별로 달성해야 할 목표와 그에 따른 '권한' 변화를 아이콘과 함께 배치하여, 고객이 어디에 있는지 즉시 인지하게 함. |

## 4. 구독 및 전환 (The Investment Funnel)

| 섹션 | 제목/내용 | 시각적 요소 (Visual Elements) | 디자인 지침 (Design Directives) |
| :--- | :--- | :--- | :--- |
| **Section 4.1** | **시스템 투자 레벨 선택** | 세 가지 구독 플랜(Core, Elite, Sovereignty+)을 카드 형태로 배치. 각 카드는 Gold 테두리로 강조됨. | 가격보다는 '획득하는 권한'을 강조. (예: Core는 '접근 권한', Sovereignty+는 '자산 관리 권한'). |
| **Section 4.2** | **Call to Action (CTA)** | 각 레벨에 맞는 CTA 버튼 배치. | 가장 상위 레벨(Sovereignty+)로의 전환을 유도하는 강력한 문구 사용. |
