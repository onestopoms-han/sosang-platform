기존의 브랜드 시스템(Deep Blue, Growth Green)과 핵심 마케팅 논리([경고 $\rightarrow$ 원리 제시 $\rightarrow$ 안정화])를 게이지 내러티브에 완벽하게 통합하여 Mockup Level 디자인 사양을 확정합니다.

## SSI 게이지 미터 인터랙티브 UI Mockup 최종 디자인 브리프

### 1. 색상 및 타이포그래피 시스템 (Color & Typography System)

*   **Primary Color (신뢰/시스템):** Deep Blue (`#004D66`) - 데이터의 심층적 분석과 과학적 권위를 표현합니다.
*   **Secondary Color (성장/해결):** Growth Green (`#3CB371`) - 긍정적인 변화와 시스템 최적화의 이득을 표현합니다.
*   **Accent Color (경고/위기):** Amber/Orange 계열 (예: `#FFC300` 또는 `Deep Blue`에서 파생된 따뜻한 색) - 위험 신호 및 즉각적인 주의를 요구하는 경고 단계에 사용합니다.
*   **Typography:** Sans-serif 계열 중, 전문성과 가독성이 높은 폰트 (예: Inter 또는 Montserrat). 모든 수치는 명확하고 간결하게 제시되어야 합니다.

### 2. 레이아웃 및 구조 설계 (Layout & Structure Design)

게이지 전체를 **3단계 논리 흐름**을 반영하는 하나의 통합된 시각적 여정(Journey)으로 설계합니다.

| 단계 | 논리 (Message) | 게이지 상태 (Visual State) | 색상 적용 (Color Application) | 주요 텍스트 지시 (Callout Text) |
| :--- | :--- | :--- | :--- | :--- |
| **1단계: 경고 (Warning)** | **위기 인식** (현재 시스템 상태 진단) | 게이지의 시작점 또는 낮은 레벨 (Low/Critical Zone) | Deep Blue 배경, 위기 구간은 Amber/Orange 강조 | "시스템 경고: 현재 상태 분석 필요" |
| **2단계: 원리 제시 (Principle)** | **해결책 제시** (과학적 메커니즘 이해) | 게이지의 중간 영역 (Transition Zone) | Deep Blue와 Growth Green의 그라데이션 혼합 | "미토콘드리아 최적화 원리 적용" |
| **3단계: 안정화 (Stabilization)** | **최종 결과** (시스템 주권 확보) | 게이지의 최대 레벨 (Optimal/Master Zone) | Growth Green 강조, 성공적인 완료 표시 | "시스템 안정화: 최적 상태 달성" |

### 3. 인터랙션 및 애니메이션 설계 (Interaction & Animation Design - Mockup Level)

사용자가 데이터를 보고 '경고 $\rightarrow$ 원리 제시 $\rightarrow$ 안정화' 흐름을 체험하도록 동적인 상호작용을 설계합니다.

1.  **데이터 흐름 애니메이션:** 사용자가 슬라이더나 데이터 입력 필드를 조작할 때, 게이지는 정지된 상태가 아니라 **실시간으로 변화하며** 각 단계의 색상과 텍스트 레이어가 순차적으로 활성화되도록 설계합니다.
    *   (예시) 사용자가 특정 지점에 도달하면, 경고 영역이 사라지고 원리 제시 구간이 확장되며, 최종적으로 안정화 구간에 Growth Green이 채워지며 "시스템 주권 확보"라는 최종 메시지가 강조되어야 합니다.
2.  **게이지 시각화:** 단순한 선형 게이지 대신, **생체 시스템의 흐름(Flow)**을 연상시키는 유기적인 곡선 또는 원형 디자인을 사용하여 '살아있는 데이터'의 느낌을 부여합니다.
3.  **권위 확보 요소:** 각 단계 전환 시, 해당 섹션에 과학적 근거(예: 미토콘드리아 관련 그래프 아이콘이나 작은 팩트 박스)가 간결하게 나타나도록 설계하여, 디자인이 단순한 UI가 아닌 **'데이터 기반 권위 증명 도구'**임을 강조합니다.

### 4. 최종 시스템 스펙 요약 (Final System Specification Summary)

*   **레이아웃:** 중앙에 유기적인 게이지를 배치하고, 그 주변에 3단계 논리 박스를 배치하여 설명의 흐름을 명확히 합니다.
*   **핵심 시각 요소:** Deep Blue 배경 위에 Growth Green으로 점진적 채워지는 동적 게이지 애니메이션이 핵심입니다.
*   **톤앤매너:** 차갑고 냉철한 과학적 데이터(Deep Blue)와 따뜻하고 긍정적인 성장(Growth Green)의 대비를 통해, 고객에게 **'불안 해소 $\rightarrow$ 확신 제공'**이라는 감성적 경험을 동시에 전달합니다.

## 🚀 핵심 목표
데이터 변화의 흐름을 직관적으로 보여주는 애니메이션/인터랙션 설계 및 '위기-원리 제시-안정화' 논리를 시각적 구조에 녹여내는 레이아웃 확정.

## 🎨 디자인 시스템 적용
*   **Primary Color (신뢰):** Deep Blue (`#004D66`)
*   **Secondary Color (성장):** Growth Green (`#3CB371`)
*   **Accent Color (경고):** Amber/Orange 계열 (`#FFC300` 또는 파생 색상)

## 📊 레이아웃 구조 (3단계 논리 흐름)
### SECTION 1: 경고 (Warning - 현재 상태 진단)
*   **배경:** Deep Blue.
*   **게이지:** 낮은 레벨 표시 (Critical Zone).
*   **텍스트:** "시스템 경고: 현재 시스템 상태 분석 필요" (Accent Color 강조).
*   **목표:** 사용자가 즉각적인 문제 인식을 하도록 유도.

### SECTION 2: 원리 제시 (Principle - 과학적 해결책)
*   **배경:** Deep Blue에서 Growth Green으로 부드럽게 전환되는 그라데이션 영역.
*   **게이지:** 변화 과정(Transition Zone).
*   **텍스트:** "미토콘드리아 최적화 원리 적용" (Growth Green 텍스트 강조).
*   **목표:** 데이터 변화의 과학적 메커니즘을 제시하여 신뢰 확보.

### SECTION 3: 안정화 (Stabilization - 최종 결과)
*   **배경:** Growth Green 지배적인 영역.
*   **게이지:** 최대 레벨 표시 (Optimal/Master Zone).
*   **텍스트:** "시스템 안정화: 최적 상태 달성" (Growth Green 강조).
*   **목표:** 시스템 주권 확보라는 최종 이득을 시각적으로 확정.

## ✨ 인터랙션 설계 지침 (Interaction Guidelines)
1.  **동적 흐름:** 사용자의 입력에 따라 게이지는 세 섹션을 순차적으로 확장하며, 각 단계의 색상 전환은 부드러운 애니메이션(Smooth Transition)으로 이루어져야 합니다.
2.  **권위 부여:** 각 단계 사이에 '원리 제시' 구간에서는 관련 과학적 키워드를 미니 팝업 형태로 노출하여 디자인에 논리적 깊이를 더합니다.
3.  **최종 CTA:** 안정화 단계 완료 시, 가장 크고 명확하게 **"시스템 주권 확보 경험"**이라는 메시지를 Growth Green 배경 위에서 최종적으로 강조해야 합니다.
