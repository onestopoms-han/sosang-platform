## 📊 최종 마케팅 퍼널 설계: 잠재 고객 유입 $\rightarrow$ 신뢰 구축 $\rightarrow$ 전환

이 퍼널은 잠재 고객의 **불안감(Pain)**을 자극하여, 참송이골드가 제공하는 **시스템적 통제권 회복**이라는 해답을 제시하고, 최종적으로 구매로 이어지도록 설계되었습니다.

### 1단계: 유입 (Acquisition) - Pain Point 자극 및 관심 유발
**목표:** 잠재 고객의 불안감(Pain)을 즉각적으로 인지시키고, 참송이골드가 제공하는 '시스템적 해결책'에 대한 호기심을 유발하여 트래픽을 확보합니다.

| 항목 | 세부 내용 | 근거/연결 요소 |
| :--- | :--- | :--- |
| **핵심 목표 KPI** | 노출 대비 클릭률 (CTR) > 5%, 영상 시청 지속률 > 40% | 초기 트래픽 확보의 효율성 측정 |
| **콘텐츠 유형** | **인스타그램 릴스 / 유튜브 쇼츠** (Pain $\rightarrow$ Solution 제시) | 짧고 강렬한 후크(Hook)를 통해 즉각적인 주의 집중 |
| **주요 메시지** | "당신의 건강, 불확실성에 맡기시겠습니까? 시스템의 통제권을 되찾으세요." (불안감 자극) | 'Pain' 단계에 집중 |
| **첫 번째 CTA** | **"시스템적 불안정성 확인하기"** (관련 랜딩페이지 유도) | 단순 정보 제공이 아닌, 문제 진단을 위한 다음 단계로의 이동 유도 |

### 2단계: 신뢰 구축 (Trust Building) - 시스템 검증 및 권위 확보
**목표:** 고객에게 참송이골드가 제시하는 데이터 기반의 해결책(Trust Widget/데이터 시각화)을 명확히 보여주어, 브랜드에 대한 심리적 신뢰를 극대화합니다.

| 항목 | 세부 내용 | 근거/연결 요소 |
| :--- | :--- | :--- |
| **핵심 목표 KPI** | 페이지 체류 시간 (Dwell Time) > 3분, 리드 확보율(Lead Capture Rate) > 15% | 콘텐츠 깊이와 정보의 신뢰도를 측정 |
| **콘텐츠 유형** | **유튜브 상세 영상 / 랜딩페이지** (데이터 시각화 및 시스템 설명) | Trust Widget의 작동 원리, A/B/C 등급 변화를 구체적인 그래프로 시연 |
| **주요 메시지** | "우리는 감이 아닌 데이터로 건강을 통제합니다. 실시간으로 확인 가능한 시스템 무결성." (해답 제시) | 'Control' 단계에 집중하며 신뢰 증명 |
| **첫 번째 CTA** | **"시스템 무결성 대시보드 상세 분석 보기"** (Trust Widget 프로토타입 페이지로 유도) | 데이터 기반의 깊은 정보 접근을 통해 신뢰를 강화하고 잠재 고객 정보를 확보 |

### 3단계: 전환 (Conversion) - 행동 유도 및 구매
**목표:** 구축된 신뢰를 바탕으로, 최종 제품(프리미엄 버섯 상품)에 대한 망설임을 제거하고 즉각적인 구매로 유도합니다.

| 항목 | 세부 내용 | 근거/연결 요소 |
| :--- | :--- | :--- |
| **핵심 목표 KPI** | 구매 전환율 (CVR) > 3%, 평균 주문 금액 (AOV) | 최종 비즈니스 목표 달성 여부 측정 |
| **콘텐츠 유형** | **랜딩페이지 & 이메일 시퀀스** (긴급성 및 희소성 활용) | 신뢰를 바탕으로 구매의 당위성을 제공하고 행동을 촉구 |
| **주요 메시지** | "데이터가 증명하는 최고의 선택. 지금, 통제권을 확보하세요." (행동 유도) | 명확한 가치 제안과 긴급성 부여 |
| **첫 번째 CTA** | **"오늘의 시스템 기반 최적 솔루션 구매하기"** (제품 상세 페이지/장바구니로 유도) | 신뢰가 충분히 형성되었을 때 망설임 없이 구매하도록 최종 행동 촉구 |
