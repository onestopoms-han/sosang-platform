# ⚙️ HS 분류 시스템: 복합 분기처리(Path A, B, C) 로직 및 검증 문서

**🎯 목표:** 물리적 형태, 재료 구성, 기능적 연동성을 기준으로 다단계 HS 코드 분류의 정확성과 투명성을 확보한다.

## 1. 핵심 판단 기준 (Priority Flow)

시스템은 다음 세 가지 기준을 **우선순위 순서대로** 적용하여 최종 분류를 결정합니다.

| 우선순위 | 판단 기준 | 설명 | 결과 분기 경로 |
| :---: | :--- | :--- | :--- |
| **1순위** | **물리적 형태 및 구조 (Physical Form & Structure)** | 품목의 외관, 제작 방식, 최종 마감 상태(예: 합금, 탄화물, 성형 상태)가 핵심인가? | Path A (형태 중심 분류) |
| **2순위** | **재료 구성 (Material Composition)** | 품목을 구성하는 재료(원자재)의 특성이 최종 기능에 지배적인 영향을 미치는가? | Path B (재료 중심 분류) |
| **3순위** | **기능적 연동성 (Functional Dependency)** | 품목이 다른 시스템이나 부품과의 연결/작동을 통해 가치를 창출하는가? | Path C (시스템/연동 중심 분류) |

## 2. 분기 경로 상세 로직 (If-Then Rules)

### Path A: 물리적 형태 및 구조 중심 분류 (Primary Flow)
**목표:** 품목의 외형, 제작 방식, 최종 상태를 기준으로 분류한다. (가장 높은 우선순위 적용)

*   **IF** 품목이 **명시적인 기계적 메커니즘(82.04/82.05 등)**을 통해 작동하거나 특정 물리적 형태(예: 합금, 탄화물)를 가질 때
    *   **THEN** `R001_MECHANISM_EXCLUSION` 규칙을 적용하고, 해당 경로의 HS 코드를 우선 검증한다.
    *   **검증 단계:** 최종 제품의 물리적 형태(예: 금속 탄화물 여부)를 확인하여 **'금속 탄화물 제외'** 규칙(`R004_EXC_TOOL_APPLICABLE` 연계)을 적용했는지 확인한다.
    *   **사용자 안내 템플릿:** "품목의 물리적 형태가 분류의 핵심 기준입니다. 최종 마감 상태(예: 합금, 탄화물)에 따른 예외 규칙이 자동으로 검증되었습니다."

### Path B: 재료 구성 중심 분류 (Secondary Flow)
**목표:** 품목을 구성하는 재료의 특성이 기능 및 가치를 결정할 때 적용한다. (Path A에서 불충분하거나 재료가 지배적일 경우)

*   **IF** 물리적 형태가 명확하지 않거나, **재료 구성(Material Composition)**이 품목의 핵심 기능과 최종 구조를 결정할 때
    *   **THEN** `R002_MATERIAL_SUBORDINATION` 규칙을 적용한다. 재료 분류를 1차 기준으로 삼는다.
    *   **검증 단계:** 입력된 재료 구성 리스트(`material_composition`)가 HS 코드 분류에 미치는 영향도를 분석하고, 해당 재료의 국제 표준 분류를 참조하여 검증한다.
    *   **사용자 안내 템플릿:** "품목의 최종 기능은 사용된 재료의 특성에 의해 결정됩니다. 입력된 재료 구성(`[재료 리스트]`)을 기반으로 재료 중심의 분류 로직이 적용되었습니다."

### Path C: 기능적 연동성 중심 분류 (Tertiary Flow)
**목표:** 품목이 다른 시스템이나 부품과의 상호작용을 통해 가치를 창출할 때 적용한다. (Path A, B에서 명확한 답이 없을 경우)

*   **IF** 품목이 다른 특정 기능이나 시스템(예: 84류, 85류 관련 부품)의 연동성을 통해 그 가치가 발현될 때
    *   **THEN** `R003_FUNCTIONAL_DEPENDENCY` 규칙을 활성화한다.
    *   **검증 단계:** 외부 API 모듈(`API Module`)과의 연동 여부를 확인하고, 필요한 경우 관련 부품/시스템의 분류 결과를 참조하여 최종 HS 코드를 조정한다.
    *   **사용자 안내 템플릿:** "본 품목은 기능적 연동성을 통해 분류됩니다. 관련 시스템 및 부품(예: 84류)과의 연관성을 검토한 결과, [연동된 코드]를 기준으로 보정되었습니다."
