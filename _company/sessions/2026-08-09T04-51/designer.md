## 📊 HS 코드 62.07 권한 확보 경로(Authority Flow) 시각화 Mockup 브리프

본 문서는 Writer가 제시한 HS 코드 분류 논리를 기반으로, 내부직원들이 **'권한 확보 경로(Authority Flow)'**를 명확히 이해하고 리스크를 인지하며 의사결정을 내릴 수 있도록 하는 인포그래픽 구조와 비주얼 시스템을 정의합니다.

### 1. 디자인 원칙 (Principle Guidelines)

모든 시각화는 **'데이터 기반 권위(Data-based Authority)'**를 명시하여, 제시된 분류가 단순한 규칙이 아닌 과학적 근거에 기반함을 강조해야 합니다.

*   **레이아웃:** 수직적 흐름(Vertical Flow)을 최우선으로 하며, 각 단계별로 명확한 분기점(Decision Node)을 설정합니다.
*   **계층 구조:** 가장 중요한 판단 기준(제조 방식)을 최상단에 배치하고, 리스크 점수(Risk Score)는 해당 경로의 결과물에 따라 동적으로 변화하도록 설계합니다.
*   **인터랙션:** 각 노드는 클릭 또는 호버 시 다음 단계로 부드럽게 이동하는 인터랙티브 플로우 차트 형태로 구현하여 사용자가 직접 탐색하게 합니다.

### 2. 컬러 팔레트 정의 (Color Palette Definition)

기존의 데이터 기반 권위 시스템을 확장하여 리스크 수준에 따른 색상 코드를 명확히 정의합니다.

| 상태 (State) | 의미 (Meaning) | Hex Code | 사용 목적 |
| :--- | :--- | :--- | :--- |
| **안정/통제** (Control/Safe) | 낮은 리스크, 권한 확보 경로 확정 | `#10B981` (Deep Forest Green 계열) | 기본 경로, 최종 승인 노드 |
| **경고/주의** (Warning/Caution) | 중간 리스크, 추가 검토 필요 | `#F59E0B` (Amber) | 중위 단계의 분기점, 데이터 기반 권위 지표 |
| **위험/긴급** (Risk/Urgent) | 높은 리스크, 즉각적 행동 조치 필요 | `#EF4444` (Red) | 위험 구간 진입 시, 최종 경고 노드 |
| **정보/근거** (Information/Evidence) | 데이터 출처 명시 | `#6B7280` (Gray) | 시스템 지표 설명, 근거 표시 |

### 3. 인포그래픽 구조 및 컴포넌트 정의 (Infographic Structure & Components)

#### A. 핵심 구조: 권한 확보 경로 플로우 (Authority Flow Diagram)

1.  **시작 노드 (Start Node):** "HS 코드 62.07 분류 요청"
2.  **Step 1: 제조 방식 확인 (분기점):** 가장 큰 분기점으로, **'편직/크로셰 여부'**에 따라 경로가 완전히 나뉩니다.
    *   **(IF [예]):** 즉시 **[61류]**로 이동 (경고 표시)
    *   **(IF [아니오]):** Step 2로 진행
3.  **Step 2: 품목 유형 확인:** 속옷/잠옷, 기타 품목으로 분기합니다.
4.  **Step 3: 재료 및 세부 분류 (Leaf Node):** 각 경로에 따라 최종 HS 코드를 제시하며, 해당 코드의 리스크 점수를 표시합니다.

#### B. 핵심 컴포넌트: 리스크 게이지 통합 (Risk Gauge Integration)

각 주요 분기점(Step 1, Step 2)마다 **'Risk Score' 게이지 컴포넌트**를 삽입합니다.

*   **게이지 위치:** 해당 분기점 바로 옆 또는 상단에 배치하여, 사용자가 다음 행동을 취하기 전에 리스크 수준을 즉각적으로 인지하게 합니다.
*   **색상 연동:**
    *   Step 1 (제조 방식): 편직/크로셰 경로 진입 시 **Red/Amber** 색상을 강조합니다.
    *   Step 3 (최종 분류): 최종 HS 코드에 도달했을 때, 해당 코드가 내포하는 잠재적 리스크를 게이지로 표시합니다.
*   **레이블:** 게이지 아래에는 명확한 텍스트 레이블과 함께 **'권위 근거'**(`데이터 기반 권위`를 시각적으로 표현)를 작은 글씨로 병기합니다.

### 4. 디자인 가이드라인 요약

*   **타이포그래피:** 핵심 수치(Risk Score)는 **Bold & Large**, 설명 텍스트와 근거 표시는 작은 글씨(`font-size: 8px;`)로 처리하여 시각적 계층 구조를 확립합니다.
*   **시각적 강조:** 최종 분류 결과(HS 코드)는 Gold 색상으로 강조하여, 이 경로가 **'과학적 근거에 기반함'**을 명확히 합니다.
*   **일관성:** 모든 경로에서 `Data-based Authority`의 원칙이 시각적으로 일관되게 적용되어야 합니다.
