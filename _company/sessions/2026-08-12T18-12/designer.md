# 📊 Authority Flow 인터랙티브 와이어프레임 및 마이크로-인터랙션 디자인 브리프 (v1.0)

## 1. 디자인 목표
사용자가 '위험 인지(불안)' 상태에서 시스템의 통제권을 회복하는 과정에서 발생하는 심리적 변화를 시각적으로 극대화하여, **데이터 기반 권위(Data-driven Authority)**가 사용자에게 즉각적인 신뢰와 안도감을 전달하도록 설계합니다.

## 2. 핵심 디자인 원칙 (재확인)
*   **색상 시스템:** 'Rich Gold' ($\#FFD700$)는 통제권 확보의 상징으로 사용하며, 상태 변화에 따라 **Deep Forest Green (안정)**, **Amber (경고)**, **Red (위험)** 계열을 동적으로 활용합니다.
*   **시각적 강조:** 모든 수치(Score) 옆에는 시스템 지표 설명이 명시되어 시각적 강조가 과학적 근거에 기반함을 확립합니다.

## 3. 핵심 사용자 시나리오 및 인터랙션 설계 (3안 비교 정리)

다음은 'Authority Flow'의 세 가지 핵심 단계에 따른 인터랙티브 경험을 디자인한 것입니다. 각 단계는 리스크 점수 변화에 따라 동적으로 반응해야 합니다.

### 📌 시나리오 1: 초기 위험 인지 및 경고 (Anxiety Phase)
**목표:** 사용자가 현재 상태가 위험함을 즉각적으로 인지하고, 시스템의 개입이 필요함을 알립니다.

| 요소 | 상태 변화 | 색상 로직 | 애니메이션/마이크로-인터랙션 | 텍스트 피드백 | 근거 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **리스크 게이지** | 점수가 Amber (중간 리스크) 이상으로 상승 시 | **Amber** ($\#FFC107$)로 즉시 전환 | 경고 톤의 미세한 진동(Pulse) 시작. 배경에 은은한 노란색 그라데이션 추가. | "주의: 통제권 확보율이 중간 수준입니다. 선제적 조치가 필요합니다." | `designer_wireframe_update_risk.md`, `RiskGauge.tsx` |
| **시스템 메시지** | 리스크 임계값 초과 시 (예: 50%) | Amber 배경에 검은색 텍스트 강조 | 경고 아이콘(⚠️)이 빠르게 깜빡이며 화면 중앙으로 이동. | "권한 확보 경로상, 위험 수준이 증가했습니다." | `designer_wireframe_update_risk.md` |
| **액션 유도** | - | - | 다음 단계 버튼이 잠시 비활성화(Dim) 상태로 표시 후 활성화 준비. | "다음 행동을 선택하세요." | UX Flow 원칙 |

### 📌 시나리오 2: 통제권 회복 및 조치 (Action Phase)
**목표:** 사용자가 제시된 해결책(Actionable Insight)을 실행하여 리스크를 감소시키는 과정을 시각화합니다.

| 요소 | 상태 변화 | 색상 로직 | 애니메이션/마이크로-인터랙션 | 텍스트 피드백 | 근거 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **리스크 게이지** | 사용자가 조치(Action)를 완료하여 점수가 하락할 때 | **Deep Forest Green** ($\#4CAF50$)으로 부드럽게 전환 | 녹색 파동(Wave) 효과. 리스크 게이지가 서서히 채워지며 안정감을 부여. | "조치 성공: 시스템 통제권이 회복되었습니다." | `designer_system_guide.md` (Green=안정), UX Flow 원칙 |
| **데이터 강조** | 핵심 지표(Control Score)에 포커스 시 | **Rich Gold** 색상으로 순간적으로 최대 밝기 강조 | 게이지의 중심 축이 Gold로 폭발하듯 강조되며, 안정 상태를 시각적 보상. | "통제권 확보율: 98.5% (안정)" | `designer_system_guide.md` |
| **피드백** | - | - | 조치 완료 애니메이션 후, 성공 메시지가 잠시 고정되어 사용자가 결과를 명확히 인지하도록 함. | "권한 확보 경로가 안정적으로 확립되었습니다." | 감정적 보상 설계 |

### 📌 시나리오 3: 최종 상태 확인 및 안도 (Relief Phase)
**목표:** 모든 권위 흐름이 성공적으로 완료되었음을 최종적으로 확인하고, 시스템의 신뢰성을 각인합니다.

| 요소 | 상태 변화 | 색상 로직 | 애니메이션/마이크로-인터랙션 | 텍스트 피드백 | 근거 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **최종 게이지** | 모든 조건 충족 시 (Green 상태) | **Deep Forest Green** 고정 유지 | 전체 화면에 잔잔한 녹색 빛이 감싸는 듯한 부드러운 아우라 효과. | "시스템 안정성 확보 완료." | `designer_system_guide.md` |
| **인증 마크** | 최종 성공 시 | Gold 색상 점멸 (Flicker) | 인증 마크 전체가 밝게 빛나며 잠시 정지 상태(Hold) 후 안도감 표현. | "Authority Flow 인증 완료." | 데이터 기반 권위 원칙 |

## 4. 디자인 적용 지침 요약
1.  **Gradient 활용:** 리스크 레벨 전환 시, 단순한 색상 변경이 아닌 **Amber $\rightarrow$ Green** 또는 **Red $\rightarrow$ Gold** 간의 부드러운 그라데이션 변화를 사용하여 감정적 흐름을 자연스럽게 유도합니다.
2.  **Gold의 역할:** 'Rich Gold'는 최종 목표(안정)에 도달했을 때, 시스템이 제공하는 **최고의 가치와 신뢰**를 상징하며, 이는 다른 모든 녹색/주황 색상 위에 덧입혀져 강조되어야 합니다.
3.  **모션:** 모든 변화는 '급격함' 대신 '부드러운 흐름(Flow)'을 우선하며, 사용자가 잠시 멈춰서 정보를 소화할 시간을 제공해야 합니다.
