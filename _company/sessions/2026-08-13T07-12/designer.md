# 🛡️ Authority Flow 기반 UX 상세 가이드: 위험 점수 하락 시나리오 (Risk Reduction Scenario)

본 가이드는 사용자가 시스템 내에서 '불안($\rightarrow$) 통제권 회복'의 여정을 경험하도록 설계하며, 특히 리스크가 감소할 때 발생하는 **감정적 전환**과 **시스템 권한 확보 단계**를 시각적으로 명시하는 데 중점을 둡니다.

## 1. 핵심 원칙 및 디자인 시스템 적용

모든 시나리오는 기존의 '데이터 기반 권위' 디자인 시스템(`designer_system_guide.md`)을 준수하며, 색상과 레이아웃은 **통제권 확보** 경험에 집중합니다.

*   **색상 매핑:**
    *   **Red (높은 위험):** 긴급성, 경고. (불안 상태)
    *   **Amber (중간 위험):** 주의, 선제적 조치 필요. (경계 상태)
    *   **Deep Forest Green (낮은 위험/안정):** 통제권 확보 완료, 안전. (Authority Flow 달성)
    *   **Rich Gold:** 권한/통제 지표 강조 및 최종 성공 피드백.

## 2. 시나리오 상세 흐름: 리스크 감소 과정

사용자의 리스크 점수가 하락하는 과정을 **'위험 인지 $\rightarrow$ 조치 실행 $\rightarrow$ 통제권 확보'**의 세 단계로 분할하고, 각 단계마다 명확한 디자인 피드백을 제공합니다.

### 단계 1: 위험 인지 (Risk Recognition)
*   **상태:** 리스크 점수가 기준 임계값($T_{high}$) 이상일 때.
*   **UX 목표:** 사용자가 현재 상황의 위험성을 즉각적으로 인식하게 함.
*   **시각적 스펙:**
    *   **대시보드:** 해당 지표(Risk Score)가 **Red** 또는 **Amber**로 강조 표시됩니다. (기존 시스템 가이드 준수)
    *   **피드백 컴포넌트 (Micro-interaction):** 리스크 수치 주변에 미세한 진동 애니메이션(Subtle Pulse)이 발생하여 긴급성을 부여합니다.
    *   **카피라이팅:** "경고: 현재 위험 임계값 초과 상태입니다." (법적 근거는 숨기고 감정적 경고에 집중)

### 단계 2: 조치 실행 및 권한 확보 (Action & Authority Acquisition)
*   **상태:** 사용자가 시스템에서 제시된 '다음 행동(Actionable Blueprint)'을 수행하고, 이에 따른 법적/시스템 조치를 취하는 순간.
*   **UX 목표:** 사용자의 행동이 직접적으로 리스크 감소로 이어짐을 시각화하여 통제권 회복의 과정을 체험하게 함.
*   **시각적 스펙:**
    *   **화면 전환 (Transition):** 현재 화면에서 다음 단계의 '실행 대기' 화면으로 **부드러운 슬라이드 전환(Smooth Slide Transition)**이 발생합니다. (급작스러운 변화 방지)
    *   **권한 경로 명시 (Authority Linkage):** 화면 중앙에 해당 조치가 어떤 법적 근거를 기반으로 하는지 명확하게 표시합니다.
        *   **표시 예시:** `[Action: Data Input] $\rightarrow$ [Authority Flow Step 1: Article ID XXXX 적용]`
    *   **피드백 컴포넌트 (Micro-interaction):** 사용자가 특정 버튼(예: '권한 승인')을 클릭하면, 해당 버튼이 **Gold 색상으로 채워지며** 시스템 내부의 권한 경로가 활성화되는 듯한 시각적 효과를 줍니다.

### 단계 3: 통제권 회복 (Authority Flow Achieved)
*   **상태:** 리스크 점수가 안전 임계값($T_{low}$) 이하로 하락하고, 시스템이 해당 조치를 성공적으로 반영했을 때.
*   **UX 목표:** 사용자가 '통제권 회복'이라는 긍정적인 감정적 경험을 극대화함.
*   **시각적 스펙:**
    *   **색상 변화 (Color Shift):** 전체 대시보드 및 해당 지표가 **Red/Amber에서 Deep Forest Green**으로 즉각적으로 전환됩니다.
    *   **최종 피드백 컴포넌트:** 리스크 게이지(Gauge)가 완전히 채워지며, 중앙에 **Rich Gold 색상의 '통제권 확보 완료' 배지**가 나타납니다.
    *   **카피라이팅:** "성공적으로 통제권을 회복했습니다. 현재 안전 상태입니다." (감정적 보상 제공)
    *   **법적 근거 강조:** 해당 성공에 기여한 **Article ID**가 명확하게 표시되어, 사용자가 자신의 행동이 법적 프레임워크 내에서 권위를 확보했음을 인지하도록 합니다.

## 3. 최종 컴포넌트 스펙 요약 (예시: Risk Score Component)

| 요소 | 위험 상태 ($R \ge T_{high}$) | 중간 상태 ($T_{low} \le R < T_{high}$) | 성공 상태 ($R < T_{low}$) |
| :--- | :--- | :--- | :--- |
| **게이지 색상** | Red (긴급) | Amber (경고) | Deep Forest Green (안정) |
| **주요 텍스트** | "위험 임계값 초과" | "선제적 조치 필요" | "**통제권 확보 완료**" |
| **Micro-interaction** | 미세 진동 (Pulse) | 시각적 강조 (Highlight) | Gold 배지 활성화 |
| **시스템 연계** | `Article ID` 하이라이트 | `Actionable Blueprint` 제시 | 성공한 `Authority Flow Step X` 명시 |
| **전환 효과** | N/A | 부드러운 전환 | 최종 상태 고정 (Lock) |
