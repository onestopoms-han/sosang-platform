## 1. 시스템 개요 및 목표 (System Overview & Goal)

**목표:** 사용자가 입력한 리스크 변수(원자재 가격 변동, 관세율 변화 등)를 조정함으로써 잠재적 예방 비용 절감액($CA$)을 실시간으로 시뮬레이션하고, 이에 따라 최적의 대응 계획($Plan$)과 실행 경로($Execution$)를 제시하여 재무적 통제권을 확보하게 한다.

**핵심 원칙:** **'예방 비용 절감액(Cost Avoidance)'**을 중심으로 디자인하며, 모든 시각적 강조는 '데이터 기반 권위'에 기반해야 한다.

**핵심 변수 (Input Variables):**
1.  **리스크 지표 (Risk Metrics):** $L_{\text{Duty}}$ (관세 리스크), $C_{\text{Delay}}$ (지연 비용), $CA_{\text{Re-export}}$ (재수출 절감액) 등.
2.  **조정 변수 (Adjustable Factors):** 각 지표에 영향을 미치는 가중치, 대응 전략 선택 옵션.

## 2. 3단계 인터랙티브 플로우 명세서 (Interactive Flow Specification)

### Step 1: 진단 (Diagnosis) - 리스크 평가 및 현황 파악

**목표:** 현재 상황의 위험 수준과 잠재적 손실액을 명확히 제시한다.
**시각화 컴포넌트:** **Dynamic Gauge & Risk Meter (동적 게이지 및 리스크 측정기)**

| 요소 | 상세 명세 | 인터랙션/상호작용 | 디자인 가이드 |
| :--- | :--- | :--- | :--- |
| **핵심 지표** | **잠재적 예방 비용 절감액 ($\text{CA}_{\text{Total}}$):** 사용자가 입력한 모든 변수를 기반으로 계산된 최종 잠재 절감액. | 실시간 업데이트 (Input 변경 시 즉시 변화) | 가장 크고 중앙에 배치. **'Rich Gold'** 색상으로 강조하여 재무적 가치를 극대화. |
| **리스크 레벨** | 현재 리스크 상태를 3단계로 분류: Low, Medium, High Risk. | 게이지 바 또는 컬러 기반 표시 (Deep Forest Green $\rightarrow$ Amber $\rightarrow$ Red) | **Risk Level** 레이블 아래에 시스템 지표(`Control Score: XX%`)를 작게 배치하여 권위 확보. |
| **변수 입력** | 사용자가 $L_{\text{Duty}}$나 $C_{\text{Delay}}$의 구체적인 값을 슬라이더나 입력 필드를 통해 직접 조정하도록 함. | 2D 슬라이더 또는 숫자 입력 필드 (Range Slider) | 변수를 조작할 때마다 $\text{CA}_{\text{Total}}$이 즉시 변화하는 피드백을 제공해야 함. |
| **Aha Moment 유도** | 특정 변수(예: 관세 리스크 증가 시)를 조정하면, $CA_{\text{Total}}$의 변화 폭이 시각적으로 극대화되도록 설계한다. | 마우스 오버 시 툴팁으로 각 지표가 의미하는 재무적 함의 설명 제공. |

### Step 2: 계획 (Plan) - 최적 경로 설정 및 전략 선택

**목표:** 진단된 위험에 대응하기 위한 구체적인 실행 방안을 제시한다.
**시각화 컴포넌트:** **Decision Tree / Scenario Comparison Card (결정 트리 / 시나리오 비교 카드)**

| 요소 | 상세 명세 | 인터랙션/상호작용 | 디자인 가이드 |
| :--- | :--- | :--- | :--- |
| **대응 전략** | 시스템이 도출한 3~4가지의 대응 시나리오(예: 최소 리스크 회피, 고수익 재수출, 일정 조정)를 카드 형태로 제시. | 라디오 버튼 또는 선택 가능한 모달 선택. | 각 옵션은 **'예상 절감액'**과 **'필요한 자원/시간'**을 명확히 비교하여 제시. |
| **시나리오 비교** | 각 시나리오별로 $\text{CA}_{\text{Total}}$의 기대값, 리스크 수용 수준($\lambda_{\text{Emotion}}$), 예상 실행 시간 등을 나란히 비교하는 표(Table). | 선택된 시나리오를 하이라이트하고 다른 시나리오와의 차이를 명확하게 대비. | **Growth Green**을 긍정적/최적의 경로에 할당하고, Red는 위험한 경로로 표시. |
| **인터랙션 심화** | 사용자가 특정 전략(예: '고수익 재수출')을 선택하면, 해당 전략이 $L_{\text{Duty}}$와 $C_{\text{Delay}}$에 미치는 영향을 시뮬레이션하여 계획의 타당성을 즉각적으로 보여준다. | 선택 후 동적 계산 결과가 카드 내에서 즉시 갱신되어야 함. |

### Step 3: 실행 (Execution) - 액션 플랜 및 모니터링

**목표:** 확정된 계획을 실제 행동으로 옮기고, 진행 상황을 추적한다.
**시각화 컴포넌트:** **Progress Tracker & Real-time Feedback Loop (진행 추적기 및 실시간 피드백 루프)**

| 요소 | 상세 명세 | 인터랙션/상호작용 | 디자인 가이드 |
| :--- | :--- | :--- | :--- |
| **워크플로우 시각화** | $\text{Diagnosis} \rightarrow \text{Plan} \rightarrow \text{Execution}$의 흐름을 시각적 경로(Flowchart)로 명확히 표시. | 단계별 완료 여부를 체크하는 토글 방식 (Step-by-Step). | 현재 위치를 강조하며, 다음 단계로 이동할 때마다 '신뢰도 점수'가 상승함을 시각적으로 표현. |
| **실시간 모니터링** | 실행 중인 작업(예: 재수출 서류 준비)의 진행률을 퍼센티지 게이지로 표시. | 실시간 데이터 연동 (API Feedback Loop). | 진행률이 높아질수록 색상을 Deep Forest Green으로 점진적으로 변화시켜 안정감을 제공. |
| **감성 보정** | $\lambda_{\text{Emotion}}$ 슬라이더를 실행 단계에 통합하여, 사용자의 심리 상태(불안/통제)가 계획의 진행 속도에 미치는 영향을 반영한다. | 사용자 입력에 따라 계획 목표 달성률이 동적으로 조정됨을 명시. |
