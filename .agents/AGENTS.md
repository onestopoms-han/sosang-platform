# ⚙️ 에이전트 프로젝트 분리 운영 지침

> [!IMPORTANT]
> **본 워크스페이스는 오직 [BDS 소상공인 플랫폼] 전용 공간입니다.**
> 아래 프로젝트들의 코드, 자산, 스타일 가이드를 절대 이 프로젝트 내부로 가져오거나 혼용하지 마십시오:
> - **(1) BDS 소상공인 플랫폼** (본 폴더 - SME SaaS)
> - **(2) ONSTOP AI Legal Shield** (Vite React + Tailwind CSS v4 기반 법률 진단 툴)
> - **(3) 참송이 골드 프로젝트** (B2C/B2B 프리미엄 버섯 상세페이지/세션)
> - **(4) onestop-ai-custom-service** (Vite React + Vanilla CSS 유리창 효과 커스텀 툴)
> 에이전트는 작업 중인 현재 파일 경로가 `소상공인플렛폼` 하위인지 반드시 확인하십시오.

본 지침은 회사 내에서 병렬로 진행 중인 여러 독립 프로젝트들의 자료와 기획을 명확히 구분하여 에이전트들이 혼동 없이 분배/관리하기 위한 규칙입니다. 각 프로젝트는 비즈니스 모델과 기술 스택이 완전히 분리되어 작동합니다.

---

## 1️⃣ [분류 1] BDS 소상공인 플랫폼 (SME SaaS)
*   **정의:** 소상공인들의 실질적인 재무적/운영적 어려움(Pain Point)을 감지하고 AI 기반 분석을 통해 성공을 돕는 SaaS 플랫폼.
*   **핵심 키워드:** `PainGauge`, `Trust Widget`, `통제권 회복 게이지`, `재무 데이터 분석`, `액션 플랜 처방`.
*   **타겟:** 골목상권 소상공인 및 소기업 자영업자.
*   **주의 사항:** 타 프로젝트의 자산 및 논리를 절대로 섞어서 기획하거나 코딩하지 마십시오.

---

## 2️⃣ [분류 2] ONSTOP AI Legal Shield (React + Vite + Tailwind v4)
*   **정의:** 8대 자격사 AI와 협업하여 기업 법률 리스크를 진단하고 전문가 서명을 확보하는 법률 보호 테크 플랫폼.
*   **기술 스택:** React + Vite + Tailwind CSS v4.
*   **주의 사항:** 소상공인 플랫폼에 이 프로젝트의 Tailwind v4 코드 스타일이나 법률 진단 비즈니스 로직을 적용하지 마십시오.

---

## 3️⃣ [분류 3] 참송이 골드 프로젝트 (Mushroom B2C/B2B)
*   **정의:** 특화된 AI 스마트방주 재재 기술을 탑재하여 생산된 프리미엄 버섯('참송이 골드')을 B2C/B2B용으로 기획 및 판매하는 독자적 상품 유통 페이지 빌딩.
*   **핵심 키워드:** `스마트방주`, `송이알코올 22배`, `에르고티오네인 180mg/kg`, `이중 사슬 다당체 2.67%`.
*   **주의 사항:** 이 프로젝트는 소상공인 자영업자 지원 플랫폼(BDS)과는 전혀 관계가 없으므로 상세페이지 및 영상 기획 시 소상공인 플랫폼의 SaaS 비즈니스 논리를 섞지 마십시오.

---

## 4️⃣ [분류 4] onestop-ai-custom-service (React + Vite + Vanilla CSS)
*   **정의:** 엑셀 변환기, 가계부 시뮬레이터, 카카오톡 알림 전송기 등 다양한 유틸리티 도구를 제공하는 커스텀 서비스 플랫폼.
*   **기술 스택:** React + Vite + custom Vanilla CSS glassmorphic variables (No Tailwind).
*   **주의 사항:** 소상공인 플랫폼의 구조나 타 프로젝트의 CSS 시스템과 섞이지 않도록 순수 커스텀 CSS 변수를 활용하십시오.
